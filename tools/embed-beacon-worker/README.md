# 埋め込みウィジェットの設置面カウンタ

## なぜ要るか
`/embed/` の31本は **90日間PV 0**、かつ**設置数を測る計器が存在しなかった**（2026-08-15 実測）。
「設置ゼロ」なのか「測れていないだけ」なのか判別できず、配布装置として伸ばす判断ができない。
keiri-tools は GitHub Pages 配信なので**アクセスログが取れない**ため、受け口を別に立てる。

## 何を測るか（これ以上は測らない）
- 送るのは **設置ページのオリジンとウィジェットのslugだけ**
- パス・クエリ・利用者の入力値・IP は**送らないし保存しない**
- 1オリジン×1ウィジェット×1日で1件（利用回数ではなく**設置面の数**を数える）

★第三者のサイトには**何も置かせない**。設置側が貼るのは iframe 1行のまま。
  計測は自分のドメイン（=このウィジェット）の中だけで完結する。

## デプロイ（未実施。★Cloudflareアカウントが要るので人の判断）
```
npm i -g wrangler
wrangler login
wrangler kv namespace create BEACON      # 出力された id を wrangler.toml に書く
wrangler deploy
```
デプロイして出た URL を `docs/assets/embed_beacon.js` の `ENDPOINT` に書いて push する。

★**ENDPOINT が空のうちは、埋め込み側は何も送らない**（設定漏れで黙って壊れるより安全側）。

## 読む
```
curl "https://<your-worker>.workers.dev/stats?days=30"
```
設置元オリジンの一覧・ウィジェット数・観測日数が返る。

## 費用
Workers も KV も無料枠の範囲（1日10万リクエストまで）。設置面を数えるだけなので桁違いに収まる。
