# Codex Sol × Grok 4.6 全ページデザイン・AIっぽさレビュー 最終裁定

対象: `docs/**/*.html` 451ページ（公開相当442）。

Codex Sol と Grok 4.6 xhigh に同じ軸で独立レビューさせ、その後に互いのレポートを交換して再集計・相互反証させた。本文は、両者の合意と実ファイルの再検算に基づく最終裁定。

## 結論

主サイトのデザイン体系は再置換不要。白・濃紺・深緑、影とグラデーションなし、本文672px、一覧1120px、罫線リスト中心の方向は、一般的なAI生成LPっぽさをかなり抑えている。

残っている問題は「主体系の失敗」ではなく、次の4系統。

1. embed 31ウィジェット＋案内1ページが別デザイン体系
2. SVG文字コントラスト、live region、ナビ、footerなど局所の同期漏れ
3. 331公開コラムの導入句・FAQ・CTA・注意箱の反復が作る量産テンプレート感
4. 375px検査が実際は500pxで動く計器の不備

## 食い違いの最終裁定

### shell幅二系統

**修正しない。** WIDE 384 / NARROW 32、x=80 / 304は事実だが、一覧・toc付きは1120px、単一本文は672pxという明示的なページ型設計。同一ページ内の左端・節幅は411 URLで一致。Grokが初回指摘を撤回した。

### `.tool-cta`

`352ページ / 406個 = a 402 + button 4`。button 4は単なるクラス誤用として修正。

リンク402個は、恒久方針 `design/ui-no-left-accent-border-cards` の「リンク導線: カードではなく、上下罫線のリスト行と矢印」の文言上は対象。ただし記事末の単発CTAと一覧の大量カードでは役割が異なる。**方針の対象ではあるが、一括置換は保留し、代表記事でCTAとリスト行を比較してから決める。**

### `.summary-box`

149ページ / 200個。恒久方針は結論・要約を枠で囲わないと明記するが、同クラスが計算式・仕訳例・ダウンロード・送信完了にも転用されている。**役割を分類し、真の結論・要約だけ枠を外す。**

### table `scope`

`scope=` がページ内0の104ページと、一部でもunscoped `th` を持つ公開225ページは別指標。遅反件数とは断定せず、複雑なデータ表から意味付けする。

## Fable独立監査追補（2026-08-28）

Fableは本裁定を**条件付き採択**。実375pxで451ページを再走査し、主体系の再置換不要、shell幅変更の却下、横溢れ2ページ限定を追認した。その上で上記3点（SVG 8要素、live region 6ページ、27種3箇所）を訂正した。
