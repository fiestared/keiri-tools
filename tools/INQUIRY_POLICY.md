# 問い合わせ対応のルール（資格法の線引き）

> **このサイトの資格法リスクは、公開しているページではなく「返信」にある。**
> 静的ページを何年磨いても、個別事案への返信1通で台無しになる。ここを運用で固定する。

対象は **`docs/contact/` のフォーム（Formspree）**、**X `@keiri_tools` のリプライ・DM**、
メールなど、**運営者が個人に向けて返す経路すべて**。

---

## 1. なぜ必要か（法的根拠）

- 税理士法2条1項3号の「税務相談」＝**納税義務者の具体的事実**について答弁・指示・意見表明すること。
  一般的な租税法の解説や**仮設例に基づく税額計算**は該当しない
- **サイトのツール・記事は前者にあたらない**（入力値はサーバに届かず、応答は事前に一律に書かれた
  プログラム。誰の事実かをサイトは知らない）。だから**ページは安全側**にいる
- 一方、**フォームに書かれた具体的な事情に運営者が返信すると、それは「具体的な質問に対する答弁」**に
  なる。サイトを継続運営しながら反復すれば「業として」を満たしうる
- **税理士法52条に報酬要件はない。無償でも違反になる。** 「無料で答えただけ」は通らない
- 労務は事情が違う（社労士法27条の独占は申請書作成・提出代行・帳簿書類作成で、相談は非独占。
  かつ「報酬を得て」が要件）。ただし**紛争性のある労務相談は弁護士法72条**に触れうるので、
  税務と同じ扱いにしておく

詳細は gbrain `keiri-tools/shikakuho-compliance`。

## 2. 判断基準（これだけ覚える）

> **入力と正解の検証か（答えてよい）／その人の事案の判断か（答えない）**

| 来た内容 | 対応 |
|---|---|
| 「東京都・月給30万・35歳で計算したら◯◯円になるが、協会けんぽの表では△△円」 | **答える。** ソフトの不具合報告であって事案の判断ではない |
| 「令和8年度の雇用保険料率が古いのでは」 | **答える。** 法改正の反映漏れの指摘 |
| 「このページの説明が国税庁のNo.◯◯と食い違っている」 | **答える。** 記述の誤りの指摘 |
| 「私は年商1,200万の◯◯業ですが、簡易課税にすべきですか」 | **答えない。** 個別事案の判断 |
| 「うちの母は年金だけですが非課税世帯になりますか」 | **答えない。** 同上 |
| 「この土地は小規模宅地の特例が使えますか」 | **答えない。** 事実認定を伴う |
| 「うちの会社のこの残業代の払い方は違法ですか」 | **答えない。** 紛争性があれば弁護士法72条の入口 |

**迷ったら答えない。** 「一般論として書けるならページに書く」が正しい対応で、
個人宛の返信で書くべきものではない。

## 3. 定型返信

### 税務

```
お問い合わせありがとうございます。

恐れ入りますが、個別の事案についての税務上のご判断は、税理士法により
税理士以外の者がお答えできないため、当サイトでは承っておりません。

一般的な計算方法は各ページの解説をご覧ください。個別のご判断は、
所轄の税務署（無料の電話相談があります）または税理士にご相談ください。

なお、計算結果の誤りのご指摘であれば、入力された値と正しいはずの結果を
お知らせいただければ確認して修正いたします。
```

### 労務・社会保険

```
お問い合わせありがとうございます。

恐れ入りますが、個別の事案についてのご判断は当サイトでは承っておりません。

一般的な計算方法は各ページの解説をご覧ください。個別のご判断は、
年金事務所・労働基準監督署、または社会保険労務士にご相談ください。

なお、計算結果の誤りのご指摘であれば、入力された値と正しいはずの結果を
お知らせいただければ確認して修正いたします。
```

## 4. やってはいけないこと

- **「参考までに言うと〜」で個別事案に踏み込む。** 断り書きの後に答えを書けば、断ったことにならない
- **AIに個別回答させる仕組みを作る。** 利用者の事情を受け取って回答を返す形にすると、
  税理士法54条の2（税務相談停止命令・令和6年4月施行）の議論の対象になりうる。
  ページに置くなら「あらかじめ一律に用意した一般的な情報」の形を崩さないこと
- **申告書・届出書の作成や添削を引き受ける**（税理士法2条1項2号）
- **報酬を得て社会保険の申請書作成・提出代行をする**（社労士法27条）

## 5. サイト側で担保していること（崩さない）

- `docs/contact/` — 種類プルダウンに「税務相談」「労務相談」を**置かない**。
  「個別の税務・労務相談にはお答えできません」を明記
- `docs/about/` — 「税理士・社会保険労務士ではありません」を meta description・JSON-LD・本文の
  3箇所に明記。**ここを消さないこと**（誤認惹起を防ぐ最大の防御であり、
  匿名化はリスクを下げるどころか上げる）
- 各ツールの結果直下と記事末尾の免責。`docs/embed/` にも1行版を入れてある
