支払サイト・支払日計算ツール

締め日と支払条件から、向こう1年の支払予定日を一括計算します。土日祝・年末年始は自動で営業日調整。条件はこの端末内にだけ保存されます。

よくある質問

支払サイトとは何ですか？

締め日から支払日までの猶予期間のことです。「サイト30日」なら締めから約30日後の支払い(翌月末払い相当)を意味します。下請法では、物品等の受領日から60日以内の支払いが義務付けられています。

「月末締め翌月末払い」とは？

毎月末日までの取引をまとめて締め、翌月末日に支払う条件です。7月分(7/1〜7/31)なら8月31日が支払期日です。

支払日が土日祝のときは？

銀行休業日のため、前営業日に前倒しするか翌営業日に後ろ倒しします。どちらにするかは契約・社内規程次第です。本ツールは内閣府公表の祝日データ(2027年まで)と年末年始(12/31〜1/3)を考慮します。

下請法（中小受託取引適正化法）の60日ルールとは？

物品等の受領日から60日以内の、できる限り短い期間内に支払期日を定める義務があります。「月末締め翌々月払い」は60日を超えるおそれがある条件です。なお下請法は令和8年1月1日施行の改正で題名が変わり、略称も「中小受託取引適正化法」になりました。フリーランスへの発注ではフリーランス法の60日ルールが別にかかります。両者の違いは下請法と中小受託取引適正化法・フリーランス法の違いで解説しています。
