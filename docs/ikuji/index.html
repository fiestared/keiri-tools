育児休業給付金 計算機

公開日: 2026年7月15日（更新日: 2026年10月19日）

育児休業給付金は、休業開始時賃金日額×支給日数の67%で、通算181日目から50%に下がります。月給30万円（年2回などの賞与を除く）の方なら1か月あたり201,000円で、181日目からは150,000円です。

賃金の月平均と育休の開始日・日数を入れると、支給単位期間ごとの額と合計を計算します。出生後休業支援給付金（＋13%）の判定にも対応しています。

入力例：月30万円なら 300000通勤手当・残業代・役職手当を含む額面の月給です。臨時の賃金と年2回などの賞与は除きます（入力する賃金）。
母親は原則、産後休業が終わった翌日、父親は勤務先に申し出た育休の初日です（開始日と日数の入れ方）。
産後パパ育休の給付を先に受けた方だけ入力します。先行分を67%の180日に通算します。
土日祝を含む暦の日数です。初期値の307日は、母親が産後休業から続けて育休に入り、子どもが1歳になるまで休む一般例です。
出生後休業支援給付金（＋13%）の判定
要件を満たすと最大28日分だけ13%が上乗せされます（13%の条件と対象期間）。
対象期間は、出生日・予定日の早い日から、遅い日より8週間を経過する日の翌日までです。産後休業をした方は16週間です。
出生日・予定日の早い日から、遅い日より8週間を経過する日の翌日までの日数です。
支援給付は支給済日数を差し引き、合計28日までです。

賃金日額の限度額の改定をまたいで金額が変わる期間などは、計算を止めます（正しく出ない場合）。

入力のしかた

どの6か月の給与を入力するか

計算の土台は、原則として同一の子の最初の出生時育児休業又は育児休業開始前の算入対象6か月に支払われた賃金です。母親が産前産後休業から続けて育休に入る場合は、原則として産休開始前の6か月を使います。

給与が毎月違う方、欠勤月がある方 賃金支払基礎日数が11日未満の月は、原則として6か月から除きます。育休開始前2年間に11日以上の月が6か月ない場合は、80時間以上の月を使えることがあります。単純な6か月平均にならないため、給与明細だけで判断せず、勤務先が作る「休業開始時賃金月額証明書」を確認してください。

臨時の賃金・3か月を超える期間ごとの賃金は除きます

賃金日額の計算に使うのは、3か月を超える期間ごとに支払われる賃金を除いた賃金です（17条1項）。臨時の賃金も除きますが、賞与という名称だけでは除外できません。

  • 含めるもの：通勤手当や残業代などは含みます。
  • 年間4回以上の賞与：同じ性質の賃金が年間4回以上支払われる場合等は算入対象です。月平均に含めて入力してください。
  • 分割払い：3か月を超える期間ごとの賃金を例外的に分割支給しただけの場合は除きます。

月給30万円・年2回の賞与計120万円（年収480万円）で他の算入賃金がなければ、賃金日額は10,000円です。この例で年収を12で割った額を入力すると、除外対象の賞与まで含めて給付額を多く見積もります。

67%・支給日数30日の給付201,000円を12倍して年収で割ると50.25%です。ただし、これは月額の年換算比較であり、181日目以降50%となる実際の年間給付の補償率ではありません。

開始日と日数の入れ方

  • 育児休業を開始する日：分からない方は、厚生労働省の産休・育休期間の計算で確認できます。支給単位期間は、この日の「応当日」で1か月ごとに区切られます。
  • 育児休業の日数：給付は原則として1歳の誕生日の前々日までです。父親、延長、分割取得の方は実際の開始日と終了日を数えて入力してください。厚生労働省の公式試算ツールでも期間を確認できます。
  • 支援給付を受給済みの日数：今回の休業日数を超える日数は入力できません。

給付期間を延長する場合

保育所等に入れないなどの延長要件を満たして育休を続ける場合、給付対象は子が1歳6か月に達する日前まで、さらに要件を満たせば2歳に達する日前まで延長できます。

延長理由は保育所等に入れない場合に限らず、養育予定の配偶者の死亡・疾病などもあります。理由ごとの条件や有期雇用の契約期間の条件は、厚生労働省の育児休業等給付のQ&Aで確認できます。

2025年4月以降、保育所等に入れないことを理由に給付期間を延長するには、利用申込みが速やかな職場復帰のためと認められる必要があります。延長時の支給申請書には、次の書類を添付します。

  • 育児休業給付金支給対象期間延長事由認定申告書
  • 市区町村に提出した保育所等の利用申込書の写し
  • 市区町村が発行する入所保留通知書・入所不承諾通知書など、利用できないことを示す通知

この計算機の見方

計算のしかた（雇用保険法61条の7第6項）

  • 給付額：1か月の給付は休業開始時賃金日額×支給日数（原則30日）×67%で、通算181日目から50%です。
  • 賃金日額：同一の子の最初の出生時育児休業又は育児休業開始前の算入対象6か月の賃金総額÷180で求めます。産前産後休業を取得した場合は、原則その開始前の6か月です。
  • 日割り：終了期間と180日目をまたぐ期間は法定の日割りで計算します。

上限額は「あなたの年齢」では変わりません（賃金日額16,540円）

賃金日額には上限があり、それを超える人は16,540円で頭打ちになります。つまり67%の期間は月332,454円が上限です。どちらも令和8年8月改定後の額で、332,454円は支給日数30日の場合です。

育児休業給付の賃金日額上限は年齢で変わりません。61条の7第6項は17条4項2号ハ（30歳以上45歳未満の区分）を適用します。

180日目をまたぐ支給単位期間は「まるごと50%」になりません（日割り）

67%から50%への切り替わりは、月の区切りではなく通算180日目で起こります。180日目をまたぐ支給単位期間は、180日目までの日数×67%と、181日目からの日数×50%を足した額になります（61条の7第6項かっこ書き）。

たとえば賃金日額10,000円の方が4月1日から1年休むと、6回目（9/1〜9/30）に180日目（9/27）が来ます。この回は27日分が67%（180,900円）＋3日分が50%（15,000円）＝195,900円です。「まるごと50%」と考えると150,000円になり、45,900円少なく見積もってしまいます。

なぜ「開始日」が要るのか — 支給日数（30日）と休業日数（暦）は別物です

ここが育児休業給付でいちばん間違えられるところです。2つの「日数」が、別々の数え方で動いています。

支給日数（いくら払うかを決める日数）終了月以外の支給単位期間は一律30日（61条の7第6項1号）。暦が31日の月でも30日、暦28日の2月でも30日です。終了月だけは実日数（同項2号）
休業日数（67%が50%に下がる境目）暦の通算日数（同項本文）。180日目＝休業開始日＋179日

そのため、同じ365日の休業でも、開始日によって給付の合計が変わります（条文による計算例）。

  • 2026年4月1日～2027年3月31日の365日では67%が177日、50%が184日で2,105,900円です。
  • 2026年2月1日～2027年1月31日の365日では67%が180日、50%が182日で2,116,000円です。
計算例の条件は、先行給付なし、休業中賃金なし、支援給付なし、賃金日額10,000円が全期間で上下限にかからない場合です。どちらも令和8年8月改定による日額の変更はなく、差は10,100円です。

初回申請でそろえるものと期限

初回申請は、勤務先を管轄するハローワークへ原則として会社経由で提出します。本人が希望すれば、本人による申請も可能です。主な書類は次のとおりです。

  • 雇用保険被保険者休業開始時賃金月額証明書
  • 育児休業給付受給資格確認票・（初回）育児休業給付金／出生後休業支援給付金支給申請書
  • 賃金台帳・出勤簿・育児休業申出書など、賃金の額・支払い状況と休業開始日を確認できる記録
  • 母子健康手帳など、育児の事実や出産予定日・出生日を確認できるもの

新たな振込口座の登録では口座番号を確認できる資料も必要です。届け出たマイナンバーに対応する公金受取口座への振込を希望する場合は不要です。出生後休業支援給付金も申請する場合は、配偶者の状況などに応じた追加書類があります。

受給資格確認と初回支給申請を同時に行う場合の提出期限は、育児休業開始日から4か月を経過する日が属する月の末日です。受給資格確認だけを先に行う場合は、初回の支給申請日までに手続きします。

計算額と振込の時期は別です

画面の月ごとの計算額が、そのまま毎月振り込まれるとは限りません。育児休業給付金の2回目以降の支給申請は原則2か月に一度ですが、本人が希望すれば1か月に一度も可能です。申請日と入金日は別なので、給付対象の期間・金額と受取日程を分けて確認してください。

出生後休業支援給付金（＋13%）の条件

要件を満たすと最大28日分だけ13%が上乗せされ、67%＋13%＝80%になります。出生後休業支援給付金は、2025年4月に新設された給付です。育児休業給付は非課税で、所定の要件を満たせば社会保険料も免除されるため、手取りでは休業前の約10割になります。

  • 本人の条件：本人が対象期間内に通算14日以上の給付対象休業をする等の条件があります。
  • 本人の対象期間：出生日・予定日の早い日から、遅い日より8週間を経過する日の翌日までです。本人が産後休業をした場合は、8週間ではなく16週間です。
  • 配偶者の条件：配偶者は免除に該当しない場合、早い日から遅い日より8週間を経過する日の翌日までに通算14日以上の対象休業が必要です。
  • 上限：同じ子の支援給付は通算28日が上限で、既支給日数を差し引きます。
  • 通算：先行する出生時育児休業給付の日数は14日要件にも通算します。

配偶者の要件が免除される7つの類型（61条の10第2項）

子の出生日の翌日に次の所定類型に該当する場合は配偶者の育休要件が免除されます。

  • ①配偶者がいない（行方不明は勤務先で3か月以上無断欠勤が続く場合又は災害による場合に限る）
  • ②配偶者が子と法律上の親子関係がない
  • ③配偶者から暴力を受け別居中
  • ④配偶者が無業者
  • ⑤配偶者が自営業など雇用される労働者でない
  • ⑥配偶者が産後休業中
  • ⑦その他の理由で育児休業をできず、所定の申告書の列挙理由に該当

父親で配偶者が出産した子（養子でない）の場合は、配偶者の無業・非労働者・産後休業等の類型により配偶者要件を満たします。母親も、ひとり親や配偶者が無業・自営業等の免除類型に該当すれば配偶者の14日要件は免除されます。どちらの場合も、本人の対象休業14日以上等の要件は免除されません。

受給資格が足りないとき・正しく出ない場合

「被保険者期間が12か月に足りない」と言われた方へ — 諦める前に読んでください

受給の原則は、育児休業を開始した日の前2年間に、賃金支払基礎日数が11日以上の月が12か月以上あることです（61条の7第1項）。被保険者期間が足りない場合は、算定対象期間の延長や特例基準日などの適用を確認します。第1子の産休・育休から復帰後すぐに第2子を妊娠・出産した場合も、資格の有無は休業期間・復職期間・賃金支払基礎日数等によって変わり、一律に不足とはいえません。それでも救済①によって受給できることがあります。

12か月に足りないときの確認事項（雇用保険法）

  • ① 「2年間」を最大4年間まで延ばせます（61条の7第1項かっこ書き）。次の理由によって引き続き30日以上賃金の支払を受けられなかったとき、その日数を2年に加算します（上限4年）。
    • 疾病・負傷
    • 出産
    • 事業所の休業
    • 事業主の命による外国における勤務
    • 教育訓練休暇
    • 国と民間企業との間の人事交流に関する法律による交流採用
    • これらに準ずる理由で公共職業安定所長がやむを得ないと認めるもの
    疾病・負傷以外の理由は施行規則101条の29の列挙です。産前産後休業は「出産」に当たります。産前6週＋産後8週で約98日あり、30日以上です。第1子の産休・育休で無給だった期間があるなら、まずこれを疑ってください。
  • ② 母親は「産前休業を開始した日」で数え直せます（61条の7第4項・特例基準日）。産後休業をした方で、育休開始日を基準にするとみなし被保険者期間が12か月に満たない場合、基準日が産前休業を開始した日まで戻ります。
    • 育児休業給付金には特例基準日の規定があり、出生時育児休業給付金（61条の8）には同じ規定がありません。
    • 出生後休業支援給付金には61条の10第5項に特例基準日の規定があります。
  • ③ 11日以上の月が12か月に足りないときは、「80時間以上」の月も1か月と数えます（14条3項）。週2〜3日勤務などで11日に届かない月がある方は、この規定で届くことがあります。
  • ④ 入社した月は「半月」として数えられることがあります（14条1項ただし書）。入社日から最初の喪失応当日の前日までが15日以上あり、かつその期間の賃金支払基礎日数が11日以上なら、2分の1か月として計算します。

この画面は「あなたが受給できるか」を判定していません。上のどれかに当てはまりそうな方は、自己判断で諦めず、必ずハローワークに確認してください。

1年の育休なら、諦めることで失う額は月給30万円の方で約210万円です。上限に張り付く方なら約350万円で、休業開始日・月の日数で変動します。

育休中の就業にも支給条件があります

通常の育児休業給付金では、各支給単位期間の就業日数が10日以下、10日を超える場合は就業時間が80時間以下であることが必要です。この就業条件を超えた期間は給付対象になりません。

無給の就業でも確認が必要です。休業前の被保険者期間の条件や、下記の賃金額による減額・不支給とは別に確認します。産後パパ育休の就業上限とは区別してください。

この計算機で正しく出ない場合

  • 育休中に就業して賃金を受け取る方は、賃金と給付の合計が休業前の80%で頭打ちになります（61条の7第7項）。賃金が80%以上なら不支給です。賃金が13%（181日目以降30%）を超えると給付が減額され、賃金と育児休業給付の合計は80%で一定になる区間があります。
  • 産後パパ育休（出生時育児休業給付金）は別の給付です（61条の8）→ 産後パパ育休 給付金 計算機。
  • 通常育休を分割した後の再開分は対象外です。ここでは、産後パパ育休の後に連続して取る通常育休を計算します。
  • 限度額の改定をまたぐ期間：限度額は支給対象期間に応じて切り替えます。令和8年8月1日の改定をまたぐ支給単位期間で新旧の限度額によって金額が変わる場合、又は令和9年8月1日以後など改定額が未収録の場合は計算を止めます。開始時の表示額だけで全期間を計算するものではありません。
  • 振込日：支給単位期間ごとの休業期間の日付と支給額の目安を出します。口座への振込日は計算しません。

最終的な金額はお住まいの地域のハローワークにご確認ください。

よくある質問

育児休業給付金は月にいくらもらえますか？

休業開始時賃金日額×支給日数の67%で、通算181日目からは50%です。月給30万円（年2回などの賞与を除く）の方なら賃金日額は10,000円で、1か月あたり201,000円になります。181日目からは50%に下がり、150,000円です。ただし賃金日額には上限（16,540円）があるため、67%の期間の上限は月332,454円です。

育児休業給付金の上限は年齢で変わりますか？

変わりません。育児休業給付は、年齢に関係なく賃金日額16,540円が上限です。失業保険（基本手当）は年齢で4段階に分かれますが、育児休業給付は61条の7第6項の読替えによって「30歳以上45歳未満」の額に固定されています。令和8年8月改定後は、50歳でも25歳でも育児休業給付の賃金日額上限は16,540円です。

出生後休業支援給付金の13%は誰でももらえますか？

いいえ。本人が所定の対象期間に通算14日以上の給付対象休業をする等の要件があります。配偶者要件の免除に該当しない場合、配偶者の対象休業が14日未満なら13%の給付は支給されません。ただしひとり親の方や、配偶者が被用者でない方などは、この配偶者要件が免除されます（61条の10第2項）。支給されるのは最大28日分です。

賞与（ボーナス）も育児休業給付金の計算に入りますか？

年2回など3か月を超える期間ごとの賞与は入りません。雇用保険法17条1項が「三箇月を超える期間ごとに支払われる賃金」を除いているためです。年間4回以上の同じ性質の賞与等は算入対象ですが、単なる分割払いは除きます。賞与の割合が大きい方ほど、年収に対する実質の補償率は下がります。

制度と税金の、別の計算

個人のお金・資産形成 毎月いくら積み立てられるか、手取りから逆算 積立額と信託報酬の差、売却時の税金まで。銘柄のおすすめはありません。 補助金・事業支援 いま公募中の補助金を、締切が近い順で検索 都道府県・従業員数・上限額で絞り込み。登録不要・営業の連絡はしません。

関連する解説

  • 育児休業給付金はいくら？67%＋13%の計算と「手取り10割」の条件育児休業給付金は賃金日額の67%（181日目以降50%）。出生後休業支援給付金13%を足すと80%＝手取り10割相当だが、母親側はこの13%
  • 介護休業給付金 — 67%は附則の暫定措置、上限366,222円と対象家族7区分の境界介護休業給付金の67%は雇用保険法の本則ではなく、附則12条が「当分の間」読み替えているもの。上限は年齢に関係なく45〜60歳の額に固定され
  • 育休中の年末調整 — 給付金が非課税なのは「準用」されているから。配偶者控除が新たに立ち上がる育休中の年末調整は、その年に給与の支払があれば原則として対象、1円も無ければ行われません。育児休業給付金は非課税で合計所得金額に入らないため
  • 育児時短就業給付金はいくらもらえるか｜賃金の10%と、90%を超えたときの支給率の正体育児時短就業給付金は時短中の各月の賃金の10%。ただし賃金が開始時賃金月額の90%を超えると逓減し、100%以上は不支給。逓減率は規則101
