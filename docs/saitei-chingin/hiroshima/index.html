広島県の令和8年度の地域別最低賃金は、令和8年10月11日から時間額1,141円です。

広島県の令和8年度の改定は、改定前の時間額1,085円から56円の引上げ（5.2%）です。厚生労働省の全国一覧（令和8年度）に掲載されています。

広島県の改定前・改定後の境界

地域別最低賃金の時間額は発効日を境に切り替わります。広島県の令和8年度の改定をまたぐ期間は、次の区分で確認してください。出典: 厚生労働省の全国一覧（令和8年度）。

広島労働局の最低賃金資料で、特定（産業別）最低賃金も確認できます。地域別と特定最低賃金の両方が適用される場合は、高い方を使います。減額特例の許可を受けている場合は許可内容を確認してください。適用範囲の説明。

広島県の最低賃金を月給に換算する例

広島県の令和8年度の地域別最低賃金を、月の所定労働時間が一定の場合の月給に換算した例です。時間が月によって違う場合は、年間の月平均所定労働時間で換算します。賞与や対象外の手当を含む総支給額とは区別してください。

表の月給額 ＝ 地域別最低賃金の時間額 × 月の所定労働時間。換算の根拠は最低賃金法施行規則の月給の換算規定、時間額と発効日の出典は厚生労働省の全国一覧（令和8年度）です。

最低賃金に含めない賃金の確認

次の賃金は最低賃金の比較から除きます。

  • 臨時に支払われる賃金
  • 一か月を超える期間ごとの賃金
  • 所定時間を超える労働への賃金
  • 所定休日の労働への賃金
  • 深夜労働の通常賃金を超える部分
  • 精皆勤手当
  • 通勤手当
  • 家族手当

対象外の賃金の詳しい列挙と固定残業代の扱いは親ページで確認できます。根拠: 最低賃金法・同法施行規則・厚生労働省「最低賃金の対象となる賃金」。
