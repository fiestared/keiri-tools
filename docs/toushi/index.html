資産形成の計算ツール

給与から毎月いくら回せて、それが将来いくらになり、出すときにいくら税金がかかるかを計算します。このセクションは算数と条文だけで作っていて、商品の推奨はしません。

このセクションでやらないこと

  • 銘柄・商品を勧めません。「どのファンドを買うべきか」は書きません
  • 利回りはあなたが入力します。こちらで「年◯%」と置きません（過去の実績は将来を保証しません）
  • あなたの資産や家族構成に合わせた提案はしません。入力した前提での計算例だけを出します
  • 有料化・会員登録・個別相談はしません。入力値はブラウザの外へ出ません

当サイトは金融商品取引業者ではありません。投資には元本割れの可能性があり、計算結果は将来の成果を保証するものではありません。

ツール

積立シミュレーター（信託報酬つき）
毎月の積立額・年数・あなたが想定する利回りから将来の評価額を計算します。★信託報酬を年率で差し引いた場合の差額も同時に出します（0.09%と0.5%の差は月3万・20年・年5%の前提で535,298円）。★年利を12で割らずに月次の複利で計算します（12分割だと同じ条件で158,656円ずれます）。NISAの枠に収まるか、特定口座なら税金がいくらかも表示。
iDeCoの出口の税金（退職所得控除の重複調整）
iDeCoを一時金で受け取ると退職所得になります。会社の退職金と時期が近いと勤続期間の重複で控除が減ります。★令和8年1月1日以後に受け取るiDeCo一時金は前年以前9年内＝「10年ルール」に延長されました（従来は5年）。★退職金を先に受け取る場合は19年内＝20年で、向きによって年数が違います。

このセクションの数字の出どころ

NISAの枠は租税特別措置法37条の14を e-Gov 法令API で実読しています（生涯1,800万円・うち成長投資枠1,200万円・年間はつみたて120万円と成長240万円）。譲渡益の税率20.315%は同法37条の10・地方税法・復興財源確保法13条によります。このサイトについてに検証のやり方を書いています。

枠は「買った値段」で数えます。値上がりしても枠は減りません（条文が「取得対価の額の合計額」と書いているため）。時価で数える計算は、上がった人ほど枠を少なく見せます。

税金・社会保険のツールもあります

毎月いくら回せるかは、手取りが分からないと決まりません。手取り計算機・iDeCo節税シミュレーター・ふるさと納税の限度額・退職金の税金もあわせてお使いください。
