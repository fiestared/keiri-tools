短い1行版

税金・経理・補助金ツールズ（https://keiri-tools.com/）— 手取り・社会保険料・源泉徴収税額などを無料で計算できるサイトです。

2〜3行版

税金・経理・補助金ツールズ（https://keiri-tools.com/）は、手取り・社会保険料・源泉徴収税額・ふるさと納税の上限などを無料で計算できるサイトです。国税庁・協会けんぽなどの公表資料にもとづき、公式の計算例と照合して作られています。入力した金額はブラウザの中で計算され、サーバーには送信されません。

主なツールのURL

ご紹介先の読者に合いそうなツールを選んでお使いください。すべての計算ツールはトップページの一覧にあります。

給与・社会保険

  • 手取り計算機https://keiri-tools.com/tedori/額面の月給から、社会保険料・所得税・住民税を引いた手取りを自動計算。
  • ボーナス手取り計算機https://keiri-tools.com/bonus-tedori/賞与の額面から、社会保険料と源泉所得税を引いた手取りを自動計算。
  • 社会保険料 計算機https://keiri-tools.com/shakai-hoken/給与額から標準報酬月額の等級・健康保険・介護保険・厚生年金を自動計算。
  • 源泉徴収税額 計算機https://keiri-tools.com/gensen-choshu/給与は国税庁の税額表（月額表・令和8年分／甲欄・乙欄）、賞与は算出率の表を引いて計算。
  • 残業代（割増賃金）計算機https://keiri-tools.com/zangyodai/月給と年間所定休日から1時間あたりの単価を求め、時間外25%・1か月60時間超は50%・法定休日35%・深夜は上乗せ25%で残業代を計算。
  • 有給休暇の付与日数 計算機https://keiri-tools.com/yukyu/入社日から付与日数・付与日を自動計算。
  • 年収の壁 手取り逆転シミュレーターhttps://keiri-tools.com/kabe/130万円の壁の手取り逆転と、勤務先の社会保険に入ったときの本人負担を計算。
  • 年末調整 計算機（還付・不足額）https://keiri-tools.com/nenmatsu-chosei/給与の総額と天引きされた税額から、12月の年末調整でいくら戻るか・追加で引かれるかを国税庁の手順どおりに計算。
  • 算定基礎届（定時決定）の計算https://keiri-tools.com/santei/4月・5月・6月の報酬と支払基礎日数から、9月からの標準報酬月額（健保・厚年の等級）を出します。

税金・控除

  • ふるさと納税 限度額シミュレーションhttps://keiri-tools.com/furusato/年収と家族構成から、自己負担2,000円で収まる寄附額の上限を計算。
  • 所得税 計算機（確定申告）https://keiri-tools.com/shotokuzei/給与・年金・事業などの所得と控除から、令和8年分の所得税と確定申告で納める税金・還付される税金を計算。
  • 住民税 計算機https://keiri-tools.com/juminzei/年収と家族構成から住民税の年額を計算。
  • 医療費控除 計算機https://keiri-tools.com/iryohi/1年間の医療費と年収から、控除額と戻ってくる税金（所得税＋復興特別所得税＋住民税）の目安を自動計算。
  • 退職金の税金（退職所得）計算機https://keiri-tools.com/taishokukin/退職金の額と勤続年数から、退職所得控除・所得税・住民税・手取りを計算。
  • 相続税 計算機https://keiri-tools.com/sozokuzei/遺産の総額と相続人の構成（配偶者・子・親・兄弟姉妹）から、相続税の総額と実際の納税額を自動計算。
  • 収入印紙の金額 判定機（印紙税額一覧表）https://keiri-tools.com/inshi/文書の種類と記載金額から、必要な収入印紙の額を自動判定＋第1号〜第20号の印紙税額一覧表。
  • 消費税・端数処理 計算機https://keiri-tools.com/shohizei/税込・税抜を8%/10%で相互計算。

経理・請求・振込

  • 振込手数料「先方負担」計算https://keiri-tools.com/senpou-futan/請求額からいくら差し引いて振り込むかを計算。
  • 振込名義カナ変換（全銀フォーマット）https://keiri-tools.com/zengin-kana/受取人名を半角カナ・法人略語（先頭の株式会社→ｶ)）に一括変換。
  • 支払サイト・支払日計算https://keiri-tools.com/shiharai-site/「月末締め翌月末払い」等から向こう1年の支払日を一覧化。
  • 日数計算・営業日計算https://keiri-tools.com/eigyobi/期間の日数、「◯営業日後」の日付、期間内の営業日数を計算。
  • インボイス登録番号チェック（一括）https://keiri-tools.com/invoice-bangou/請求書のT＋13桁を貼り付けてまとめて検証。
  • 減価償却費の計算機（定額法・定率法）https://keiri-tools.com/genka/取得価額・耐用年数・償却方法から、減価償却費が毎年いくらか（償却スケジュール）を自動計算。
  • 利益率・原価率 計算（売価の逆算）https://keiri-tools.com/riekiritsu/原価と売価から粗利率・原価率・上乗せ率。
  • 電帳法 索引簿テンプレート（無料DL）https://keiri-tools.com/denchoho-index/電子帳簿保存法の検索要件を満たす索引簿のCSVテンプレート。

給付金・手当

  • 失業保険（基本手当）計算機https://keiri-tools.com/kihonteate/離職時の年齢・給料・勤続年数・退職理由から、1日あたりの基本手当日額・所定給付日数・受け取れる総額の目安・支給が始まる時期を計算。
  • 傷病手当金 計算機https://keiri-tools.com/shobyo/病気やケガで働けないときの日額・支給日数・合計額を計算。
  • 出産手当金 計算機https://keiri-tools.com/shussan/産休中に健康保険から出る出産手当金を計算。
  • 育児休業給付金 計算機https://keiri-tools.com/ikuji/育休中に毎月いくら振り込まれるかを30日ごとに計算。
  • 高額療養費 計算機https://keiri-tools.com/kogaku-ryoyohi/ひと月の医療費が高額になったとき、いくらまでが自分の負担で、いくら戻ってくるのかを計算。

補助金

  • 補助金の検索（締切が近い順）https://keiri-tools.com/hojokin/いま公募中の補助金を締切が近い順で探せます。
  • 補助金の経理・税務（圧縮記帳）https://keiri-tools.com/hojokin-zeimu/補助金をもらったときの圧縮限度額・仕訳・減価償却を計算。

計算ウィジェットの埋め込み

リンクのほかに、手取り・社会保険料・源泉徴収税額などの計算機を、ご自身のページの中にそのまま表示することもできます。コードをコピーして貼るだけです。詳しくは計算ウィジェットを、あなたのサイトに埋め込むをご覧ください。
