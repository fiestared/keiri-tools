短い版

税金・経理・補助金ツールズ（https://keiri-tools.com/）— 手取り・社会保険料・源泉徴収税額などを無料で計算できるサイトです。

少し詳しい版

税金・経理・補助金ツールズ（https://keiri-tools.com/）は、手取り・社会保険料・源泉徴収税額・ふるさと納税の上限などを無料で計算できるサイトです。国税庁・協会けんぽなどの公表資料にもとづき、公式の計算例と照合して作られています。入力した金額はブラウザの中で計算され、サーバーには送信されません。

主なツールのURL

ご紹介先の読者に合いそうなツールを選んでお使いください。すべての計算ツールはトップページの一覧にあります。

給与・社会保険

  • 手取り計算機https://keiri-tools.com/tedori/額面の月給から、社会保険料・所得税・住民税を引いた手取りを計算。
  • ボーナス手取り計算機https://keiri-tools.com/bonus-tedori/賞与の額面から、社会保険料と源泉所得税を引いた手取りを計算。
  • 社会保険料 計算機https://keiri-tools.com/shakai-hoken/給与額から標準報酬月額の等級と、健康保険・介護保険・厚生年金の保険料を計算。
  • 源泉徴収税額 計算機https://keiri-tools.com/gensen-choshu/給与・賞与から差し引く源泉所得税の額を、国税庁の税額表を引いて計算。
  • 残業代（割増賃金）計算機https://keiri-tools.com/zangyodai/月給と所定労働時間から時間あたりの単価を求め、割増賃金（残業代）を計算。
  • 有給休暇の付与日数 計算機https://keiri-tools.com/yukyu/入社日から有給休暇の付与日と付与日数を計算。パートの比例付与にも対応。
  • 年収の壁 手取り逆転シミュレーターhttps://keiri-tools.com/kabe/年収の壁の手取り逆転と、勤務先の社会保険に入ったときの本人負担を計算。
  • 年末調整 計算機（還付・不足額）https://keiri-tools.com/nenmatsu-chosei/給与の総額と天引きされた税額から、年末調整で戻る額・追加で引かれる額を計算。
  • 算定基礎届（定時決定）の計算https://keiri-tools.com/santei/春の報酬と支払基礎日数から、算定基礎届で決まる標準報酬月額を計算。

税金・控除

  • ふるさと納税 限度額シミュレーションhttps://keiri-tools.com/furusato/年収と家族構成から、ふるさと納税の自己負担が最小で収まる寄附額の上限を計算。
  • 所得税 計算機（確定申告）https://keiri-tools.com/shotokuzei/所得と控除から、所得税と確定申告で納める税金・還付される税金を計算。
  • 住民税 計算機https://keiri-tools.com/juminzei/年収と家族構成から住民税の年額を計算。
  • 医療費控除 計算機https://keiri-tools.com/iryohi/年間の医療費と年収から、医療費控除の額と戻ってくる税金の目安を計算。
  • 退職金の税金（退職所得）計算機https://keiri-tools.com/taishokukin/退職金の額と勤続年数から、退職所得控除・所得税・住民税・手取りを計算。
  • 相続税 計算機https://keiri-tools.com/sozokuzei/遺産の総額と相続人の構成から、相続税の総額と各人の納税額を計算。
  • 収入印紙の金額 判定機（印紙税額一覧表）https://keiri-tools.com/inshi/文書の種類と記載金額から、必要な収入印紙の額を判定。印紙税額の一覧表つき。
  • 消費税・端数処理 計算機https://keiri-tools.com/shohizei/税込・税抜の相互計算と、端数処理の違いを確認。

経理・請求・振込

  • 振込手数料「先方負担」計算https://keiri-tools.com/senpou-futan/請求額からいくら差し引いて振り込むか（振込手数料の先方負担）を計算。
  • 振込名義カナ変換（全銀フォーマット）https://keiri-tools.com/zengin-kana/受取人名を、全銀フォーマットで使える半角カナと法人略語に一括変換。
  • 支払サイト・支払日計算https://keiri-tools.com/shiharai-site/「月末締め翌月末払い」などの条件から支払日を一覧化。土日祝の営業日調整つき。
  • 日数計算・営業日計算https://keiri-tools.com/eigyobi/期間の日数、「◯営業日後」の日付、期間内の営業日数を計算。
  • インボイス登録番号チェック（一括）https://keiri-tools.com/invoice-bangou/請求書のインボイス登録番号をまとめて貼り付け、形式を一括で検証。
  • 減価償却費の計算機（定額法・定率法）https://keiri-tools.com/genka/取得価額・耐用年数・償却方法から、毎年の減価償却費（償却スケジュール）を計算。
  • 利益率・原価率 計算（売価の逆算）https://keiri-tools.com/riekiritsu/原価と売価から粗利率・原価率を計算し、目標の粗利率から売価を逆算。
  • 電帳法 索引簿テンプレート（無料DL）https://keiri-tools.com/denchoho-index/電子帳簿保存法の検索要件に合わせた索引簿のテンプレート。記入例・書き方の解説つき。

給付金・手当

  • 失業保険（基本手当）計算機https://keiri-tools.com/kihonteate/離職時の年齢・給料・勤続年数・退職理由から、失業保険の日額・給付日数・総額の目安を計算。
  • 傷病手当金 計算機https://keiri-tools.com/shobyo/病気やケガで働けないときの傷病手当金の日額・支給日数・合計額を計算。
  • 出産手当金 計算機https://keiri-tools.com/shussan/産休中に健康保険から出る出産手当金を計算。
  • 育児休業給付金 計算機https://keiri-tools.com/ikuji/育休中に受け取る育児休業給付金を、支給の単位期間ごとに計算。
  • 高額療養費 計算機https://keiri-tools.com/kogaku-ryoyohi/ひと月の医療費が高額になったとき、自己負担の上限と戻ってくる額を計算。

補助金

  • 補助金の検索（締切が近い順）https://keiri-tools.com/hojokin/いま公募中の補助金を、締切が近い順に探せます。都道府県・従業員数などで絞り込み。
  • 補助金の経理・税務（圧縮記帳）https://keiri-tools.com/hojokin-zeimu/補助金をもらったときの圧縮記帳（圧縮限度額・仕訳・減価償却）を計算。

計算ウィジェットの埋め込み

リンクのほかに、手取り・社会保険料・源泉徴収税額などの計算機を、ご自身のページの中にそのまま表示することもできます。コードをコピーして貼るだけです。詳しくは計算ウィジェットを、あなたのサイトに埋め込むをご覧ください。
