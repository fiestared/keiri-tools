この表の前提

  • 賞与なしとして、年収を12等分した額を毎月の給与として計算しています。賞与があると源泉徴収の計算式が別（賞与の税額表）になるため、同じ表には混ぜられません。
  • 東京都・40歳・独身（扶養なし）・給与収入のみ。健康保険は協会けんぽ東京都の料率、介護保険料を含みます。
  • 所得税は毎月の源泉徴収額（甲欄）で、年末調整や各種控除は反映していません。
  • 住民税はこの年収が前年も続いた場合の概算です（住民税は前年の所得で決まります）。

扶養・年齢・都道府県・賞与を自分の条件で入れて計算したい場合は手取り計算機をお使いください。住民税だけを詳しく見るなら住民税の計算があります。
