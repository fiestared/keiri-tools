年収400万円の手取りはいくら？

令和8年分の所得・東京都・40歳・独身（扶養なし）・給与収入のみで計算／数字は当サイトの計算コアから算出

年収400万円（東京都・40歳・独身）の場合、社会保険料が約632,000円、住民税が172,300円です。 年収からこの2つを引くと約3,195,700円になります（所得税は別途かかります）。

住民税（所得割＋均等割・森林環境税）− 172,300円
差引3,195,700円

所得税はこの表に含めていません（扶養や各種控除で人により大きく変わるためです）。所得税まで含めた手取りは手取り計算機で計算できます。

年収が25万円増えると、手取りはいくら増えるか

年収を400万円から425万円に上げると、上の差引額は 196,650円増えます（増えた年収25万円のうち、53,350円が 社会保険料と住民税の増加分です）。

逆に375万円と比べると、差引額は196,250円多くなっています。

この計算の前提

  • 東京都・40歳・独身（扶養なし）・給与収入のみ・賞与なしとして年収を12等分
  • 社会保険料は協会けんぽ東京都の料率による概算です。実際は標準報酬月額の等級で決まります
  • 住民税は令和8年分の所得にもとづく計算（＝令和9年度に納める住民税）。均等割は標準税率
  • 所得税は含めていません
手取り計算機所得税まで含めて計算します 住民税 計算機所得割・均等割の内訳を出します 年収400万円の住民税住民税だけを詳しく

この計算は一般的な条件による目安であり、個別の税額を保証するものではありません。実際の金額はお住まいの市区町村・勤務先の給与担当にご確認ください。
