厚生年金基金とは｜代行・上乗せの仕組みと解散後の受け取り先・確認方法

公開日: 2026年10月18日

文責: Masahiro Yasu（クリニック・EC事業の経営者／経理実務者）

厚生年金基金は、老齢厚生年金の報酬比例部分の一部を国に代わって支給し、独自の年金を上乗せする企業年金制度です。

加入していた人の受け取り先は、基金の存続・解散・代行返上と、企業年金連合会への引継ぎの有無で変わります。まず基金名と通知書を確認し、受け取り先の表で照会先を整理します。

基金の状態別に確認する受け取り先

代行部分と上乗せ部分を分けて確認します。基金が解散したからといって、代行部分まで一緒に消えるわけではありません。

厚生年金基金の代行部分は老齢厚生年金の一部で、国や企業年金連合会から代行部分を受ける際も、老齢厚生年金と同じ受給要件や支給停止の調整を受けます。上乗せの支給内容は、基金・移行先の規約や移換内容によって確認します。

基金の状態別に確認する受け取り先
基金の状態代行部分上乗せ・残余財産
存続している基金基金から支給。平成26年3月31日までに連合会へ基本部分の支給義務の移転の申出があった人は連合会へ確認基金へ照会。連合会へ移された原資があれば通知書も確認
平成26年3月31日以前に解散した基金企業年金連合会の代行年金残余財産分配金を本人の選択で連合会へ移換した人には通算企業年金
平成26年4月1日以後に解散した基金最低責任準備金を国へ納付し、国の老齢厚生年金として支給残余財産分配金があり、本人が連合会への移換を選んだ場合は通算企業年金
代行返上して確定給付企業年金へ移行した基金最低責任準備金を国へ納付し、国の老齢厚生年金として支給移行先の企業年金の規約・通知を確認

最低責任準備金が国に納付される場合、既に基金の年金を受けていた人は、過去期間分の返上の認可日の翌月分から、代行部分を含む国の老齢厚生年金に切り替わります。

残余財産分配金は、解散した基金に残った財産の分配です。解散前の上乗せ年金が、そのまま連合会へ引き継がれるとは限りません。分配金の有無と、受領・移換の選択内容は基金からの案内で確認します。

根拠は、日本年金機構「厚生年金基金加入期間がある方の年金」と、企業年金連合会「厚生年金基金から企業年金連合会への移転・移換」です。

代行部分と上乗せ部分の仕組み

基金が支給する年金には、国の老齢厚生年金の一部である代行部分と、基金が独自に給付するプラスアルファ部分があります。基金からの支給額を、国の年金に丸ごと追加される額と考えると二重に数えてしまいます。

基金等が代行給付の支給義務を持つ間は、基金加入員期間にかかる代行部分を差し引いた老齢厚生年金が国から支給されます。スライド・再評価部分は国が支給し、代行返上などで最低責任準備金が国に納付されると、代行部分も国の年金に戻ります。

保険料も国と基金に分かれる

基金に加入している事業所は、厚生年金保険料から免除保険料を除いた額を国に納め、基金には免除保険料と上乗せ部分の掛金を納めます。免除保険料は、代行給付の費用として基金が預かる保険料です。

給与の控除を確認するときは、国へ納める分と基金へ納める分を分け、勤務先の基金の掛金表と照合します。従業員の負担額を、一般の厚生年金保険料に基金掛金をそのまま足して求めることは避けます。

一般の健康保険・厚生年金保険料を確認する → 社会保険料ツール

上のツールは厚生年金基金の加入員を対象外としています。基金加入員の控除額は勤務先・基金に確認してください。

新規設立は不可。存続基金の現状

厚生労働省の制度案内では、平成25年の法律改正により、平成26年4月1日以降、厚生年金基金の新規設立は認められていません。

改正では存続の基準が厳しくなり、基金の解散や確定給付企業年金への移行が促されました。新規設立ができないことと、存続基金がなくなったことは別です。

厚生労働省「健全化法施行後の厚生年金基金の解散・代行返上の状況」によると、令和7年度末の存続基金数は4基金です。

過去の加入歴を調べる場面では、現在の基金名だけでなく、加入当時の基金名と、その後の解散・移行の通知をたどります。「基金は廃止された」と聞いただけで、受給の確認を終えないようにします。

加入していた人の確認手順

基金名と手元の通知書をそろえ、基金または企業年金連合会へ照会します。連合会は、引き継いだ年金の原資・記録を確認する窓口です。基金加入経験者の記録が、全員分まとめて連合会へ移っているとは限りません。

基金加入員証と引継ぎ通知を探す

基金の加入員証や、企業年金連合会からの「移換完了通知書」「年金の引き継ぎのお知らせ」が手掛かりになります。連合会へ年金原資が移された人には、これらの通知が送られます。

通知書が見つからなくても、転居などで届いていない可能性があります。紛失・不着だけで受給権がないと判断せず、連合会の年金記録確認の案内から照会・再発行の方法を確認します。

照会で確認される情報を準備する

連合会の記録照会では、次のような情報を確認します。判明している内容と、不明な項目を整理しておくと照会内容を伝えやすくなります。

  • 氏名。結婚などで変わった場合は旧姓も
  • 生年月日と住所
  • 年金手帳や基礎年金番号通知書で分かる基礎年金番号
  • 厚生年金基金の名称と加入員番号など

電話・文書などの照会方法は、企業年金連合会の記録確認ページに掲載されています。記録の確認と年金の請求は別の手続きなので、記録が見つかったら請求先の案内も確認します。

中途退職した人は引継ぎの有無を確認する

中途脱退者とは誰を指すかは、各厚生年金基金の規約で決まります。中途脱退者の基本部分は、平成26年4月1日以降、企業年金連合会への支給義務の移転の申出ができませんが、脱退一時金相当額の移換は可能です。過去の引継ぎは、連合会の移転・移換の案内と通知書で確かめます。

基金が存続していて連合会への引継ぎが確認できない場合は、加入していた基金へ照会します。代行返上して別の企業年金へ移行している場合は、移行先からの案内も探します。

会社で問い合わせを受けたとき

会社側は、加入当時の基金名・加入期間と、解散・移行・引継ぎの案内を整理します。「国の年金に含まれるはず」「連合会からもらえるはず」と推測せず、本人が照会できる資料と窓口を案内します。

退職者からの問い合わせで整理する項目
確認項目確認する資料・案内
どの基金に加入していたか基金加入員証、当時の勤務先・基金名が分かる書類
現在どこが管理しているか基金の解散・代行返上・制度移行の案内、連合会の引継ぎ通知
上乗せ分はどう扱われたか残余財産分配金の案内、受領や移換に関する書類
国からの支給額が変わったか代行返上に伴う日本年金機構の年金額変更通知

受給額や開始時期は、給付の種類と加入記録によって確認します。企業年金連合会の代行年金には、国の老齢厚生年金と同じ受給要件があり、在職や雇用保険との調整で一部または全部が支給停止になる場合があります。

国民年金基金を調べる場合は国民年金基金の解説、保険契約の個人年金を調べる場合は個人年金の税金の解説へ進んでください。厚生年金基金の加入歴の照会とは、参照する制度・書類が異なります。

まとめ

受け取り先を調べる出発点は、基金名と引継ぎ通知です。代行部分と上乗せ部分を分け、基金の解散時期・代行返上・連合会への移換内容を確認します。通知書がない場合も、基金や連合会へ記録を照会できます。

よくある質問

厚生年金基金は厚生年金に上乗せされるものですか？

独自の上乗せ給付に加え、国の老齢厚生年金の報酬比例部分の一部を代行する制度です。基金からの給付額全体を、国の年金に追加される額として数えることはできません。

基金が解散したら年金はなくなりますか？

代行部分は、国または企業年金連合会が支給を引き継ぎます。受け取り先は解散時期で異なり、上乗せの扱いは残余財産の分配・移換内容によるため、基金の案内と通知書を確認します。

企業年金連合会から通知が来ていません。加入していなかったのでしょうか？

通知がないだけでは判断できません。原資が連合会へ移っていない場合や、転居などで通知が届かなかった場合があるため、基金の加入員証や勤務先・基金名を手掛かりに照会します。

短期間の加入でも年金を受け取れますか？

給付の種類と引継ぎ内容によります。連合会の代行年金は国の老齢厚生年金と同じ受給要件であり、在職・雇用保険との調整による支給停止もあるため、加入期間だけでは受給を判断できません。
