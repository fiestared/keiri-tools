FXの税金：分離課税の対象取引・スワップ・必要経費・繰越損失を検算

公開日: 2026年10月17日

文責: Masahiro Yasu（クリニック・EC事業の経営者／経理実務者）

居住者が行う対象FXの差金等決済による所得は、給与などと分ける申告分離課税です。税額を計算する前に、当年の決済損益・収入に入るスワップ・必要経費・使える繰越損失をそろえます。

ここでいう対象FXは、金融商品取引法上の市場デリバティブ取引、または第一種金融商品取引業者・登録金融機関を相手方とする店頭デリバティブ取引のうち、現物受渡しを伴わないFXです。法人・非居住者の計算は扱いません。

分離課税になる取引・ならない取引

「国内か海外か」という呼び名だけで決めず、契約相手の登録区分と取引の内容を確認します。国税庁No.1521は、対象の市場・店頭デリバティブ取引と、それ以外を区別しています。

居住者のFXの課税区分
取引の区分所得の扱い
対象FXの差金等決済先物取引に係る雑所得等として申告分離課税
上の対象に当たらないFX一般的には雑所得の総合課税。対象FXの損益とは通算不可

現物受渡しを伴う取引はこの特例の対象外です。暗号資産の証拠金取引も同じ枠に入れません。詳しくは暗号資産の税金で区別しています。

所得から税額までの計算例

経費を引いた所得に、いきなり税率を掛けるとは限りません。有効な繰越損失を控除し、所得控除の残額があれば反映した後の課税所得で計算します。

令和8年分の居住者の対象FXだけを計算する設例です。ほかの先物損益はなく、所得控除は給与所得等で使用済み、税額控除・高額所得への追加課税はありません。繰越損失は本年控除可能なものとし、住民税は当該所得に対応する年度の所得割だけを示します。

令和8年分・対象FXの設例：所得と課税所得

当年の収入に計上するスワップ20万円
当年の必要経費20万円（報告書の損益から未控除の分）
繰越控除前の所得300万円＋20万円−20万円＝300万円

次も同じ令和8年分・居住者の対象FXの設例で、所得控除は使用済み、税額控除等はありません。繰越損失控除後の課税所得を使い、住民税は所得割のみです。税率の根拠は国税庁No.1522です。

この設例は端数が出ない金額にしています。実際の納付額は申告書の端数処理や他の所得・控除で変わり、住民税の均等割・森林環境税も上の合計に含めていません。

令和8年分の対象FXの課税所得に対する税率を単純合計すると20.315%ですが、これは収入総額に掛ける率ではありません。後の年分の内訳は上の出典で確認してください。

スワップと必要経費の確かめ方

スワップは出金の有無だけで決めない

スワップを口座から引き出していなくても、それだけで当年の収入から外せるとは限りません。別段の定めがある場合を除き、その年に収入すべき金額を計上するのが所得税法の収入金額の定めです。

年間取引報告書のスワップ欄と、取引先の受払・振替条件を照らし合わせます。建玉の決済時に確定するのか、建玉を残したまま受け取れるのかを確認し、未決済建玉の評価損益と混同しないようにします。

ここでは通常の収入計上を扱います。現金主義の特例を適用している場合などは別途確認が必要です。スワップの具体的な権利確定日は契約条件によるため、この記事で一括判定しません。

経費は品名より用途と記録を確認する

FXの必要経費は、FX収入を得るため直接に要した費用や、その業務について生じた費用から確認します。所得税法の必要経費の定めは、別段の定めがある場合を除き、償却費以外はその年に債務が確定した費用を対象にしています。

取引手数料は、報告書の決済損益に既に織り込まれていないかを先に確認します。パソコン・通信費・書籍代などは、購入しただけで全額を当年の経費にできるわけではありません。用途・業務との関係・償却の要否を確かめ、領収書と計算根拠を残します。

私生活の支出は区別します。家事上の経費等の不算入には所得税法の別の定めがあり、自宅の通信費などの全額算入をここで保証するものではありません。

損益通算と損失繰越の手続き

対象FXの損失は、同じ年のほかの「先物取引に係る雑所得等」と通算できます。給与・株式の譲渡所得・暗号資産の雑所得など、別の所得群とは通算できません。別口座のFXでも、分離課税の対象外なら同じ枠に混ぜません。

通算しても引き切れない先物取引の損失は、必要書類を添付する連続申告の要件を満たせば、翌年以後3年間、各年の先物取引に係る雑所得等の金額を限度に控除できます。先物取引について前年以前3年以内の複数年に損失があるときは、最も古い年分から順に控除します。

先物取引の損失繰越控除を受けるための手続きです。付表とは「所得税及び復興特別所得税の申告書付表（先物取引に係る繰越損失用）」、計算明細書とは「先物取引に係る雑所得等の金額の計算明細書」を指します。出典は国税庁No.1523です。

取引をしない年も連続申告を途切れさせないことが必要です。雑損失の繰越控除もある場合は、先物取引の損失繰越控除を先に行います。

申告前にそろえる資料

まず対象FXの各口座の年間取引報告書、当年の経費の記録、前の年の繰越損失の付表をそろえます。報告書の合計と計算明細書の数字を照らし、手数料やスワップの二重計上を避けます。

先物取引に係る雑所得等について確定申告する場合は、計算明細書の添付が必要です。様式は国税庁の手続き案内から開けます。

申告が必要かどうかは、FXだけでなく給与などの状況と合わせて確認します。給与所得者の副収入と申告不要の要件、所得別の申告要否で整理しています。所得税の申告不要と住民税の申告は別に確認します。

よくある質問

FXの損失を株式の利益から引けますか？

引けません。対象FXの損失を通算できるのは、同じ「先物取引に係る雑所得等」の範囲です。株式の譲渡所得とは分けて計算します。

取引をしなかった年は、損失繰越の申告を省けますか？

先物取引の損失繰越控除を受けるには省けません。損失年に必要書類を添付して申告した後も、付表を添付した確定申告を連続して提出する必要があります。控除を受ける年には計算明細書も添付します。

スワップを出金しなければ収入に入れなくてよいですか？

出金していないことだけでは決まりません。別段の定めがある場合を除き、その年に収入すべき金額かどうかを、受払・振替条件と年間取引報告書で確認します。
