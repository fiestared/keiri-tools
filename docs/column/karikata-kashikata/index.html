借方・貸方とは？左右の覚え方と増減の早見表・仕訳の基本

公開日: 2026年10月24日

文責: Masahiro Yasu（クリニック・EC事業の経営者／経理実務者）

借方（かりかた）は左、貸方（かしかた）は右です。取引を記録するときは、勘定科目の性質と、その科目が増えたか減ったかで左右を決めます。

現金が増えたら借方、減ったら貸方。ただし、売上の発生は貸方です。「借方＝入金、貸方＝出金」と覚えると、現金以外の科目で迷います。まず下の早見表で分類を確かめ、取引例に当てはめてください。

借方・貸方の増減早見表

通常の勘定では、資産と費用は増えたら左、負債・純資産・収益は増えたら右に記入します。減少や取消しは反対側です。

次の表は通常の勘定の記入法則です。純資産のうち自己株式などの控除項目、資産から差し引く減価償却累計額などは、科目固有の性質も確認します。

勘定の分類と記入する側
分類科目の例借方（左）貸方（右）
資産現金・普通預金・売掛金・備品増加減少
負債買掛金・借入金・預り金減少増加
純資産資本金・利益剰余金減少増加
収益売上・受取利息減少・取消し発生・増加
費用仕入・給料手当・支払利息発生・増加減少・取消し

資産は会社が持つ財産や権利、負債は支払いや返済などの義務です。純資産は資産から負債を差し引いた残りで、手元の現金の額とは違います。収益は売上など、費用はその収益を得るために消費した価値などを表します。

国税庁の「記帳のしかた及び帳簿の保存」にも、この記入法則が載っています。同資料の個人事業の「資本（元入金）」に対し、会社の貸借対照表では会社計算規則の貸借対照表の区分にある「純資産」という言葉を使います。

左右の覚え方と間違いやすい点

左右は「かりかた」の「り」が左へ払い、「かしかた」の「し」が右へ払う、と結び付けると覚えやすくなります。これは位置を覚えるための補助です。実際の仕訳では早見表の増減を使います。

借方に書くことが「お金を借りた」という意味ではありません。現代の簿記では、借方・貸方を記入位置の名前として捉えます。語源を知りたい場合は、神戸大学の「借方」と「貸方」の解説に、債権・債務の記録から広がった経緯が紹介されています。

現金の入出金と、収益・費用を分ける

借入で預金が増えても、その入金は売上ではありません。返済義務が生まれたので、相手科目は借入金です。売掛金の回収も、すでに売上を記録していれば、回収時にもう一度売上を立てません。

預金から給与を支払い、その時に初めて費用計上する場合は、借方に給料手当、貸方に普通預金や預り金を記入します。未払計上済みの給与を支払うときは、借方は未払費用などの負債の減少です。「お金が出るから取引全体が貸方」とは考えません。

貸方にある科目が負債とは限らない

売上は貸方に発生しますが、負債ではなく収益です。また、間接法で記録する有形固定資産の減価償却累計額は、資産から差し引くための勘定です。これも負債ではありません。表示の扱いは会社計算規則の有形固定資産に対する減価償却累計額の表示で確認できます。

科目が分からないときは勘定科目一覧へ進み、分類を確かめてから左右を決めます。

仕訳で迷ったときの手順

  1. 取引の中身を言葉にする。何を売ったか、受け取ったのは現金か預金か、支払いがまだなのかを確認します。
  2. 使う科目を選ぶ。現金・売掛金・買掛金など、変わった財産や義務を拾います。
  3. 分類と増減を決める。資産か負債か、増えたか減ったかを早見表に当てはめます。
  4. 左右に記入して合計を比べる。科目数ではなく金額の合計を合わせます。摘要には取引相手や内容を残します。

現金や預金の動きが分かる取引なら、その科目から考えると整理しやすくなります。ただし、合計を合わせるために、根拠の分からない科目を入れるのは避けてください。請求書・契約書・通帳などで取引内容を確認します。

取引別の仕訳例

以下は会社の記入方向を学ぶための架空の設例です。金額をそのまま実務の税額や保険料として使うものではありません。

現金売上

設例では税込経理・三分法で商品を現金売上し、13,000円を受け取ったと仮定します。

現金売上の設例（単位：円）
借方科目借方金額貸方科目貸方金額
現金13,000円売上13,000円

現金という資産の増加が左、売上という収益の発生が右です。売上原価や棚卸の処理は、この売上仕訳とは分けて考えます。

掛け売上

設例では税込経理・三分法で商品を21,000円で掛け売上したと仮定します。

掛け売上の設例（単位：円）
借方科目借方金額貸方科目貸方金額
売掛金21,000円売上21,000円

まだ代金を受け取っていなくても、売上を計上する段階では売掛金という権利が増えます。後日の回収は、現金・預金の増加と売掛金の減少として記録します。

仕入

設例では税込経理・三分法で商品を17,000円で掛け仕入れしたと仮定します。

仕入の設例（単位：円）
借方科目借方金額貸方科目貸方金額
仕入17,000円買掛金17,000円

仕入を借方、買掛金という負債の増加を貸方に記録します。三分法は仕入・売上・繰越商品を使う方法です。期末には棚卸による売上原価の調整があります。

給与

給与を支払時に初めて費用計上する設例で、控除前総額260,000円、本人負担分等の控除35,000円、振込225,000円と仮定します。

給与の設例（単位：円）
借方科目借方金額貸方科目貸方金額
給料手当260,000円預り金35,000円
——普通預金225,000円

給与費用は控除前の総額で記録します。本人から預かった分は預り金という負債、実際に振り込んだ分は預金の減少です。会社負担保険料の計上は別の仕訳で行います。

借入

設例では借入による入金600,000円を普通預金で受け取り、差引手数料なしと仮定します。

借入の設例（単位：円）
借方科目借方金額貸方科目貸方金額
普通預金600,000円借入金600,000円

預金が増えるので借方、返済義務が増えるので貸方です。収益を得た取引ではないため、借りた金額を売上にはしません。

返済

設例では元本40,000円と当期分の利息800円を預金から支払い、手数料なし、合計40,800円と仮定します。

返済の設例（単位：円）
借方科目借方金額貸方科目貸方金額
借入金40,000円普通預金40,800円
支払利息800円——

元本と利息を分けます。元本は借入金という負債の減少なので借方、利息は費用の発生なので借方です。返済額をまとめて費用にしない点が実務上の注意です。

減価償却

設例では有形固定資産の備品について当期償却額が24,000円と確定済みとし、間接法で記録すると仮定します。

減価償却の設例（単位：円）
借方科目借方金額貸方科目貸方金額
減価償却費24,000円備品減価償却累計額24,000円

減価償却費の発生を借方、備品の価額を差し引く累計額を貸方に置きます。購入時の現金支払いとは別の処理なので、この仕訳では現預金は動きません。償却額の算定自体は扱いません。

前払い

設例では保険料36,000円が全額翌期分に対応し、短期前払費用の税務特例は使わず、支払時に資産計上する仮定です。

前払いの設例（単位：円）
借方科目借方金額貸方科目貸方金額
前払費用36,000円普通預金36,000円

支出した時点の仕訳は、前払費用という資産の増加と預金の減少です。役務を受けた期間に費用へ振り替えます。勘定名に「費用」があっても、前払費用は資産に分類される点に注意します。

商品の例は消費税額の区分計上を省いた税込経理です。実際の科目名や摘要は会社の運用に合わせ、税区分や証憑も別に確かめます。小口の支払いは小口現金の記事で扱います。

貸借が一致する理由と検算の限界

複式簿記では、同じ取引を財産や義務の変化、その原因などに分け、借方と貸方に等額で記録します。正しく作った仕訳では借方合計と貸方合計が一致し、その記録を正しく転記・集計すれば全体の合計も一致します。これを貸借平均の原理と呼びます。

同じ側に科目が複数あってもかまいません。給与や返済の設例のように、片側の内訳を足した合計で比べます。「借方の科目と貸方の科目が同じ数だけ必要」という規則ではありません。

貸借の一致は、内容まで正しいという証明ではありません。売上の仕訳を借方・貸方とも記入し忘れたり、同じ仕訳を重ねて入れたりしても、左右の合計は合ったままです。科目を取り違えた場合も、合計だけでは見つかりません。

合計の検算に加え、通帳や請求書との突合、売掛金・買掛金の相手先別残高の確認が必要です。差額から転記漏れなどを探す手順は試算表の見方にまとめています。

仕訳帳・元帳・試算表へのつながり

取引を発生順に並べるのが仕訳帳、科目ごとに集め直すのが総勘定元帳です。元帳の借方・貸方の合計や残高を一覧にして確認するのが試算表です。

現金残高は、期首または前月からの繰越残高に、その期間の借方の増加額を足し、貸方の減少額を引いて求めます。費用・収益も含む各科目を試算表で確かめ、必要な決算整理を加えたうえで決算書へ進みます。記入欄や保存のルールは仕訳帳の書き方、転記の実例は総勘定元帳の書き方を参照してください。

なお、仕訳の左右と決算書の見た目は分けて考えます。損益計算書には収益・費用を縦に並べる報告式があり、「左が費用、右が収益」とは限りません。会社計算規則の損益計算書等の区分は表示する項目を定めています。決算書の読み方は損益計算書の記事へ進んでください。

仕訳に使った証憑の管理に：電帳法 索引簿メーカー

まとめ

借方は左、貸方は右。科目を選び、その分類と増減を早見表に当てはめれば、記入する側を決められます。

記入後は左右の金額の合計を確認し、さらに証憑や残高と照合します。左右が一致していても、記帳漏れや科目の取り違えは残るためです。

よくある質問

借方と貸方はどう違いますか？

借方は左側、貸方は右側の記入位置です。借入や貸付を表す語として判断せず、科目の分類と増減で左右を決めます。

売上は借方ですか、貸方ですか？

売上の発生は貸方です。現金売上なら借方に現金、掛け売上なら借方に売掛金を記録します。返品や取消しでは反対方向の処理になります。

費用の発生は借方ですか、貸方ですか？

費用の発生は借方です。現金や預金で同時に払う場合は、その資産の減少を貸方に記録します。支払時点で費用が発生しない前払いや、未払計上済みの費用の支払いは、資産や負債の動きとして記録します。

借方と貸方の金額が合っていれば正しいですか？

金額の一致だけでは正しさを確認できません。取引を両側とも記入し忘れた場合や、同じ仕訳を重複して記録した場合は、合計が一致していても帳簿に誤りが残ります。

次に読む

予実管理とは？月次の進め方・差異分析とExcel表の作り方予実管理の月次表と差異分析を整理。売上・費用の架空例、数量・単価への分解、Excelの式から翌月の改善まで確認できます。労務費とは？人件費との違い・内訳と計算製造原価の労務費は、製造に関わる人の人件費です。賃金・賞与・会社負担の社会保険料などの内訳、販管費との区分、直接工の手待時間の扱いを表で確認。直接労務費と労務費率の月次計算例も示し粗利とは？粗利率の計算式・売上原価の出し方粗利は売上高から売上原価を引いた売上総利益です。粗利率の分母は売上高。商品売買業の期首棚卸・仕入・期末棚卸を使う計算例と、営業利益との違い、決算書で拾う数字を確認できます。
