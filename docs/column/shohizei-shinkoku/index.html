消費税申告のやり方｜個人・法人の期限と提出書類の確認表

公開日: 2026年10月24日

文責: Masahiro Yasu（クリニック・EC事業の経営者／経理実務者）

消費税申告では、第一表・第二表のほか、方式別の付表や還付内容に応じた明細書等を提出します。申告とは別に、納付の手続きも行います。

このページは、国内取引の消費税申告を準備する課税事業者向けの確認表です。申告義務や課税方式の選択を個別に判定するものではありません。

個人・法人の申告期限

通常の確定申告の期限は次のとおりです。申告期限・納期限が土日祝日等に当たる場合は翌開庁日となります。災害等による期限延長を受ける場合は、指定された期限を確認してください。

消費税・地方消費税の確定申告と納付の期限
区分期限
個人事業者（死亡に伴う申告を除く）12月31日を含む課税期間は、翌年3月31日まで
法人（申告期限延長・清算時の残余財産確定を除く）課税期間の末日の翌日から2か月以内

主な例外：死亡に伴う申告、清算時の残余財産確定、課税期間の短縮、期限延長です。個人の短縮した課税期間のうち年末を含まない期間は、上表の個人の期限とは異なります。各期限は国税庁「申告と納税」で確認できます。

法人税の申告期限を延長していても、消費税の延長を自動で扱わず、消費税の届出と対象の課税期間を確認します。延長された期間の納付には利子税の取扱いもあるため、国税庁「法人に係る消費税の確定申告書の提出期限について」を確認してください。

提出書類と様式の選び方

最初に課税期間の開始日と、適用する課税方式を確認します。申告書をダウンロードした日で様式を選ぶのではありません。

課税期間を短縮していない個人事業者の令和8年分申告は、「令和8年9月30日以前に開始した課税期間用」を使います。法人は申告する課税期間の開始日を、国税庁の申告書・添付書類の様式一覧の区分と照らしてください。

以下は標準税率又は軽減税率が適用された取引だけで、旧税率の取引がない場合の基本書類です。一般用・簡易課税用は、適用する課税方式に合わせて選びます。個別の調整に用いた付表・計算表や、その他参考となる事項は別途確認してください。

課税方式別の申告書と付表
適用する方式申告書基本となる付表
一般課税一般用の第一表・第二表付表1-3・付表2-3
簡易課税簡易課税用の第一表・第二表付表4-3・付表5-3

2割特例の適用要件を満たして申告する場合は、第一表・第二表と付表6を確認します。簡易課税制度選択届出書の提出の有無により、様式一覧で指定された第一表を選んでください。

特例の適用対象・期間は小規模事業者の特例の解説へ。旧税率の取引がある場合の付表は、上記の国税庁の様式一覧で確認してください。

還付になる場合の追加書類

控除不足還付税額がある場合は、消費税の還付申告に関する明細書を添付します。中間納付還付税額だけの還付申告書には、この明細書の添付は必要ありません。

根拠は国税庁「確定申告書等に添付することとなる書類」です。還付の対象や手続きの詳しい区別は、消費税の還付申告で確認できます。

消費税計算ツールで計算方法を確認する →

計算ツールは申告書の作成・送信や、適用方式の判定を行うものではありません。

電子申告・郵送・持参の経路

個人と法人では、電子申告の作成入口が異なります。電子申告義務化の対象法人は、申告書に添付すべき付表も含めてe-Taxで提出します。

申告書の作成・提出経路
経路確認すること
個人の電子申告確定申告書等作成コーナーで対応する申告内容かを確認する
法人の電子申告e-Taxソフトなど、法人の消費税申告に対応した作成・送信環境を確認する
郵送（紙提出ができる場合）郵便又は信書便で、所轄税務署又は指定の業務センターへ送る
持参（紙提出ができる場合）納税地を所轄する税務署に申告書と必要な添付書類を提出する

個人でも申告内容により作成コーナーを使えない場合があります。法人向けを含むソフトの対応範囲はe-Tax「ご利用の流れ」、付表の電子提出義務はe-Taxの義務化Q&Aで確認できます。

送信したら、受信通知まで確認する

e-Taxでは、データ送信後に受信通知を確認し、正常に提出できたかを確かめます。送信直後の完了画面は形式的なチェックの結果で、申告内容が正しいという税務上の審査結果ではありません。

受信通知の格納に時間がかかる場合は、再送信せず、時間を置いてメッセージボックスを確認します。申告データと受信通知を保管し、納付の手続きへ進んでください。

紙で提出する場合は、控えと提出年月日の記録を自社で保管します。郵便又は信書便で送付する申告書は、通信日付印に表示された日を提出日とみなします。控えへの収受日付印を前提にせず、郵送先・郵便又は信書便の扱いを国税庁「申告書の提出」で確認してください。

中間申告と中間納付税額の確認

確定申告の前に、中間申告で納付すべき税額の記録を集めます。中間申告の対象・回数の確認には、直前の課税期間の長さと、地方消費税を除いた確定消費税額を使います。

課税期間の特例を適用している場合や、災害等の期限延長によって中間申告と確定申告の期限が同日となる場合などは、取扱いが異なります。基準・回数と任意の制度は、中間申告の解説にまとめています。

消費税申告で確認する中間申告の記録
確認物確認内容
中間申告の記録対象となる課税期間と、国税・地方消費税それぞれの納付すべき税額
確定申告書の中間納付税額欄実際に支払った税額ではなく、中間申告の際に納付すべき消費税額を記載する
納付の記録未納がないかを別に確認する。確定申告の控除と支払実績を混同しない

中間申告義務のある事業者は、期限までに提出しなくても前期実績による申告があったものとみなされます。提出しなかったから納付が不要になる、とは扱えません。

仮決算による中間申告を行う場合は、申告期限内に、確定申告書の様式と必要な明細を用意します。仮決算の中間申告では2割特例を使えません。仮決算でも簡易課税の適用があり、計算した税額がマイナスでも中間申告による還付は受けられません。詳細は国税庁「中間申告の方法」を確認してください。

提出前から納付までの確認順序

申告書を作ったところで作業を終えず、必要な付表の提出、受付確認、納付まで確かめます。

  • 課税期間と方式に合う様式を選び、必要な添付書類をそろえる。
  • 確定申告書の中間納付税額欄を、中間申告で納付すべき税額と照合する。
  • 電子申告は受信通知、紙申告は控えと提出記録を保管する。
  • 選んだ納付方法で手続きを行い、納付の記録を保管する。

よくある質問

消費税申告は、第一表だけ提出すればよいですか？

第一表に加え、第二表と、適用する方式に応じた付表等が必要です。控除不足還付税額がある場合は還付申告に関する明細書も添付します。

消費税の申告書を送信すれば、納付も終わりますか？

送信とは別に納付の手続きを確認します。e-Taxの受信通知で正常に提出できたかを確かめたうえで、納付方法に応じた手続きを行ってください。

中間納付税額欄には、支払った分を記載しますか？

確定申告書の中間納付税額欄に記載するのは、実際の支払額ではなく、中間申告で納付すべき消費税額です。国税と地方消費税はそれぞれの欄を確認します。
