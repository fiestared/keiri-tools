金融所得課税の改正で変わる追加税額を年分別に検算

公開日: 2026年10月17日

文責: Masahiro Yasu（クリニック・EC事業の経営者／経理実務者）

今回の金融所得課税の改正は、金融所得の税率を一律30%にするものではなく、極めて高い所得の個人に対する追加負担の見直しです。

改正後の算式は2027年分以後の所得税に適用され、2026年分は改正前の算式を使います。基準所得金額が控除額を超えても、比較する基準所得税額によっては追加負担は生じません。

この記事は非永住者以外の居住者を対象に、追加税額の算式と申告時の確認事項を整理します。会社の法人税や、役員・従業員の個別の申告要否を判定する記事ではありません。

何が変わるかを先に確認

見直すのは、基準所得金額から差し引く特別控除額と、控除後の金額に掛ける率です。

表は個人の基準所得金額に対する特例の年分別算式です。特定株式等の調整がない場合は、基準所得税額を上回る差額だけを追加します。基準所得金額・基準所得税額の範囲は下の用語の節にまとめています。

適用する所得税の年分基準所得金額からの控除控除後の基準所得金額に掛ける率
2026年分3億3,000万円22.5%
2027年分以後1億6,500万円30%

適用年分の根拠は、改正法附則47条です。令和9年分以後に新しい規定を適用し、令和8年分以前は従前の例によると定めています。

金融所得だけに別の税率を上乗せする計算ではありません。給与・事業所得や土地建物の譲渡所得なども、法律が定める基準所得金額に含めて判定します。

同じ仮定で追加税額を比較

控除額の引下げと率の引上げがどう効くか、入力を固定して比べます。ここでは収入から通常の税額を計算するのではなく、算式に入れる基準所得金額と基準所得税額が確定した状態を仮定します。

追加税額の比較の仮定は非永住者以外の居住者で、2026年分・2027年分とも基準所得金額10億円、基準所得税額1億6,000万円です。下表は特例の追加税額だけの比較で、税額控除・特定株式等の調整を扱いません。仮定の数値では円未満の端数は生じません。

計算段階（基準所得金額・基準所得税額は上の仮定）2026年分2027年分
基準所得金額から特別控除を引く6億7,000万円8億3,500万円
基準所得金額の控除後の額に、その年分の率を掛ける1億5,075万円2億5,050万円
基準所得税額と比べ、上回る差額だけを追加する追加0円追加9,050万円

住民税・付加税を含む最終年税額や、源泉徴収済みの税額との精算額を示す表ではありません。各年の付加税を含めた基準所得税額そのものも、ここでは同額に固定しています。

改正前の列では、控除後に率を掛けた額が基準所得税額を下回るため、追加はありません。負の差額を、この特例による還付として扱うこともありません。

基準所得金額と基準所得税額を分ける

基準所得金額は、売却代金や年収そのものではありません。給与・事業・不動産などの総合課税の所得と、株式・土地建物・先物取引などの分離課税の所得を、所定の方法で合算する金額です。

主な扱いを次の表に示します。細かな所得区分の全件は、租税特別措置法の「特定の基準所得金額の課税の特例」と国税庁の解説で確認できます。

確認する点基準所得金額への扱い
源泉徴収ありの特定口座の譲渡益・申告不要の配当等申告不要制度を適用しないものとして計算して含める
損失の繰越控除適用した後の金額で計算する
土地等の特別控除適用した後の金額で計算する
非課税となる所得・源泉分離課税の対象所得含めない

「源泉徴収あり」と「源泉分離課税」は別です。前者の口座でも、申告不要の扱いを外して基準所得金額を計算するため、年間取引報告書などを確認する必要があります。

基準所得税額は、追加負担を適用する前の、法定の方法で計算した所得税額です。申告書上の所得税だけでなく、申告不要とした所得に係る源泉徴収税額も確認します。住民税を足した税額とは区別します。

2026年分の特例の基準所得税額には復興特別所得税を含みます。2027年分以後の特例の基準所得税額には、防衛特別所得税と復興特別所得税を含みます。外国税額控除・分配時調整外国税額控除の適用前で計算し、附帯税や源泉分離課税による所得税は除きます。

非永住者・非居住者は課税される所得の範囲が異なるため、本記事の設例の対象外です。特定株式への投資等に関する特別な調整も、設例では扱いません。

特例の適用がある場合の申告

追加税額が生じてこの特例の適用がある場合は、申告不要としていた所得も含めて申告書を作成します。

申告の準備では、総合課税と分離課税の所得を揃え、基準所得金額と基準所得税額を計算してから、年分に対応する算式で比較します。金融機関の天引きだけで申告が完結すると決めつけないことが、確認の出発点です。

特例の適用がある場合、申告書第二表の「特例適用条文等」欄に「措法41の19」と記載します。特例の適用があり、国税庁の適用判定表兼税額計算書を使用した場合は、申告書と一緒に提出します。

特例の適用によって合計所得金額の要件を超えることになる控除は、使えなくなります。基礎控除などの各種控除も、要件を改めて確認します。

通常の口座別の扱いは特定口座と確定申告、配当の課税方式は配当金の確定申告で説明しています。これらの一般的な扱いと、この特例による申告不要制度の制限を分けて確認してください。

総合課税の通常の税額は所得税計算機へ（本記事の追加税額には未対応）
確認する順序

基準所得金額と基準所得税額を分け、対象年分の算式で比較します。追加が生じる場合は申告不要制度と各種控除への影響も確認します。

よくある質問

金融所得だけで対象者を判定できますか？

できません。給与・事業所得や土地建物の譲渡所得なども、法律が定める基準所得金額に含めて判定します。さらに基準所得税額との比較が必要です。

特別控除額を超えたら必ず追加負担がありますか？

追加負担が生じない場合もあります。基準所得金額だけでなく、基準所得税額との比較が必要です。

特定口座で申告不要にした利益も確認しますか？

確認します。基準所得金額は、申告不要制度を適用しないものとして計算します。この特例の適用がある場合は、確定申告不要制度を利用できません。
