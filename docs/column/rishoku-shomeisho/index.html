離職証明書の書き方｜会社向けの欄別記入表・提出期限と添付書類

公開日: 2026年10月24日

文責: Masahiro Yasu（クリニック・EC事業の経営者／経理実務者）

離職証明書は、会社が退職者の賃金と離職理由を記載し、資格喪失届とともにハローワークへ提出する書類です。正式名称は「雇用保険被保険者離職証明書」です。

書くときの要点は、離職日で区切る期間と、給与の締日で区切る期間を分けることです。賃金台帳・出勤簿・雇用契約書を揃え、下の欄別表と照らして記入します。

本稿は一般被保険者・高年齢被保険者の会社側の作成手順を扱います。短期雇用特例・日雇・マルチジョブホルダーは対象外です。本人の「いつ届く・届かない・異議」は離職票の記事で確認できます。

提出期限と作成が必要な場合

退職による雇用保険の資格喪失届と離職証明書の提出期限は、退職日の翌々日から起算して10日以内です（末日が土日祝・年末年始の行政機関の休日なら翌開庁日）。提出先は、事業所の所在地を管轄するハローワークです。

根拠は雇用保険法施行規則7条と行政機関の休日に関する法律2条です。本人の受給手続きが完了する期限ではありません。

次の表は、離職日の年齢と本人の離職票交付希望に応じた添付の取扱いです。

本人の希望・年齢離職証明書の扱い
離職票を希望する被保険者資格喪失届に添えて提出する
離職日に59歳未満で、本人が離職票を希望しない添付を省略できる。資格喪失届は提出する
離職日に59歳以上の被保険者本人が離職票を希望しなくても添付する

「次の就職先が決まっている」「勤続期間が短い」だけで、会社が不要と決めないようにします。本人の希望を確認し、記録を残します。

不希望として添付しなかった後、まだ離職証明書を提出していなければ、本人から離職票請求のため交付を求められたときに交付します（雇用保険法施行規則16条）。

欄別の書き方早見表

この表は一般被保険者・高年齢被保険者で、毎月の締日がひとつの給与を扱います。帳票の欄番号と手元の記録を対応させます。紙の標準用紙は3枚複写で、事業主控・安定所提出用・離職票－2が組になっています。紙の用紙はハローワークで入手し、公開された記載例は見本として使います。

欄記入する内容主に照合する記録
①〜③被保険者番号・事業所番号・離職者氏名資格取得時の確認通知書・被保険者証
④ 離職年月日退職日。資格喪失日と取り違えない資格喪失届・退職の記録
⑤・⑥事業所名・所在地・電話番号、離職者の住所または居所・電話番号事業所情報・本人への確認
⑦ 離職理由主たる理由と具体的事情を記載（個人的事情は本人から把握している範囲）退職願・契約書・就業規則等
⑧・⑨離職日を基準にした期間と、その賃金支払基礎日数在籍記録・出勤簿・賃金台帳
⑩・⑪・⑫賃金締日を基準にした期間・基礎日数・賃金額給与規程・出勤簿・賃金台帳
⑬・⑭欠勤・未払い等の備考。特別の賃金の記入範囲は下の「賃金額」で確認休業記録・手当の支払記録
⑮・⑯⑮は離職理由以外の記載内容の確認、⑯は離職理由への本人の判断（確認できないやむを得ない場合は代替記載）本人への説明・確認

⑤欄では、法人でない事業主の名称・氏名から判別できない屋号等も記載します。事業所の所在地・電話番号で事務担当者に連絡がつかない場合、事業主の住所・電話番号も併記します（現行の業務取扱要領）。欄別の見本は東京ハローワークの手引きで確認できます。

期間と必要月数の数え方

⑧と⑩は、同じ行でも期間が異なることがあります。一般被保険者・高年齢被保険者で締日が毎月ひとつの給与は、⑧を離職日、⑩をその締日で区切ります。給与支払日で区切る欄ではありません。

締日が複数のときは月末に最も近い日、締日がないときは月末を基準に、⑩の賃金支払対象期間を記入します。

次は名古屋南ハローワークの記載例にある、令和5年7月22日退職・月末締めの設例から、期間だけを抜き出した表です。

行⑧ 離職日を基準にする期間⑩ 賃金締日を基準にする期間
最上段6月23日〜7月22日7月1日〜7月22日
その下5月23日〜6月22日6月1日〜6月30日

この設例では⑩の最上段は月の途中までなので、完全月に含めません。入社月も途中からの加入なら、資格取得日より前には遡りません。離職日の翌日に応当する日がない月の⑧欄は、その月の末日を使います。

通常の記入月数

この表は船員の変動賃金を対象外とし、一般被保険者・高年齢被保険者の通常の記入範囲を示します。表の完全月は、対象期間がひと月あり、賃金支払基礎日数が11日以上ある月です。不足・休業等の主な例外は表の下にまとめます。

対象と欄遡る範囲と記入の目安
一般被保険者の⑧・⑨離職前2年間で、完全月12か月に達するまで
高年齢被保険者の⑧・⑨離職前1年間で、完全月6か月に達するまで
⑩・⑪・⑫賃金締日で区切った完全月6か月を記入する

基礎日数が少ない月を飛ばして、都合のよい月だけを並べる記入はしません。欄が足りなければ続紙を使います。被保険者期間の不足だけを理由に、作成を見送ることも避けます。

主な例外：傷病・出産等による長期無給や全休業等では、通常と異なる範囲の記入が必要になる場合があります。育児・介護の休業や短時間勤務がある特定受給資格者は、別の賃金証明が必要になることもあるため、記録を揃えて管轄へ確認します。

日数基準で月数が足りないとき

令和2年8月1日以降の離職で日数基準の月数が不足する場合、⑨・⑪が11日未満の期間の賃金支払基礎時間数を⑬欄へ記載し、80時間以上の完全月も確認します（例外は下の注）。

単に出勤した時間ではなく、賃金支払の基礎となった時間数を使います。受給資格・賃金日額に影響しないことが明らかな期間は、時間数の記載を省略できます。

加入月の端数期間の算定や長期無給による算定対象期間の延長は、本稿では扱いません。資料を揃えて管轄へ確認します。日数基準を満たす月が後ろにあるのに、先に時間基準だけで記入を終えないようにします。

賃金支払基礎日数の数え方

賃金支払基礎日数は「何日出勤したか」ではなく、「何日分の賃金の支払対象か」です。⑨は⑧の期間、⑪は⑩の期間について、それぞれ数えます。

賃金の決め方基礎日数の考え方
月間全部を支払対象とし、欠勤しても減額しない月給その期間の暦日数
欠勤日数に応じて控除する月給給与規程の計算方法に照らし、控除後の賃金に対応する日数
日給・時給出勤日だけでなく、有給休暇・休業手当の支払対象日も含む

「正社員だから暦日数」「パートだから出勤簿の日数」と固定しないようにします。欠勤控除に使う日数が、暦日なのか、所定の出勤日なのかも給与規程で確認します。深夜勤務が翌日にまたがる場合などは、手引きの個別の数え方に従います。

賃金額・備考・特記事項

⑫欄のA・Bは雇用形態で決めない

⑫欄には、⑩の期間に対応する、税金・社会保険料を差し引く前の賃金額を記載します。手取り額や、その月に振り込んだ合計額をそのまま写す欄ではありません。

主たる賃金の形態⑫欄の書き分け
月給が主体A欄。一部に時間等で算定する賃金があってもA欄に含める
日給・時給・出来高給等が主体主たる賃金はB欄、月単位の定額手当等はA欄。両方ある場合は計欄も記入

通勤手当を定期券代などでまとめて支給した場合は、対象月へ割り振り、端数は最後の月に計上します。基本給と残業代の支払月がずれている場合も、⑩の対象期間に戻して集計します。

最終月が未計算の場合と、未払いの場合

船員の変動賃金を除き、離職日と締日が異なる不完全月の賃金は、ほかに、ひと月の期間と賃金支払基礎日数11日以上を満たす完全月6か月があれば、未計算と記載できます。後日、確定額の確認を求められる場合があるため、集計の予定と確認記録を残します。

支払日を過ぎ、離職時まで支払っていない賃金が「未払い」です。⑬欄に、その旨と月別の未払い額を記載します。締日と支払日の間に離職し、支払日に支払うことが確実な賃金は未払いとせず、⑫欄に記載します。「未計算」と記載しても、会社の賃金支払義務がなくなるわけではありません。

賞与・休業手当などの扱い

臨時に支払う賃金と、本来の支給周期が3か月を超える賃金は、離職証明書の賃金から除きます（同じ性質の賃金は名称を問わず本来の年間支払回数を合算）。「雇用保険料を計算した賃金総額」と、同じ範囲とは限りません。

毎月以外で、本来3か月以内ごとに支払う特別の賃金は、⑭欄に離職前1年間の支給日・名称・額を記載します（一括払いで各回の額が判明なら本来の支給日・額で記載）。

各回の額が不明な一括払いの配分は、業務取扱要領の特別の賃金の記載方法を確認します。

通常の終日休業の手当は、⑬欄に休業日数と手当額を記載します（全休業・時間休業等は別の取扱い）。全休業や休業間に所定休日がある場合、時間休業の場合には個別の記載方法があるため、業務取扱要領の離職証明書記載要領と照合します。

離職理由と本人の記名

⑦欄は主たる離職理由を選び、具体的事情記載欄に原因・経緯を書きます（個人的事情は本人から把握している範囲）。

事情の例具体的事情欄に整理する内容
本人の転居による退職把握している範囲で、転居先・通勤困難の事情・申出の経緯
契約期間満了期間・更新回数・更新の明示と本人の希望。希望を聞く機会がなければ、その経緯も記載
定年就業規則上の定年、継続雇用の希望と会社の対応
退職勧奨・解雇会社から働きかけた経緯・理由と通知の記録

表は整理する事項の例で、離職理由の認定結果を示すものではありません。会社と本人の主張、客観的な確認資料を踏まえ、ハローワークが最終的に判定します。

⑮と⑯は確認する内容が異なる

⑮欄は、離職理由を除く記載内容を本人に確認してもらう欄です。⑯欄は、会社の記載した離職理由への異議の有無を本人が判断する欄です。やむを得ず確認・記名を得られない場合を除き、可能な限り離職前に本人へ説明し、氏名を記載してもらいます。

帰郷その他やむを得ない理由で本人の確認・記名を得られないときは、該当欄に理由と事業主氏名を記載する取扱いがあります。空欄のままにしたり、会社が本人の異議を勝手に「無し」としたりせず、確認できなかった事情を記録します。

添付書類と電子申請

賃金・勤務の記録と、離職理由の記録を分けて揃えます。賃金台帳と出勤簿は、離職証明書に記載した期間を確認できるものを準備します。

確認する内容準備する資料の例
被保険者期間・基礎日数・賃金労働者名簿、賃金台帳、出勤簿・タイムカード
自己都合退職願・退職届など、理由を確認できる資料
解雇・退職勧奨解雇通知書・退職勧奨の記録など
契約満了雇用契約書、契約更新・不更新の通知など
定年・再雇用期限の到来就業規則、再雇用に関する規程・雇用契約書など

自己都合の退職願がもともと存在しない場合、新たに作成させる必要はありません。確認資料の照合省略を認められている場合や、追加資料を求められる場合もあるので、管轄の案内に従います。

e-Govでの電子申請

電子申請でも本人に内容を確認します（やむを得ず確認できない場合は下記の代替資料）。厚生労働省の電子申請手順では、本人の電子署名に代えて、離職証明書の記載内容を確認したことを証明する確認書を添付できます。確認書を添付して本人の電子署名に代える場合は、離職証明書の⑮・⑯欄の記載は不要です。

  1. e-Govの手続検索で、雇用保険被保険者資格喪失届の「離職票交付あり」を選ぶ。
  2. 資格喪失届・離職証明書を入力し、必要な確認資料を添付する（照合省略の承認がある資料を除く）。
  3. やむを得ず本人確認ができない場合を除き、本人の電子署名または確認書を用意して送信する。
  4. 審査状況と補正の連絡を確認し、返された離職票・事業主控などの公文書を取得する。

本人と連絡がとれず確認を得られない場合は、厚生労働省の電子申請案内にある「被保険者の確認を得られないやむを得ない理由について」の様式を使います。事業主側の電子証明書・GビズID等の利用準備とは分けて確認します。送信が到達したことと、審査が完了して離職票が交付されたことを混同しないようにします。

提出前によくある誤りを確認

  • 期間の混同：⑧を給与締日で区切っていないか、⑩を給与支払日で区切っていないか。
  • 日数の不足：出勤日だけを数え、有給休暇や休業手当の対象日を落としていないか。
  • 賃金の転記：手取り額や振込月の合計を写し、通勤手当や変動給の対象月を取り違えていないか。
  • 本人確認の不足：具体的事情欄と本人の判断欄を説明し、確認できなかった場合の理由を記録したか。

離職日・給与締日・賃金規程を先に揃えると、欄どうしの食い違いを確認できます。記入した期間の賃金台帳・出勤簿と照合し、本人確認または、やむを得ず確認できない場合の代替記載を整えて提出します。

離職証明書の作成以外の会社側の手続きは退職手続き一覧へ。給付額の案内が必要な場合は、次の計算機で条件を確認できます。

よくある質問

離職証明書と離職票は同じですか？

別の書類です。会社が離職証明書を作成し、資格喪失を確認したハローワークが離職票を交付します（住所不明等で交付できない場合を除く）。退職者の受給手続きで使うのは離職票です。

本人が離職票を希望しなくても作成しますか？

離職日に59歳以上の被保険者は、本人の希望にかかわらず離職証明書の添付が必要です。これに該当しない被保険者が希望しないときは添付を省略できますが、資格喪失届は提出します。

賃金支払基礎日数は出勤日数と同じですか？

同じとは限りません。有給休暇や休業手当の支払対象日も含みます。月給の場合は、欠勤控除の有無や賃金の支払対象期間に応じて数え、⑨と⑪でそれぞれの期間に対応させます。

退職者と連絡がとれず、記名してもらえません。

帰郷その他やむを得ない理由で本人の確認・記名を得られない場合、該当欄に理由と事業主氏名を記載する取扱いがあります。連絡した経緯を記録し、電子申請で添付する資料などは管轄のハローワークに確認します。

次に読む

在職証明書の書き方・もらい方｜記載項目と退職証明書・就労証明書の違い勤務先への依頼と記載項目を用途別に確認。退職時の証明・保育所の就労証明書との違い。処遇改善手当とは｜介護・障害福祉の配分と給与明細の確認表処遇改善手当は、事業所が取得する処遇改善加算を使った賃金改善の支払項目です。介護と障害福祉の制度・適用時点を分け、基本給・手当・賞与への配分と、給与明細・賃金規程・計画書の照合順を退職手続きの会社側チェックリスト会社側の退職手続きを、保険の資格喪失・住民税の異動・本人への書類交付・翌年の給与支払報告まで、期限と提出先の一覧で確認できます。
