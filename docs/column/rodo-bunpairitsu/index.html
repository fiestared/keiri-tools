労働分配率の計算方法｜統計ごとの分子・分母を同じ決算で比べる

公開日: 2026年10月22日

文責: Masahiro Yasu（クリニック・EC事業の経営者／経理実務者）

労働分配率は、会社が生み出した付加価値額のうち人件費に回った割合で、人件費÷付加価値額×100で計算します。ただし、付加価値額と人件費の数え方は統計ごとに違います。

本記事の架空決算では、同じ数字から57.1%〜71.4%まで4通りの労働分配率が出ます（設例）。自社の値を公表値と比べるときは、分子と分母を公表値と同じ式にそろえます。

基準日は2026年10月22日です。一律の「適正値」は示さず、計算の仕組みを説明する一般的な解説です。

統計ごとの式の早見表

財務省の法人企業統計と、経済産業省の企業活動基本調査の式です。どちらも2026年10月22日に各省の公表物で確かめました。

項目法人企業統計（財務省）企業活動基本調査（経済産業省）
付加価値額の式営業純益＋役員給与・賞与＋従業員給与・賞与＋福利厚生費＋支払利息等＋動産・不動産賃借料＋租税公課営業利益＋減価償却費＋給与総額＋福利厚生費＋動産・不動産賃借料＋租税公課

労働分配率の分子本記事では役員給与・賞与、従業員給与・賞与、福利厚生費の合計給与総額（福利厚生費は入れない）
最新の年次の結果令和7年度年次別調査（2026年9月1日公表）2025年確報・2024年度実績（2026年6月29日公表）

法人企業統計の式は平成19年度調査以降のもので、それ以前は役員賞与を含みません。営業純益は営業利益から支払利息等を引いた額なので、式の中で支払利息等は打ち消し合います。

2つの式の大きな違いは、減価償却費を付加価値額に入れるかと、分子に福利厚生費を入れるかです。どちらも「人件費÷付加価値額」と説明されますが、そのまま並べると比べられません。

同じ架空決算で4通りに計算する

設例（架空・単位は千円）：売上高200,000の会社です。設例で外部から買った費用は、商品仕入（売上原価）95,000と、販管費の運賃・広告費など15,000だけとします。役員賞与は0、法定福利費は福利厚生費に合算します。

①と③の差は、減価償却費6,000千円を分母に入れるかどうかです（設例）。②と③の差は、分子に福利厚生費8,000千円を入れるかどうかです（設例）。

売上高から外部から買った費用を引く「控除法」でも、この設例では200,000−95,000−15,000＝90,000千円で、企業活動基本調査の式と同じ額になります。外部から買った費用を2つだけと置いた設例だからそろう額で、実際の決算では科目の振り分けで差が出ます。

公表値と比べるときは式をそろえる

企業活動基本調査の2025年確報（2024年度実績）の労働分配率です。分子は給与総額で、福利厚生費は入りません。

企業活動基本調査の労働分配率（2024年度実績）
産業労働分配率
合計46.6%
製造業45.9%
卸売業43.7%
小売業46.7%

設例の会社をこの表と比べるなら、同じ式で計算した②の57.8%を使います（設例）。設例の①の71.4%を並べると、式の違いの分まで差に見えてしまいます。

上の経産省の表は、産業ごとの給与総額の合計を付加価値額の合計で割った割合で、自社が目指す値を示すものではありません。法人企業統計の付加価値額を使った公表値と比べるときは、その表の分子の定義を確かめてから①のように計算し直します。

売上が同じまま賃上げすると

設例で売上と他の費用・支払利息を変えずに従業員の給料を2,000千円上げると、営業利益が同じ額だけ減ります。売上と他の費用が同じなので、法人企業統計の式の付加価値額は84,000千円のまま、人件費が62,000千円になり、労働分配率は73.8%に上がります（設例）。

付加価値額は、人件費と利益などに分ける元の額です。売上と他の費用が変わらなければ、賃上げは配分を変えるだけで、付加価値額は増えません。

設例では、賃上げに伴う法定福利費の増加は入れていません。入れれば人件費はさらに増えます。

労働生産性との関係

企業活動基本調査の概況は、労働生産性を付加価値額÷常時従業者数で計算しています。

設例の常時従業者を10人とすると、企業活動基本調査の式の労働生産性は90,000千円÷10人＝9,000千円です（設例）。常時従業者10人の設例の1人当たり給与総額は52,000千円÷10人＝5,200千円で、労働生産性に丸める前の分配率（52,000÷90,000）を掛けた額と一致します。

労働分配率が同じでも、労働生産性が高い会社ほど従業者ひとり当たりに回せる額は大きくなります。分配率だけで人件費の多い少ないを決めず、生産性と組で見ます。

外形標準課税の付加価値額は別の数字

外形標準課税の付加価値割で使う付加価値額は、報酬給与額・純支払利子・純支払賃借料の合計額と、単年度損益との合計額です（地方税法72条の14）。

名前は同じでも統計の付加価値額とは項目の範囲が違うので、申告書の付加価値額を労働分配率の分母に使うと、統計の公表値とはそろいません。対象法人と各項目の計算は外形標準課税の記事で扱っています。

労働分配率は人件費÷付加価値額ですが、付加価値額に減価償却費を入れるか、分子に福利厚生費を入れるかが統計ごとに違います。公表値と比べるときは、その統計と同じ式で自社の値を計算し直します。

よくある質問

労働分配率の適正値は何%ですか？

本記事は一律の適正値を示しません。同じ決算でも式によって設例では57.1%〜71.4%まで変わるので、比べる公表値と同じ式にそろえ、同じ業種の値と比べます。

法定福利費は人件費に入れますか？

使う統計の式によります。企業活動基本調査の概況の労働分配率は分子が給与総額で、福利厚生費は分母の付加価値額にだけ入ります。本記事の設例の①③④では、法定福利費を福利厚生費に合算して分子の人件費に含めています。

賃上げすると労働分配率は上がりますか？

売上と他の費用が変わらなければ上がります。設例では従業員の給料を2,000千円上げると、法人企業統計の式の付加価値額84,000千円は変わらず、71.4%から73.8%になります。付加価値額も増えれば、上がらないこともあります。
