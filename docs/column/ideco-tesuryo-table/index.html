iDeCoの手数料：加入時・毎月・運用指図中・受取時の費用を同条件で集計

公開日: 2026年10月24日

文責: Masahiro Yasu（クリニック・EC事業の経営者／経理実務者）

iDeCoは、運営管理手数料が無料でも、加入・資産管理・給付などの費用が別にかかります。掛金を払っている期間と、掛金を止めて運用だけを続ける期間を分けて集計します。

以下は、確認した料金表の単価を固定した事務費用の参照表です。金融機関の共通最低額や、将来の総負担を示すものではありません。所得控除と受取時の税額は、末尾の既存ツールで分けて確認できます。

加入から受取までの手数料表

「無料」と表示された費目を確認します。運営管理機関に払う費用と、国民年金基金連合会・資産管理機関に払う費用は別です。

2026年10月24日確認・金額は税込。国民年金基金連合会の新規加入時等手数料と、参照プランの運営管理手数料なし・資産管理月額66円・給付1回440円を使う固定設例です。改定前は2026年11月分まで、改定後は2026年12月分以降の掛金拠出中の連合会手数料。年単位拠出も改定後は対象月数で計算します。出典：連合会の改定案内・参照料金表。

固定設例：事務手数料の支払先・発生単位
場面支払先・費目金額と発生単位
新規加入時等国民年金基金連合会2,829円／加入時等
掛金拠出中・改定前国民年金基金連合会105円／収納1回
掛金拠出中・改定後国民年金基金連合会120円／拠出対象月
掛金拠出中・運用指図中資産管理機関66円／月
給付を受けるとき資産管理機関440円／給付1回

連合会の改定後手数料は、2027年1月26日の口座引落分から適用され、事業主払込も同じです。連合会の改定は毎月拠出では2026年12月分に当たり、改定に伴う加入者の手続きはありません。

運営管理・資産管理・給付の料金は、契約先のプランで確認してください。この表の資産管理費や給付費を、他の金融機関の料金と決めつけないでください。

改定前後の年間費用を検算

改定前は収納回数、改定後は掛金の対象月数を掛けます。年単位拠出の利用可否とは分けた、費用だけの比較です。企業年金制度に加入している方や公務員は、年単位拠出を選択できません（公式サイトの加入案内）。

年間の固定設例：運営管理手数料なし・資産管理月額66円で、全12対象月に拠出する連合会と資産管理の事務費用のみ。旧期間は2025年12月〜2026年11月、新期間は2026年12月〜2027年11月とし、新旧それぞれの単価を期間中固定します。改定前の連合会は掛金収納1回105円、改定後は対象月1か月120円です。加入時・給付時・信託報酬・移換・還付費用は含めません。

固定設例：改定前後の年間事務費用
期間と収納回数計算式（円）年額
旧期間・毎月収納105×12＋66×122,052円
旧期間・年1回収納105×1＋66×12897円
新期間・毎月収納120×12＋66×122,232円
新期間・年1回収納120×12＋66×122,232円

改定後は、収納をまとめても連合会手数料の対象月数は減りません。このため、以前の収納回数だけで計算した年額を、そのまま改定後へ使えません。表は暦年の実際の引落総額ではなく、対象月をそろえた比較です。

運用指図期間と給付を含む集計例

掛金を止めた運用指図者にも、資産管理などの費用は残ります。参照プランでは、年金資産の一部売却による充当や、給付金からの差引きで支払います。掛金を止めることと、資産を引き出すことは別です。

税込の全体の固定設例：国民年金基金連合会の新規加入時等1回、改定後の掛金拠出1年間・全12対象月、運用指図12か月、給付1回を合計します。運営管理手数料なし・資産管理月額66円・給付1回440円、連合会は2026年12月分以降の掛金拠出対象月1か月120円の単価を固定。事務費用のみで、信託報酬・移換・還付・税は含めません。将来の料金改定を予測せず、短期間での受給が可能かも判定しない架空の集計です。

固定設例：運用指図期間と給付を含む事務費用の合計
区分計算式（円）費用
新規加入時等2,829×12,829円
改定後の拠出期間120×12＋66×122,232円
運用指図期間66×12792円
給付440×1440円
合計加入＋拠出＋運用指図＋給付6,293円

端数のない税込単価に回数・月数を掛けており、丸めは行っていません。給付を分ける場合は、その給付回数に応じた費用を入れ直します。実際の管理費用の終了時点は、契約先の給付手続きで確認します。

表に含まない費用と確認書類

上の合計は事務費用の設例です。運用商品の費用まで含めた総負担や、税負担を差し引いた損益ではありません。

  • 投資信託を保有する場合は、目論見書の信託報酬・その他費用も確認します。事務費用とは別に整理します。
  • 運営管理機関や他制度へ資産を移す場合は、移換元・移換先と移換の区分を料金表で確認します。
  • 上限超過や加入資格のない月への拠出などで掛金が還付される場合は、通常の給付と区別して還付手数料を確認します。

保存するのは、プラン名と料金表の確認日、掛金の対象月と収納回数、運用指図期間、給付回数、差引きの明細です。勤務先の担当者も、事業主払込の収納月だけで対象月を判断せず、通知の内訳を照らします。

よくある質問

運営管理手数料が無料なら、iDeCoの費用はかかりませんか？

ほかの費用は別にかかります。無料なのが運営管理機関に払う費用かを確認し、連合会・資産管理・給付と、運用商品の費用を分けます。

掛金を止めた後も手数料はかかりますか？

運用指図中にも資産管理などの費用がかかります。参照プランでは年金資産や給付金から差し引かれます。掛金停止で資産が払い出されるわけではありません。

年単位拠出なら改定後も手数料を減らせますか？

連合会の改定後手数料は、収納回数を減らすだけでは減りません。掛金の拠出対象月数に応じて計算するためです。年単位拠出の利用可否と、手数料の計算は分けて確認します。

掲載した合計は、実際の総負担ですか？

単価と期間・回数を固定した事務費用の設例です。商品の信託報酬、移換・還付費用、税を含みません。将来の料金変更や、給付を受けられる時期も織り込んでいません。
