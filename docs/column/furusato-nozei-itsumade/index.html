ふるさと納税はいつまで？
寄附・ワンストップ・確定申告の期限

公開日: 2026年10月22日

文責: Masahiro Yasu（クリニック・EC事業の経営者／経理実務者）

ふるさと納税は、その年の年末までに寄附の入金・決済を済ませます。申込みだけでは完了しません。控除を受けるには、寄附とは別に申請・申告も必要です。

2026年の寄附について、通常の期限と控除時期をまとめます。表の申請期限はワンストップ特例対象者の郵送申請、申告期限は申告義務のある人のものです。オンライン申請と還付申告は下で説明します。災害等の個別の期限延長は含みません。

寄附・控除手続の期限早見表
何をするかいつまで・いつから完了の目安
その年の寄附2026年12月31日まで入金・決済を完了。方法別の受付・支払期限は早まる場合あり
ワンストップ申請・変更届（郵送）2027年1月10日必着寄附先に到着。香川県は日曜必着と明示
所得税の確定申告（申告義務あり）2027年3月15日まで税務署へ提出。還付申告は別扱い
ワンストップ適用時の住民税控除2027年6月以降に納付する住民税所得税の還付ではなく、翌年度の住民税の減額

寄附の受付期限は自治体・決済方法ごとに確認します。所得税の申告期限には土日等の休日繰延がありますが、ワンストップの郵送申請に同じ扱いを当てはめず、寄附先の必着日を守ります。

申込みより、入金・決済の完了日を確認

寄附先がどの日を寄附日として扱うかを確認します。年末に申込みだけを済ませても、決済が翌年になれば、その年の寄附として扱われない場合があります。

クレジットカードは、銀行口座からの引落日と寄附日を区別します。韮崎市の年末年始の案内では、カード決済時の日時を受領証明書の領収日としています。

決済後は、寄附の履歴や決済完了の通知を保存し、後から届く受領証明書の領収日と照合します。年末に手続したのに翌年の日付になっているなど、記録に食い違いがあれば寄附先へ確認します。返礼品の到着を待って、入金や申請の完了を判断しないようにします。

年末受付は自治体と支払方法で違う

年末まで支払えることと、年末まで申し込めることは別です。払込票の発送が必要な方法は受付が先に終わり、金融機関の営業時間によっては入金が翌営業日になります。発行された支払番号に有効期限がある場合も、その期限内の支払が必要です。

香川県の2026年末受付から、納付書・口座振込みとカード払いを比べます。以下は香川県への寄附の例で、全国共通の締切ではありません。

香川県の年内寄附の受付例
支払方法申込み・決済の締切確認すること
納付書・口座振込み申込書は2026年12月16日までに香川県庁へ到達、払込みは年内金融機関の営業日と時刻。手続によっては翌営業日入金
クレジットカード香川県専用フォームから2026年12月31日23時59分までに決済完了申込みから決済にも時間がかかるため、締切直前に始めない

寄附先の公式ページで「年末年始」「年内受付」「支払方法」の案内を開き、申込期限と入金期限を別々に確認すると見落としを減らせます。受付が終わった支払方法を、別の方法の締切で判断しないことが大切です。

寄附額の目安を先に確認する場合は、ふるさと納税の限度額シミュレーションを利用できます。計算結果は概算で、個別の控除上限を保証するものではありません。

ワンストップは申請受付まで確認

寄附申込時に「申請書を希望する」を選ぶだけでは、ワンストップ申請は完了しません。郵送なら、申請書と必要書類を寄附先へ提出して受付を確認します。寄附の決済完了メールと、特例申請の受付通知を区別してください。

ワンストップ特例は、確定申告が不要で、寄附金控除以外に住民税申告の必要がなく、寄附先が5自治体以内の人などが対象です。医療費控除などで確定申告をする人は利用できません。

年末の寄附で申請書の到着が遅い場合は、寄附先の公式サイトから様式をダウンロードし、個人番号確認書類と本人確認書類を添えて期限内に届くように送ります。オンライン申請に対応する自治体なら、その案内に沿って申請できます。利用できる方式や必要な準備、受付時刻も寄附先で確認します。

郵送ワンストップ申請の締切は、発送日ではなく寄附先への到着日です。香川県の案内は冒頭表の締切を日曜必着としています。休日だから次の平日まで延びると考えず、配送日数を見込んで準備します。

ワンストップ申請後から寄附した翌年の元日までに氏名・住所などの申請事項が変わった場合は、申請した寄附先へ変更届を出します。香川県が案内する郵送変更届の必着日は、冒頭の申請期限と同じです。

申請後は、寄附先が案内する受付完了メールや申請状況の確認画面で処理状況を確認します。北九州市のQ&Aでも、受付完了メールや確認画面を案内しています。

申請期限を過ぎた場合の控除手続

ワンストップ申請が間に合わなくても、寄附金控除を受ける手続は残っています。確定申告をする場合は、ワンストップ申請済みの寄附も含めて申告します。申告書の入力や必要書類は、ふるさと納税の確定申告のやり方で確認できます。

税務署への確定申告書を郵便・信書便で提出する場合は、通信日付印の日が提出日です。寄附先に必着のワンストップ申請とは扱いが違います。小包や荷物扱いでは送らず、国税庁の送付方法の案内を確認します。

申告義務がなく、源泉徴収などで所得税を納め過ぎた人の還付申告は、寄附した翌年1月1日から5年間提出できます（期限内提出が要件の特例を使う場合を除く）。すでに同じ年分を申告した人の追加・訂正は、更正の請求など別の手続です。

ワンストップを使わず、年末調整等で所得税がゼロで住民税のみから控除を受ける人は、住所地の市区町村へ住民税申告を確認します。申告義務がある人が所得税の申告期限を過ぎた場合も、還付申告の期間と混同せず、税務署へ手続を確認してください。

まとめ

寄附は入金・決済まで、ワンストップは申請の受付まで確認します。年末受付は寄附先と支払方法で違うため、申込みと支払の締切を分けて確認してください。申請期限を過ぎたときは、確定申告などの手続へ切り替えます。

よくある質問

カードの口座引落しが年明けでも大丈夫ですか？

口座引落日ではなく、寄附先が案内する寄附日の扱いを確認します。韮崎市はカード決済時の日時を受領証明書の領収日としています。決済の記録と受領証明書の日付を照合してください。

ワンストップの申請書が届きません。待つ必要がありますか？

寄附先の公式サイトから申請書の様式を取得して提出できます。必要書類を添えて期限内に届くように送り、対応自治体ではオンライン申請も確認します。申込時の申請書希望だけでは、特例申請は完了していません。

ワンストップ申請後に確定申告をする場合は？

申請済みの寄附も含めて、確定申告に記載します。確定申告をするとワンストップ申請は無効になるため、申請していない寄附だけを記載すると控除が漏れます。

次に読む

無職でも確定申告は必要？退職後の還付・無収入の住民税申告退職年の還付と無収入の年の住民税申告を区別。状況別の早見表と入力資料の準備。外交員報酬とは？源泉徴収の計算・給与との違い・支払調書外交員報酬は、給与に当たる部分を分けてから源泉徴収します。同月に給与も支払う場合の控除の調整、国税庁の公表計算例、納付と支払調書の確認点を整理。受け取る側の所得区分と確定申告の流れフリーターは確定申告が必要？掛け持ち・退職・還付の確認表フリーターの確定申告は、掛け持ち給与と年末調整の状況で確認します。申告が必要な場合と還付を受けられる場合を分け、源泉徴収票の集め方、乙欄の給与、住民税の申告との関係を整理します。
