法定休日とは｜法定外休日との違い・定め方と振替休日・代休の区分

公開日: 2026年10月23日

文責: Masahiro Yasu（クリニック・EC事業の経営者／経理実務者）

法定休日は、労働基準法が会社に与えるよう求めている休日です。会社独自の法定外休日とは、出勤したときの割増賃金の扱いが異なります。給与計算の前に、就業規則と勤務表でどの日が法定休日かを確認します。

日曜日や祝日だから法定休日、とは決まりません。この記事では休日の定め方と勤怠の区分を整理し、金額の計算は休日出勤手当の計算方法へ案内します。

法定休日と法定外休日の違い

違いは、法律が求める休日か、それを上回って会社が設けた休日かです。法定休日の基準は労働基準法の休日規定で確認します。

次の表は、労働基準法の休日・割増賃金規定が適用される労働者の区分と最低限度の率を示し、深夜割増は別途必要です。時間外労働には月の累計による高率もあり、会社でより高い率を定めている場合も確認します。

法定休日と法定外休日の比較
区分位置づけ出勤したときの割増
法定休日法律の最低基準として確保する休日法定休日労働は35%以上
法定外休日法律の最低基準を上回る会社の休日法定時間外労働に当たる部分は25%以上
法定外休日で法定時間外に当たらない勤務休日出勤でも法定の時間外労働とは別時間外の割増は発生しない。勤務分の賃金や会社の手当は別に確認

たとえば、就業規則で日曜日を法定休日、土曜日を法定外休日と定めた会社では、同じ休日出勤でも区分が違います。勤怠システムに「休日出勤」という項目しかない場合は、給与計算に渡すときに内訳を分けておきます。

ここでは通常の休日制度を扱います。管理監督者などの適用除外、変形労働時間制や特例の労働時間による判定は別に確認してください。詳しい対象者と割増の組合せは休日出勤手当で確認できます。

法定休日の定め方と確認する書類

法定休日の特定と、休日数を数える期間の起算日は分けて確認します。労働基準法の休日規定は法定休日の特定自体を義務にしていませんが、通達では就業規則等で具体的な休日の定め方を規定するよう指導しています。

労働基準法の休日規定が適用される労働者の付与方式を整理します。固定期間の例外方式では、労働基準法施行規則の起算日の規定により、就業規則等で期間の起算日を明らかにする必要があります。

休日の付与方式と起算日の確認
休日の付与方式付与する休日会社で確認すること
毎週の休日を確保する方式休日は毎週少なくとも1回週の区切り、法定休日の定め方と勤務表の表示
固定した期間で休日を確保する例外方式休日は4週間を通じ4日以上就業規則等で期間の起算日を明らかにする

後から都合のよい期間を切り取って休日数を数える扱いにはしません。期間の起算日が分からなければ、給与担当が独自に決めず、労務担当へ規程の確認を依頼します。

厚生労働省の休日特定に関する資料には、休日を特定する方法を定めるよう指導する通達が掲載されています。義務がないことと、会社のルールを曖昧にしたまま運用してよいことは別です。

特定していない会社で休日出勤が発生したときの判定は、週の区切りや勤務状況で変わります。法定休日を特定せず土日とも働いた場合の判定で条件を確認し、曜日だけで一律に決めないようにします。

日曜日・祝日と法定休日は別

カレンダーの赤い日と会社の休日は、同じとは限りません。東京労働局の休日の説明は、国民の祝日に関する法律が会社に休日付与を義務付けるものではないと整理しています。

ただし、就業規則や労働契約で祝日を休日としていれば、その定めを確認します。「祝日だから法定休日」と決めることも、「法定休日ではないから通常の出勤日」と決めることも避けます。

曜日・祝日と社内の休日区分を分ける例
勤務表で見た日確認するもの判断の順番
日曜日その日を法定休日とする規程や勤務表曜日名で決めず、会社の休日の定めを確認
国民の祝日祝日を休日とする契約・就業規則会社の休日かを確かめ、そのうえで法定休日かを確認
シフト上の平日の休み勤務表と法定休日の指定方法平日でも法定休日となり得るため、勤務表の区分を確認

振替休日と代休の違い

事前に休日と労働日を交換するのが振替休日、休日労働の後に休みを与えるのが代休です。法定休日に出勤した後で代休を与えても、休日労働の割増賃金は残ります。

有効な休日振替には、就業規則の振替規程、振替日の特定、4週4日の休日を確保できる範囲のできるだけ近接した日への振替、休日労働を行う前日までの通知が必要です。群馬労働局の振替休日の説明に沿って確認します。

振替で週の法定労働時間を超えるなら、超えた部分の時間外割増は必要です。「振替だから追加の賃金はない」と決めず、振替休日・代休の要件と計算例で、週をまたぐ場合や代休日の賃金の扱いを確認してください。

まず確認すること

会社の休日のうち、法定休日はどれかを就業規則と勤務表で確認します。祝日の表示だけでは区分できず、代休を与えても休日労働の割増は消えません。

よくある質問

法定休日は日曜日ですか？

日曜日と決まっているわけではありません。労働基準法の休日規定は曜日を指定しておらず、会社の就業規則や勤務表で休日の定めを確認します。祝日も自動的に法定休日になるわけではありません。

法定休日を特定しなくてもよいですか？

労働基準法の休日規定は、法定休日の特定自体を義務にしていません。ただし、通達では具体的な休日の定め方を規定するよう指導しています。休日を数える固定期間を採用する場合の起算日の明示とは分けて確認します。

法定外休日なら割増賃金は要りませんか？

法定時間外労働に当たる部分には時間外割増が必要です。法定外休日というだけで休日労働の割増にはなりませんが、勤務時間、深夜帯の勤務、賃金規程を確認して判定します。

代休を取れば法定休日に働いた分の割増は消えますか？

消えません。代休は事後の休みなので、法定休日労働の割増賃金は必要です。事前に休日と労働日を有効に交換する振替休日とは扱いが異なります。
