イートインの消費税｜持ち帰りとの違いと判定表

公開日: 2026年10月24日

文責: Masahiro Yasu（クリニック・EC事業の経営者／経理実務者）

国内の飲食店・コンビニでは、店内飲食は地方消費税込み10%、酒類を除く食品だけの持ち帰りは軽減8%です（2026年10月現在）。

分かれ目は、食品を提供する時点の店内飲食・持ち帰りの意思です。持ち帰り用の容器に入っていても、店内で食べると申し出た商品は店内飲食として扱います。

店内飲食・持ち帰りの判定早見表

以下は2026年10月現在、国内で販売する酒類を除く食品だけの取引例です。税率は地方消費税込みで、食品以外と組み合わせた一体資産や施設給食は扱いません。

提供する内容税率判定のポイント
飲食店の席で食べる料理10%飲食設備で飲食させるサービス
容器に入れて持ち帰る弁当8%提供時に持ち帰りの意思を確認
コンビニのイートインで食べる弁当10%持ち帰り用容器でも、店内飲食の申出があれば外食
自ら設置したテーブルで食べさせる屋台10%屋外でも飲食設備で飲食させれば外食
飲食設備を利用させず、食品を売るだけの屋台8%単なる食品の販売
食品を指定先まで単に届ける出前8%配達先で調理や給仕をしない
一般家庭や会社の指定先で調理する出張料理10%指定先で調理するサービス

飲食料品の譲渡については令和9年4月1日から令和11年3月31日まで税率が引き下げられるため、その期間の取引は国税庁の案内で再確認してください。

標準税率と軽減税率の内訳や、飲食料品以外の対象は消費税率の解説にまとめています。

判定は食品を提供する時点

店内飲食か持ち帰りかは、食品を提供する時点で、顧客に意思確認するなどして判定します。注文を受ける際の確認を、商品の受渡しやレジの税区分につなげる流れです。

たとえば、弁当を同じパックで販売していても、店内の席で食べると申し出た場合は外食です。返却する食器を使わないことだけで、持ち帰り扱いにはできません。

根拠は国税庁「軽減税率Q&A（個別事例編）」問58です。

コンビニの掲示による意思確認

大半の食品を持ち帰りとして販売するコンビニでは、持ち帰りにも使う容器で販売する商品について、イートインを利用する顧客に申出を求める掲示で意思確認できます。

掲示の例は、「イートインコーナーを利用する場合はお申し出ください」です。

ただし、トレイや返却が必要な食器に入れて店内で食べさせる提供は、掲示の有無で持ち帰りに変わるものではありません。休憩スペースという名称でも、実際に顧客が飲食に使う設備なら判定の対象です。

逆に、飲食を控えるよう掲示し、実態としても飲食させていない休憩スペースは飲食設備に当たりません。掲示と実際の使われ方を合わせて確認します。

持ち帰りと言って店内で食べたら

提供時に持ち帰りの意思を確認して販売した後、顧客の気が変わって店内で食べた場合は、後の行動だけを理由に税率を変更する必要はありません。提供時点の判定と、その後の予定変更は区別します。

一方、提供する時点で店内飲食すると申し出ていた商品は、持ち帰り用の容器でも外食です。

逆の例として、店内で食べるために提供した料理の残りを折り詰めにしても、残りの分が軽減対象に変わるわけではありません。

屋台はテーブルの有無と利用関係を見る

屋台でも、自ら設置したテーブル・椅子・カウンターで顧客に飲食させれば外食です。屋外にあることや、使い捨ての皿であることは決め手になりません。

他者が設置した設備も、使用許可や合意などに基づき自店の顧客に利用させる場合は飲食設備に含まれます。飲食専用の設備である必要もありません。

たとえば、イベント主催者から共用テーブルの使用許可を受け、その席で食べさせる屋台と、近隣の公園のベンチについて特段の使用許可を取らず食品を売るだけの屋台は扱いが異なります。屋台が特段の使用許可等を得ていない公共のベンチを、他の人と同じように顧客も自由に使うことがあるだけなら、外食には当たりません。

出前とケータリングの違い

そばやピザを指定先まで単に届ける出前は、軽減税率の対象です。一般家庭や会社の指定先で、食材を持参して調理する出張料理は軽減対象から外れます。

ケータリングの注文では、提供先での加熱や給仕の有無も確認します。経費精算では、注文名が「配達」「ケータリング」のどちらかだけでなく、提供内容とレシートの税区分を確認します。

ただし、食品販売に通常必要な容器への取り分けは、ここでいうサービスには含めません。配達先で味噌汁を器に注ぐだけの弁当配達は、ケータリングに当たらない例です。

この節は一般家庭・会社向けの例です。一定の老人ホームや学校等の給食には、提供者・対象者・金額等による例外があります。詳しくは国税庁Q&A問75以降をご確認ください。

経理担当の確認順序

提供内容を確認し、店内飲食・持ち帰り・配達先でのサービスを区別してから、レシートの税区分と照らします。

迷いやすいのは、同じ容器で店内飲食も持ち帰りも扱う店と、配達後に給仕等をする取引です。販売側は意思確認とレジの区分をそろえ、購入側は注文内容も確認材料にします。

よくある質問

コンビニの弁当は、容器が同じなら税区分も同じですか？

同じとは限りません。提供時点でイートインを使って食べると申し出た商品は、持ち帰り用の容器でも外食です。持ち帰りとの区分は、容器だけで決めません。

店内で食べた料理の残りを持ち帰ると、軽減税率になりますか？

なりません。店内飲食のために提供された料理は、その提供時点で外食として判定されるため、食べ残しを持ち帰っても軽減対象に変わりません。

出前とケータリングは、何で区別しますか？

指定先でのサービスの有無で区別します。食品を単に届ける出前は軽減対象、一般家庭・会社の指定先で調理や給仕を伴う提供は軽減対象外です。販売に通常必要な容器への取り分けは、このサービスには含みません。
