親の扶養控除【令和8年分】年金収入の条件・老人扶養親族と年末調整

公開日: 2026年10月23日（更新日: 2026年10月24日）

文責: Masahiro Yasu（クリニック・EC事業の経営者／経理実務者）

親は、別居でも生計を一にし、所得などの要件を満たせば扶養控除の対象になります。年末調整では、課税される公的年金の収入から所得を計算して確認します。

この記事は、国内に住む親を申告する会社員と、申告書を確認する給与担当者向けです。所得税の控除額と、親に確認する事項を表で整理します。税負担の試算は扶養控除シミュレーター、住民税の額は住民税の扶養控除で確認できます。

親の区分と扶養控除額

親の扶養控除は、所得から差し引く額です。表の金額がそのまま還付されるわけではありません。

下表は、令和8年分の所得税で、扶養控除の要件を満たす国内居住の親について、申告する居住者の所得から控除する額です。同じ判定時点で、親を他の所得者と重複して申告できません。老人扶養親族は本年12月31日時点で70歳以上の控除対象扶養親族で、本人・親の年内の死亡や本人の所定の出国はその時点で年齢を判定します。

親の扶養控除額と区分
区分所得税の控除額
一般の控除対象扶養親族（特定・老人以外）38万円
老人扶養親族（同居老親等以外）48万円
老人扶養親族（同居老親等）58万円

所定の出国とは、納税管理人の届出をせず国内の住所・居所を失う場合です。同居の区分・例外は下の確認表で判定してください。年末までに異動があれば年末調整のやり直しを確認します。

根拠は所得税法84条と、租税特別措置法41条の16です。自分の親だけでなく、配偶者の父母も、扶養親族としての要件を満たせば対象です。

親を扶養に入れる条件

親子という関係だけでは足りません。国内に住む親について、生活費を共通にしているかと、親自身の所得を確認します。

確認すること判断のポイント
生計を一にしている生活費や療養費を共通にしている。同居は必須ではない
親の所得が上限以下令和8年分の改正後の要件は、親の年間の合計所得金額が62万円以下
事業専従者の除外に当たらない青色事業専従者としてその年を通じて給与を一度も受けておらず、白色事業専従者でもない
同じ時点の所属同じ判定時点で、他の所得者の扶養親族・同一生計配偶者に重複していないか確認する

改正後の所得要件は令和8年12月1日以後の令和8年分の年末調整で使います。本年最後の給与が11月30日以前で、改正前の年末調整を受けた場合は、改正の適用を確定申告等で確認してください。

国外に住む親には年齢や確認書類の追加条件があります。この記事の国内の表だけで判断せず、扶養控除シミュレーターの要件説明と国税庁「年末調整のしかた」の国外居住親族の項目を確認してください。

年金収入だけの親の所得を確認する

年金の振込額ではなく、年間の公的年金等の収入額から所得を求めます。公的年金等に係る雑所得は、収入金額から公的年金等控除額を差し引いて計算します。

下表は、令和8年分の改正後の所得要件について、公的年金等に係る雑所得だけの国内居住の親の収入上限です。非課税の遺族年金・障害年金は含めません。年齢は本年12月31日の現況で判定し、本人・親の年内の死亡や本人の所定の出国はその時点で判定します。ほかに所得がある場合は、この表を使わず合計所得金額で確認します。

公的年金等だけの親の収入上限
判定時点の年齢年間の公的年金等の収入額
65歳以上172万円以下
65歳未満122万円以下

これは親の所得要件を確かめる表です。生計を一にすることや専従者除外など、ほかの要件も満たす必要があります。年金に加えて給与や不動産収入などがある場合は、それぞれの所得を計算して合計します。

所得欄に基礎控除を引いた額を書かない

扶養の判定に使う合計所得金額は、基礎控除や社会保険料控除を差し引く前の額です。親本人に所得税がかからなくても、子の扶養控除の所得要件を満たすとは限りません。

主な除外例として、非課税の遺族年金・障害年金や、申告しないことを選択した一定の上場株式等の配当・源泉徴収選択口座内の譲渡所得は、合計所得金額に含めません。繰越損失を使う場合は、その繰越控除を適用する前の額で確認します。

老齢年金と遺族年金を受け取っている親なら、まず年金の種類を分けて確認します。年金収入の全額を所得見積額欄へ書き写したり、非課税年金まで足したりしないようにします。計算区分は国税庁No.1600「公的年金等の課税関係」、所得に含めないものは国税庁No.1180のQ&Aで確認できます。

別居・入院・老人ホームの確認表

別居は扶養控除の対象外という意味ではありません。所得要件などに加え、生計を一にしている実態を確認します。同居老親等に当たるかは、扶養の対象になるかとは分けて判断します。

下表は、扶養控除の要件を満たす国内居住の親について、生計や同居の状況を確認する表です。同居老親等の行は、老人扶養親族で本人か配偶者の直系尊属に当たる親が対象です。同居老親等に当たるかは年末調整日の現況で確認します（親が年中に死亡した場合は死亡時）。年末までの異動はやり直しを確認します。

親の状況確認する扱い
別居し、継続して生活費等を仕送り生計を一にしていれば扶養控除の対象となり得る。入院・別棟は下の行で確認
普段は本人か配偶者と同居し、治療のため入院長期の入院でも、同居を常況としていた親は同居老親等に当たる
老人ホームへ入所施設が居所になるため同居老親等には当たらない。扶養控除自体の要件は別に確認
同じ敷地の別棟に住む食事を一緒にするなど日常生活を共にしていれば、同居老親等に当たる
本人の転勤に伴い、親が本人・配偶者のいずれとも別居同居老親等には当たらない

同じ家に住んでいても、明らかに独立した生活を営んでいる場合は、生計を一にする扱いにはなりません。別居の親への送金は、生活費・療養費の振込記録を整理し、勤務先から確認を求められたときに説明できるようにします。

国内別居の親について、送金の証明書類の提出が法令上一律に必要というわけではありません。国税庁は、勤務先が振込票などの提示を受けて確認することを案内しています（No.1180 Q&A「地方に住む両親」）。

兄弟と親の所属を確認する

兄弟が同じ親に仕送りをしていても、年末時点のその親を双方の扶養控除に重複して入れることはできません。控除額を兄弟で分割するのではなく、要件を満たす所得者のうち、どちらが申告するかを確認します。

父と母はそれぞれ別に判定します。たとえば、父は兄、母は弟の扶養親族とする場合も、各人について生計や所得の要件を確かめます。同じ判定時点で父が母を配偶者控除の対象としている場合は、母を子の扶養控除に重ねて入れないよう確認します。

親の配偶者が年の途中で死亡したり所定の出国をしたりした場合は、その時と年末で判定が分かれることがあります。同じ時点の重複確認と区別し、No.1180 Q&A「年の中途で死亡した夫の控除対象配偶者とされた妻」を確認してください。

年末調整で親を申告する手順

扶養控除の要件を満たす親は、扶養控除等申告書のB欄で申告します。親の年間所得の見込みと、老人扶養親族の区分を確かめてから提出します。

  1. 親の年間所得を確認する。公的年金の源泉徴収票などで種類と収入額を確認し、年末調整日の現況で年間の合計所得金額を見積もります。
  2. 生計と申告者を確認する。別居なら生活費等の送金状況を確認し、親の所属を兄弟や親の配偶者とすり合わせます。
  3. B欄に親の情報を書く。氏名・続柄・生年月日・住所や居所・本年中の合計所得金額の見積額などを、勤務先の案内に沿って記入します。
  4. 老人扶養親族の欄を確認する。該当する親は「同居老親等」か「その他」かを選び、勤務先へ提出します。

改正で新たに対象になる親がいる場合も、申告書の提出が必要です。令和8年分の年末調整で改正により新たに対象となる親は、「異動月日及び事由」欄に「令和8年12月1日 改正」などと記入します（国税庁の改正Q&A Q2-1）。用紙全体の記入例、個人番号、他の所得者が控除を受ける親族の欄は、扶養控除等申告書の書き方で確認してください。

健康保険の被扶養者の手続きは別です。税の申告書へ親を書くだけでは健康保険の扶養には入りません。収入の見方や必要な手続きは社会保険の扶養に入る条件を確認してください。

この記事のまとめ
  • 親の扶養控除は、生活費の負担、親の所得、家族の申告との重複を確認する。
  • 公的年金は収入額から所得を計算し、所得見積額欄へ収入のまま転記しない。
  • 同居老親等は、治療入院と老人ホーム入所で扱いが異なる。

よくある質問

別居の親も扶養控除の対象になりますか？

対象になり得ます。国内に住む親に継続して生活費等を仕送りし、生計を一にしている場合は、所得要件や事業専従者の除外なども満たせば扶養控除の対象です。治療入院や同じ敷地の別棟で生活する場合は、同居の判定表も確認してください。

親が遺族年金を受け取っていても申告できますか？

非課税の遺族年金は、扶養判定に使う合計所得金額に含めません。ほかに老齢年金や給与などがあれば、それらの所得を確認します。生計や専従者除外などの要件を満たし、他の人の申告と重複していなければ対象です。

親が老人ホームに入ると扶養控除はなくなりますか？

入所だけで扶養控除がなくなるわけではありません。生計や所得などの要件を満たせば対象です。ただし、老人ホームが居所になるため、同居老親等としては扱いません。

兄弟で同じ親の控除を分けられますか？

同じ判定時点で、親の扶養控除を兄弟で分割したり、重複して適用したりはできません。双方が仕送りしている場合も、要件を満たす所得者のうち、どちらの扶養親族として申告するかを確認してください。
