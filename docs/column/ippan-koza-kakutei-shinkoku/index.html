一般口座の確定申告：複数回購入の取得費・売却費用・税額を自分で検算

公開日: 2026年10月19日

文責: Masahiro Yasu（クリニック・EC事業の経営者／経理実務者）

一般口座で上場株式を売った年は、売却ごとに「譲渡価額−（取得費＋委託手数料等）」を自分で計算し、年間で合計します。申告が要るかは、その合計などで決まります（申告の要否）。同じ銘柄を何回かに分けて買っていれば、取得費は総平均法に準ずる方法で出した1株当たりの金額から求めます。

この記事は、居住者が証券会社を通じて上場株式等を売買した令和8年分を前提に、設例で1株の単価から税額までを順に検算します。特定口座の年間取引報告書がある取引は特定口座（源泉徴収あり）の記事で扱います。

計算に使う記録と式

特定口座の中の取引は証券会社が区分して計算しますが、一般口座は特定口座の外なので、約定ごとの取引報告書から自分で数字を集めます（国税庁「特定口座制度」）。

一般口座の申告で集める記録
記録拾う数字計算での使い道
買付の取引報告書約定日・株数・約定代金・手数料（税込）取得費のもとになる購入価額
売付の取引報告書約定日・株数・約定代金・手数料（税込）譲渡価額と委託手数料等
株式分割・併合などの通知割当ての比率と効力の発生日1株当たりの金額の調整
相続・贈与の記録前の持ち主の取得費がわかる資料引き継ぐ取得費
NISAからの移管の記録移管の日と、その日の終値移管した株の取得費

計算式は「譲渡価額−（取得費＋委託手数料等）＝譲渡所得等の金額」です（国税庁「株式等を譲渡したときの課税（申告分離課税）」）。取得費には購入代金のほか、購入手数料とその消費税も含めます（国税庁「譲渡した株式等の取得費」）。

複数回購入の取得費：総平均法に準ずる方法

同じ銘柄を2回以上に分けて買い、その一部を売ったときは、売るたびに次の記号で1株当たりの金額を出します（国税庁「同一銘柄の株式等を2回以上にわたって購入している場合の取得費」）。種類と銘柄ごとに分けて計算します。株式分割・併合などがあった銘柄は、1株当たりの金額を調整します（No.1464）。

総平均法に準ずる方法の記号
記号中身
A最初に買った時の購入価額の総額。既に売っていれば、直前の売却時の単価×残った株数
BA の時点の後から今回の売却までに買った購入価額の総額
C・DA・B に対応する株数

1株当たりの金額は（A＋B）÷（C＋D）で、国税庁の計算例では1円未満の端数を切り上げています。2回目以降の売却では、直前の売却時の1株当たりの金額×残った株数を A に使います。

この式で国税庁の計算例（手数料なし）を計算し直すと、1回目の売却の単価は815円・取得費2,445,000円、2回目は846円・取得費5,076,000円となり、国税庁の数字と一致します。

設例：2回の売却で取得費と譲渡益を検算

設例は架空の1銘柄を一般口座で売買した場合です。2025年に2回買い、2026年（令和8年分）に2回売り、その間に1回買い増したとします。設例の手数料は売買とも1回1,100円（税込）で、株式分割などはない前提です。

ずれやすい3点

  • 購入手数料は取得費に、売却手数料は委託手数料等に入れる。同じ手数料を二重に引かない
  • 1株当たりの金額の端数は切り上げる（国税庁の計算例）

令和8年分の税額を検算する

令和8年分の上場株式等の譲渡所得等の税率は所得税15%・住民税5%で、所得税には基準所得税額の2.1%の復興特別所得税が加わります（国税庁「株式等を譲渡したときの課税（申告分離課税）」）。

国税の課税標準は千円未満の端数を切り捨てるので、設例の217,050円は217,000円になります（e-Gov法令検索「国税通則法」118条）。

次の表は設例の令和8年分の算出額です。所得控除はすべて給与などの所得から引ける前提で、源泉徴収・税額控除を精算する前の額です。

設例の令和8年分の算出額
税目計算算出額
所得税217,000円×15%32,550円
復興特別所得税基準所得税額の全体×2.1%この分だけなら683.55円
住民税の所得割（翌年度）217,000円×5%10,850円の見込み

復興特別所得税は給与などを含む基準所得税額の全体に2.1%を掛けて1円未満を切り捨てるので、設例の株式分だけの683.55円は目安です（端数処理は令和7年分の手引きの記載）。住民税は市区町村が計算します。

損失が出た年と特定口座との関係

一般口座で売った上場株式は「上場株式等」の区分に入ります。口座の名前は一般でも、非上場株式などの「一般株式等」とは別の区分です。上場株式等の損失は一般株式等の利益から引けず、一般株式等の損失も原則として上場株式等から引けません（国税庁No.1463）。

一般株式等の損失の例外は、エンジェル税制の対象となる特定中小会社の株式の一定の損失です（国税庁No.1465）。

次の表は、令和8年分に一般口座で証券会社を通じて上場株式等を売り、損失が出た場合の扱いです（国税庁「上場株式等に係る譲渡損失の損益通算及び繰越控除」）。

上場株式等の譲渡損失の扱い
やりたいこと扱い
上場株式等の配当と通算確定申告でできる。配当は申告分離課税を選んだものに限る
翌年以後への繰越3年間できる。損失の年から連続して申告し、売らなかった年も申告する
一般株式等の利益と相殺できない。繰り越した損失も同じ
相対取引・NISA内の損失通算も繰越もできない

源泉徴収ありの特定口座は口座ごとに申告するかを選べますが、一般口座の損益と相殺するなら、その特定口座の所得も申告に含めます。その特定口座の損失を申告するときは、口座で受け入れた配当等も申告に含めます（国税庁No.1476）。

申告が要るかの確認と取得費が分からないとき

給与を1か所から受け、その全部が源泉徴収の対象で、給与収入が2,000万円以下の人は、給与・退職所得以外の所得金額の合計が20万円以下なら所得税の確定申告が要りません。同族会社の役員で貸付金の利子などを受け取る人、源泉徴収義務のない者から給与を受ける人、災害減免法で源泉徴収の猶予などを受けている人などは、20万円以下でも申告が要ります（国税庁「給与所得者で確定申告が必要な人」）。

源泉徴収ありの特定口座で申告しないことを選んだ所得や、申告しないことを選んだ上場株式等の配当は、この合計に含めません。

給与以外の所得の20万円は売却代金ではなく、取得費と手数料を引いた後の所得金額で見ます。給与以外の所得が設例の217,050円だけでも20万円を超えるので、その給与所得者は申告が要ります。

給与を2か所以上から受ける人、公的年金等を受け取る人などは条件が違います。所得税の申告が要らない場合も住民税の申告は別に確認し、損失を繰り越すなら申告します。

令和8年分の確定申告期間は、原則として2027年2月16日（火）から3月15日（月）までです（国税庁「確定申告」）。

取得費が分からないとき

令和8年分の申告で取得費が分からない銘柄は、同一銘柄ごとに売却代金の5%を取得費にすることも認められ、300万円で売った銘柄なら15万円です（国税庁No.1464）。

相続・贈与で受け取った株式は、前の持ち主の取得費を引き継ぎます。ただし、NISA内の株式が相続・贈与で払い出された場合は、原則として相続開始日・贈与の日の終値に相当する金額です。NISA口座から一般口座へ移した株式は、移管の日の終値に相当する金額が取得費です。

給与などの総合課税の所得税は計算機で試算できます。株式の譲渡所得は計算機の対象外なので、この記事の手順で別に計算します。

所得税計算機で給与などの所得税を試算する（株式の譲渡所得は対象外）

まとめ
  • 上場株式等と一般株式等を分け、売却ごとに譲渡価額−（取得費＋委託手数料等）を計算して区分ごとに年間で合計する
  • 同じ銘柄の取得費は、売るたびに混ぜ直した1株当たりの金額（端数は切り上げ）で出す。分割・併合などがあれば単価を調整する
  • 上場株式等の損失を繰り越すなら、売らなかった年も続けて申告する

よくある質問

会社員が一般口座で利益を出したら確定申告は必要ですか？

給与を1か所から受けその全部が源泉徴収の対象で、給与収入が2,000万円以下の会社員なら、給与・退職所得以外の所得金額の合計が20万円を超えるときに所得税の申告が必要です。20万円以下なら所得税の申告は不要ですが、住民税の申告は別に確認します。同族会社の役員などは条件が違います。

同じ銘柄を何度も買ったとき、取得費はどの単価で計算しますか？

売るたびに総平均法に準ずる方法で出した1株当たりの金額を使います。直前の売却時の1株の単価×残りの株数と、その後の購入価額を足し、株数の合計で割ります。国税庁の計算例では1円未満の端数を切り上げています。株式分割・併合などがあった銘柄は、1株当たりの金額を調整してから計算します。

一般口座の損失を特定口座の利益と相殺できますか？

上場株式等どうしなら確定申告で相殺できます（相対取引やNISA内の損失を除く）。源泉徴収ありの特定口座の利益と相殺するときは、その特定口座の所得も申告に含めます。
