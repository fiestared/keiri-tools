銀行別 振込手数料 一覧【2026年9月更新】三菱UFJ・みずほ・ゆうちょ等30区分を比較

公開日: 2026年7月13日 ／ 最終更新: 2026年9月30日

文責: Masahiro Yasu（クリニック・EC事業の経営者／経理実務者）

振込手数料は「銀行名」だけでは決まりません。銀行によっては個人口座と法人口座で3〜4倍違うためです。三菱UFJ銀行の他行宛ネット振込で3万円以上なら（三菱UFJ信託銀行・auじぶん銀行あてとメインバンク プラスの無料優遇を除く）、個人の三菱UFJダイレクト220円に対し法人のBizSTATION660円。この差は調べるまで気づきにくく、比較記事も個人向けに偏りがちです。

そこでメガバンク・ネット銀行・地方銀行・ゆうちょの個人15区分＋法人15区分＝30区分について、他行宛の振込手数料（税込）を一覧にしました。先に結論を3つ書きます。

通帳や請求書で見た金額のほうが先に分かっている場合（「この605円はどこの銀行？」）は金額から逆引きへ、銀行名が決まっている場合は銀行別へ直接どうぞ。

この記事でわかること
  • 他行宛・会員優遇を除く通常料金で全件3万円以上なら、GMOあおぞら法人100円と三菱UFJのBizSTATION660円は6.6倍差。他行宛・会員優遇を除く通常料金でGMOあおぞら法人100円と三菱UFJのBizSTATION660円を比較し、全件3万円以上・年120件なら、振込手数料のみで年6万7,200円の差になります
  • 掲載ネット振込の対象サービス・通常料金で照合できた27区分では、3万円境界あり11区分・定額16区分です。未確認の3区分は集計から除いています
  • 境界を確認できた11区分は三菱UFJ・三井住友・千葉・福岡の掲載ネット振込の個人と法人、みずほ法人EB、横浜法人EBの通常振込（再振込を除く）、楽天法人の基本振込（給与・賞与・総合振込を除く）。GMOあおぞら法人は定額ですが、楽天法人の基本振込は他行宛3万円未満150円・以上229円です

境界があると何が起きるか

この段差は、振込手数料を先方負担にする（請求額から手数料を差し引いて振り込む）ときに厄介です。差し引いた結果、振込金額が3万円を割り込むと、適用される手数料区分そのものが変わってしまうからです。

たとえば請求額30,200円を三菱UFJのBizSTATIONから他行宛へ、手数料を手動で差し引いて先方負担で振り込む場合、「3万円以上だから660円」と考えて差し引くと振込額は29,540円になり、振り込んだ瞬間に3万円未満（484円）の区分に落ちます。どちらの手数料で差し引くのが正しいかは銀行ではなく取引先との合意（差引方式）で決まり、方式は3種類あります。

一方、金額による料金差がないことを利用銀行・契約サービスで確認できた場合は、この境界による差は生じません。金額がいくらでも手数料は同じなので、差引方式の違いが結果に影響しないためです。先方負担の差引額を確認するときは、振込金額が料金の境界をまたぐか確認してください。

法人口座の振込手数料が一番安い銀行は？

本記事で料金を照合できた法人区分の、無料回数・会員優遇・別料金の宛先を除くネット振込単価（SMTBは総合振込・提携サービスを除く2026年10月1日以後受付の通常振込で、予約も受付日時点の料金）では、GMOあおぞらネット銀行の法人口座とドコモSMTBネット銀行（旧 住信SBIネット銀行）の法人口座が、金額にかかわらず100円で最安です。ドコモSMTBネット銀行の法人の他行宛振込手数料は、総合振込・提携サービスを除く通常振込で、2026年10月1日以後の受付（予約も受付日時点）から金額にかかわらず100円（税込）となり、GMOあおぞらの通常料金と同額になりました。提携サービスではサービス・特典等が異なる場合があります。提携サービスを除き、総合振込サービスは改定対象外で、予約振込は予約受付日時点の料金が適用されます。次いでフィンサーバンクが110円（月額0円のフリープラン）、ラクスルバンクのGMOあおぞら以外の金融機関宛が119円、PayPay銀行法人の通常他行宛が145円（残高優遇・口座開設月の翌々月末まで毎月5回無料を除く）です。ただし前述のとおり、月額基本料や無料回数まで含めた総額で比べる必要があります。

振込手数料はなぜ3万円で変わるのですか？

旧銀行間手数料の金額区分に沿ってきた料金体系が、一部銀行の顧客向け手数料に残っているためです。銀行間の費用は2021年10月に金額不問の原則一律へ移行しています。本記事で掲載ネット振込の対象サービス・通常料金で照合できた27区分では、3万円境界あり11区分・定額16区分です。

この一覧に無料回数の特典は含まれますか？

含まれていません。他行宛・税込の特典を適用しない料金を比較しています。個人のドコモSMTBネット銀行では（BaaS・提携サービスは条件が異なる場合があります）スマプロランクに応じて無料回数が決まり、三井住友信託銀行以外への振込は無料回数以降77円です。対象口座・無料回数・通常単価・月額基本料を合わせて比較してください。

消費税はかかりますか？

国内の通常の振込手数料は課税取引で、掲載した通常料金は税込です（ゆうちょ銀行の非居住者関連の料金は消費税を含みません）。なお、先方負担で差し引かれた手数料相当額を売手が支払手数料として処理する場合、インボイス制度のもとでは金融機関の適格請求書が手元に無い形になるため、実務上は「売上に係る対価の返還等」（値引き）として処理する方法が広く採られています。

ドコモSMTBネット銀行の法人の他行宛振込手数料は、総合振込・提携サービスを除く通常振込で、2026年10月1日以後の受付（予約も受付日時点）から金額にかかわらず100円（税込）となり、GMOあおぞらの通常料金と同額です。提携サービスではサービス・特典等が異なる場合があります。提携サービスを除き、総合振込サービスは改定対象外で、予約振込は予約受付日時点の料金が適用されます。出典：同行の2026年9月2日発表（資料取得日：2026年9月30日）。上記の料金表は、提携サービスを除く法人通常振込について2026年10月1日以後の受付に適用する100円を反映しています。
