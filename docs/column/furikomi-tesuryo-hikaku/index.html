銀行別 振込手数料 一覧【2026年10月更新】三菱UFJ・みずほ・ゆうちょ等30区分を比較

公開日: 2026年7月13日 ／ 最終更新: 2026年10月15日

文責: Masahiro Yasu（クリニック・EC事業の経営者／経理実務者）

振込手数料は「銀行名」だけでは決まりません。同じ銀行でも、個人口座と法人口座で3〜6倍違うことがあるためです。たとえば三菱UFJ銀行の他行宛ネット振込で3万円以上なら（三菱UFJ信託銀行・auじぶん銀行あてと優遇を除く）、個人の三菱UFJダイレクトは220円、法人のBizSTATIONは660円です。この差は調べるまで気づきにくく、比較記事も個人向けに偏りがちです。

そこでメガバンク・ネット銀行・地方銀行・ゆうちょの個人15区分＋法人15区分＝30区分について、他行宛の振込手数料（税込）を一覧にしました。先に結論を3つ書きます。

この記事でわかること
  • 料金を照合できた区分の通常料金は、個人75円〜440円、法人100円〜660円です
  • 法人の年間負担は、BizSTATIONとGMOあおぞら法人の比較表で確認できます
  • 掲載額を集計した29区分では、3万円境界あり11区分・定額18区分です（掲載額を確認できていないイオン銀行の個人を除く）。境界のある区分は「3万円の境界」にまとめています

通帳・請求書の金額（「この605円はどこの銀行？」）は金額から逆引きへ。銀行名が分かる場合は一覧の銀行名から銀行別へ進めます。

この段差は、振込手数料を先方負担にする（請求額から手数料を差し引いて振り込む）ときに厄介です。差し引いた結果、振込金額が3万円を割り込むと、適用される手数料区分そのものが変わってしまうからです。

なお605円は税込額で、税抜に直すと550円です（本記事の通常の国内円建て振込手数料は課税取引）。通帳や明細で550円と605円のどちらの表記を見ているかで、同じ取引でも金額が違って見えます。

法人口座の振込手数料が一番安い銀行は？

GMOあおぞら法人の通常料金は他行宛ネット振込100円です（振込料金とくとく会員を除く）。ドコモSMTB法人も他行宛ネットの通常振込は100円です。2026年10月1日以後の受付が対象で、総合振込・提携サービスを除き、予約も受付日時点の料金です。本記事で料金を照合できた法人区分の他行宛ネット振込で、無料回数・会員優遇・別料金の宛先を除く比較です。ドコモSMTBの適用日・対象は銀行別の節へ。

次いでラクスルバンクのGMOあおぞら以外の金融機関宛が119円、PayPay銀行法人の通常他行宛が145円です。PayPayの優遇・無料回数は銀行別の節へ。フィンサーバンクの110円は税込額での順位に入れていません。月額基本料や無料回数を含めた総額で比較してください。

振込手数料はなぜ3万円で変わるのですか？

旧銀行間手数料の金額区分に沿ってきた料金体系が、一部銀行の顧客向け手数料に残っているためです。一般振込の銀行間手数料は2021年10月に内国為替制度運営費へ移行しています。本記事で掲載ネット振込の掲載額を集計した29区分では、3万円境界あり11区分・定額18区分です（掲載額が未確認のイオン銀行の個人を除く）。

この一覧に無料回数の特典は含まれますか？

含まれていません。他行宛・税込の特典を適用しない料金を比較しています。個人のドコモSMTBネット銀行では（BaaS・提携サービスは条件が異なる場合があります）スマプロランクに応じて無料回数が決まり、当社・三井住友信託銀行以外への振込は無料回数以降77円です。対象口座・無料回数・通常単価・月額基本料を合わせて比較してください。

消費税はかかりますか？

国内の通常の振込手数料は課税取引で、掲載した通常料金は税込です（フィンサーバンクの110円は、公式の料金表に税込・税抜の表記がありません）。ゆうちょ銀行の非居住者関連の料金（窓口1回7,500円、ゆうちょダイレクト等1回3,000円）は、公式の送金料金のページで「消費税は含みません」と案内されています。なお、先方負担で差し引かれた手数料相当額を売手が支払手数料として処理する場合、インボイス制度のもとでは金融機関の適格請求書が手元に無い形になるため、実務上は「売上に係る対価の返還等」（値引き）として処理する方法が広く採られています。
