学資保険の税金｜一括・分割・別人受取の課税額を検算

公開日: 2026年10月21日

文責: Masahiro Yasu（クリニック・EC事業の経営者／経理実務者）

学資保険の受取時の税金は、実際に保険料を負担した人と受取人が同じか、学資金を一時金・年金のどちらで受け取るかで変わります。被保険者が生存している満期金は、本人負担・本人受取なら所得税、別人受取なら贈与税の対象です。

本人が受け取る場合も、年金形式は一時金と同じ計算にはなりません。以下では、生存時の学資金について分類を確認し、一括受取・年をまたぐ受取・夫負担で妻が受け取る例を検算します。

払込時の保険料控除は年末調整の学資保険で扱います。本記事の基準日は2026年10月21日で、税額の設例は令和7・8年分です。

最初に負担者と受取方法を分ける

日本の居住者個人が、生存時の学資金を受け取る場合の分類です。保険料の負担者は単独で生存しているものとし、契約者名ではなく実際の負担者を確認します。死亡給付・権利の相続・複数人負担・法人負担はこの表の対象外です。

生存時の学資金の受取区分
負担者と受取方法税の扱い
本人負担・本人が一時金で受取総合課税の一時所得。ただし、金融類似商品の源泉分離課税は別扱い
本人負担・本人が年金で受取公的年金等以外の雑所得。各年の給付に対応する保険料を差し引く
他人負担・別人が一時金で受取贈与税。本人受取の一時所得の計算は使わない
他人負担・別人が年金で受取年金受給権に贈与税。各年の年金の所得税は課税部分・非課税部分に分けて計算

区分の根拠は国税庁No.1755です。他人負担の年金は、贈与税の納付額が生じなくても、各年の年金を課税部分・非課税部分に分けます。

主な対象外は、一定の一時払養老保険等で源泉分離課税となる差益、死亡による保険金、保険料負担者の死亡による契約の権利承継です。後の満期金だけを見て分類せず、死亡給付は死亡保険金の記事、契約の相続は税務署等で確認してください。

一括受取の計算例

本人負担・本人受取で総合課税となる一時所得は、年間合算した収入から対応支出を引き、特別控除は残額を上限に最高50万円、その控除後の2分の1を総所得金額へ加えます。

次の表は、学資金だけを受け取る場合と、同じ年に業務に無関係な懸賞金も受け取る場合です。保険ごとに特別控除を引く計算にはしません。

令和8年分の設例です。居住者本人が全額負担した学資金を一時金で受け取り、総合課税とします。受取前の課税総所得は表の額に固定し、所得控除の変化・税額控除・損益通算・分離課税所得・高額所得者特例はありません。他の一時所得は表の懸賞のみで、懸賞の直接支出はありません。税額は所得税本体のみで、復興特別所得税・住民税・源泉徴収税額は含めません。

課税総所得の千円未満を切り捨てて速算表を適用しますが、本例にその端数はありません。加算額は税額ではありません。

総合課税の税額は、給与等から計算した所得や所得控除と合わせて決まります。表の差額を自分の受取額に比例させる計算はできません。一般の一時所得の範囲・損失の扱いは一時所得の記事を参照してください。

年金受取の計算例

複数年の受取に、一時所得の特別控除を毎年使えるとは限りません。国税庁「数年間にわたり支払を受ける保険金」は、契約者・受取人が本人のこども保険で、契約上、所定期間に毎年定額を支払う教育資金・満期保険金を雑所得としています。

この事例の所得は、それぞれの給付から対応保険料を引いた金額です。商品名が学資保険であることや、入金が数回あることだけでは分類できません。

令和7・8年分の年金受取の設例です。居住者本人が全額負担し本人が受け取り、各年の通知に表の対応保険料が記載されると仮定します。各年とも受取前の課税総所得は表の額に固定し、所得控除の変化・税額控除・損益通算・分離課税所得・高額所得者特例はありません。税額は所得税本体のみで、復興特別所得税・住民税・源泉徴収税額は含めません。

本人負担の年金では、総払込保険料を毎年重ねて引かず、その年の給付に対応する額を使います。将来の年金総額に代わる一時金は、一時所得です（本人が保険料を負担し年金を受け取る場合、国税庁No.1610）。

別人受取：差益ではなく保険金から計算

夫が保険料を全額負担し、生存時の満期金を妻が一括で受け取るなら、妻の贈与税の対象です。妻の一時所得として夫の払込保険料を差し引く計算にはしません。

令和8年分の暦年課税の設例です。国内の居住者の夫が全額負担した生存時の満期金を、居住者の妻が一括受取します。夫は生存し、妻の同年の他の贈与はなく、配偶者控除等の特例を使わない一般税率です。相続時精算課税、年金受給権の贈与は対象外です。

夫負担・妻一括受取の贈与税の設例
計算段階金額・式
妻が受け取る満期金3,000,000円
暦年課税の基礎控除1,100,000円
基礎控除後の課税価格3,000,000−1,100,000＝1,900,000円
一般税率を適用1,900,000×10%＝190,000円

令和8年分の贈与税の基礎控除は暦年課税では受け取る人の年間合計に対し110万円です。上の表は夫婦間の一般税率で、親から子への特例税率を使う表ではありません（国税庁No.4408）。

通知書と支払履歴で確認する項目

通帳の入金額だけでなく、契約内容・保険料の支払履歴・支払通知をそろえます。申告用のメモは、次の順で作ると照合できます。

  1. 保険料を実際に負担した人と、学資金を受け取る人を記録する。
  2. 契約上の受取方法を確認し、一時金・連年給付・年金受給権を分ける。
  3. 年ごとに収入・対応保険料・源泉徴収税額を別欄に転記する。配当金や過去の給付があれば、通知の内訳と履歴も照合する。
  4. 同年の他の一時所得や雑所得、贈与を集計し、年末調整済みの給与等と分けて申告の要否を確認する。

源泉徴収されなかったことや、一定の給与所得者の申告不要に当たることは、非課税と同じ意味ではありません。給与所得者の判定条件は国税庁No.1900で確認してください。

受取時は、負担者・受取方法・年ごとの対応保険料を先に確認します。払込時の年末調整とは分け、学資金の受取額をそのまま税額や所得と読み替えないことが確認の要点です。

よくある質問

分割で受け取れば、毎年一時所得として計算できますか？

受取回数だけでは決まりません。契約者・受取人が本人で、所定期間に連年定額で支払うこども保険を雑所得とする国税庁事例があります。契約と通知で区分を確かめ、給付に対応する保険料を差し引きます。

契約者名が自分なら、本人負担として計算できますか？

名義だけでは決められません。生存時の満期金は、実際の保険料負担者と受取人が同じかで所得税・贈与税を分けます。家族が負担した期間が混在する契約は、本記事の単独負担の設例から外れます。

学資金を受け取ったら、会社の年末調整に入れますか？

学資金の受取による一時所得や雑所得は、給与の年末調整で精算するものではありません。払込保険料の生命保険料控除と区別し、他の所得も含めて確定申告の要否を確認します。
