退職手続きの会社側チェックリスト

公開日: 2026年10月18日

文責: Masahiro Yasu（クリニック・EC事業の経営者／経理実務者）

会社側の退職手続きは、保険の資格喪失、住民税の異動、本人への書類交付、翌年の給与支払報告を期限別に管理します。まず退職日と加入保険を確かめ、下の一覧で担当者・提出先・完了日をそろえてください。

このページは会社の給与・総務担当者向けの総覧です。書類の記入方法や退職理由の判断は、各行のリンク先で確認できます。

会社側の期限・提出先一覧

以下は、所得税の源泉徴収義務がある会社で、協会けんぽ・厚生年金保険と雇用保険に加入していた一般の従業員が、年の途中に生存退職する場合です。船員、死亡退職、任意喪失、継続再雇用の同日得喪は含めません。給与の源泉徴収票は居住者への交付を扱います。

中途退職者について会社が管理する主な期限
手続き・対象期限・起算点提出・交付先根拠
健康保険・厚生年金保険の資格喪失届資格喪失の事実発生（通常の退職では退職日の翌日）から5日以内日本年金機構の事務センターまたは管轄の年金事務所健康保険法施行規則29条・厚生年金保険法施行規則22条
雇用保険の資格喪失届被保険者でなくなった事実のあった日の翌日から起算して10日以内事業所所在地を管轄するハローワーク雇用保険法施行規則7条
給与所得の源泉徴収票の本人交付中途退職の日以後1か月以内（税務署長の承認による例外を除く）退職者本人。行政への提出とは別に交付する所得税法226条

給与支払報告書（その会社からの退職年中の給与総額が30万円を超える中途退職者）退職年の翌年1月31日まで退職時の住所地の市区町村地方税法317条の6第3項

行政への上表の届出・提出期限が土日祝日・年末年始の休日に当たる場合は、別段の定めがある場合を除き、休日後の開庁日が期限です。源泉徴収票の本人交付は行政提出と分けて管理してください。

表の住民税の異動届と、給与支払報告書の提出後に退職等があった場合の届出は別の手続きです。転職先で特別徴収を続けるときも新勤務先との連携が必要です。新年度分の異動や継続の期限は、納入先市区町村の案内で確認してください。

給与支払報告書の提出範囲・みなし提出の扱いは給与支払報告書の書き方と提出先で確認できます。

退職前に確認すること

退職日、最終出勤日、保険の資格喪失日を分けて記録します。有給休暇を使ってから退職する場合、最終出勤日を退職日として届出しないようにしてください。

  • 退職日と最終出勤日を確認し、勤怠・給与計算の担当者に共有する。
  • 加入している健康保険・厚生年金保険・雇用保険を確認する。
  • 退職後の送付先、連絡先、書類の受渡方法を本人と確認する。
  • 住民税の残額と、転職先での特別徴収継続の希望を確認する。
  • 資格確認書などの交付状況と、会社で預かっている本人の書類・貸与物を確認する。

雇用保険の資格取得が退職日までに確認済みで、離職日に59歳未満かつ本人が離職票を希望しない場合は、資格喪失届に離職証明書を添えないことができます。資格喪失届そのものを省略する扱いではありません。

退職の意思表示や有給休暇の扱いは、退職届・退職願の書き方と退職時の有給消化で確認してください。

資格喪失届と回収書類

雇用保険の離職手続きも、会社からハローワークへの届出期限と、離職票が本人に届く時期を分けて管理します。

離職票と離職証明書は別の書類です。書類の違い、離職理由の確認、本人への受渡しは離職票の手続きにまとめています。

協会けんぽで資格確認書を交付された従業員の生存退職では、会社が資格喪失時に遅滞なく回収し、資格喪失届に添えて返納しますが、やむを得ず同時添付できない場合は理由を付記し、紛失等で回収できない場合は資格確認書回収不能届を添付します。

協会けんぽでは、交付されている高齢受給者証や限度額適用認定証なども確認してください。添付書類は日本年金機構の資格喪失手続き、書類の違いは資格確認書と資格情報のお知らせで確認できます。

健康保険組合の加入者は、組合への資格喪失手続きと回収書類も確認してください。ここで扱う協会けんぽの添付先を、そのまま組合の手続きに当てはめないでください。

住民税と源泉徴収票の分け方

給与から引いていた住民税の残額と、退職金そのものにかかる税金は別です。まず給与分の住民税の徴収方法を確認し、退職金を支払う場合は別の処理として準備します。

給与分の住民税の残額は、退職時期、本人の申出、給与・退職手当等の支払見込み、新勤務先での継続の可否によって扱いが分かれます。自由に選べるものとして案内せず、退職後の住民税の払い方で条件を確認してください。

給与分の住民税の残額について確認する方式
方式会社が確認すること
普通徴収へ切替普通徴収に切り替える対象かと、退職者本人への納付案内を確認する
一括徴収退職時期・申出と、給与や退職手当等から徴収できる額を確認する
転職先で特別徴収を継続本人の継続希望を確認し、新勤務先へ異動届を引き継ぐ

居住者の生存退職で退職金を支払う場合は、給与分と別に退職所得の源泉徴収票の手続きを確認します。給与分は給与の源泉徴収票の交付時期、退職金分は退職所得の源泉徴収票の書き方へ進んでください。

提出後の交付・完了確認

届出を出した記録と、本人へ渡した記録を別に残します。離職票を会社経由で交付する場合は、届いた書類を本人へ渡すところまで確認してください。

退職証明書は、本人から請求があれば遅滞なく交付します。本人が請求しない事項は記載できません。解雇を理由とする退職事由の証明を請求された場合は、解雇理由も含みます。証明する項目の選び方は退職証明書の交付ルールで確認してください。

社内の管理表には「手続名・担当者・期限・提出日・受付記録・本人交付日・受渡方法」を残すと、行政処理待ちと社内の未処理を見分けられます。

よくある質問

退職手続きは退職日までに終わりますか？

終わりません。資格喪失の届出や本人への書類交付に加え、提出対象となる退職者の給与支払報告書も翌年の管理に残します。上の期限一覧で、提出と本人交付を分けて確認してください。

会社が離職票を発行するのですか？

離職票を交付するのはハローワークです。会社は資格喪失届と、必要な離職証明書を提出します。会社経由で本人へ渡す場合は、会社からの受渡しまで確認します。

退職証明書と離職票は同じ書類ですか？

別の書類です。退職証明書は、本人の請求に応じて会社が退職時の事項を証明するものです。離職票は、雇用保険の手続きに使う書類としてハローワークが交付します。
