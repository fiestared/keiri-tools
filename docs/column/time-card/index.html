タイムカードの打刻漏れ・修正の手順｜実労働時間との照合と給与集計

公開日: 2026年10月22日

文責: Masahiro Yasu（クリニック・EC事業の経営者／経理実務者）

タイムカードの打刻は、労働時間を確かめるための「基礎」の記録で、打刻時刻がそのまま労働時間になるとは限りません。打刻漏れや、打刻と実際の作業がずれた日は、入退館やパソコンの記録などと照らして始業・終業時刻を確定し、修正の理由を残してから給与集計へ渡します。

この記事は、記録が食い違ったときの残し方に絞ります。出勤簿に書く項目や保存期間は出勤簿の記事で扱います。

打刻・確定時刻・修正記録を分けて残す

打刻をそのまま書き換えず、「打刻」「確定した時刻」「修正の記録」の3つを分けて持つと、後から確定の根拠を説明できます。次の表は社内運用の一例です。

食い違いがあった日に残す3つの記録（運用例）
記録中身使い方
打刻記録タイムレコーダーやICカードの時刻手を加えずに残す
確定した始業・終業他の記録と照らして確かめた時刻労働時間の集計に使う
修正記録修正前後の時刻・理由・照らした記録・確認者・確認日確定時刻の根拠として残す

厚生労働省の労働時間の適正な把握のためのガイドラインは、使用者が労働日ごとの始業・終業時刻を確認し、記録することを求めています。原則の方法は2つで、使用者が自ら現認するか、タイムカード・ICカード・パソコンの使用時間などの客観的な記録を基礎として確認し、適正に記録します。

ガイドラインの対象から外れる人（労働基準法41条の管理監督者など、みなし労働時間制の適用者）の扱いは、出勤簿の記事を確認してください。対象外の人にも、健康確保のため適正な労働時間管理を行う責務があります。

架空の1週間で照合する

打刻と他の記録が合う日はそのまま確定し、合わない日だけ理由を確かめて直します。次の設例では、5日のうち3日で確定時刻が打刻と変わりました。

この設例は架空の従業員Aの月曜〜金曜で、所定労働時間9:00〜18:00（休憩60分）の1日8時間、変形労働時間制・フレックスタイム制・労働基準法40条の特例の事業場ではない通常の労働時間制とします。休日労働・深夜労働や土日の労働はなく、時刻はすべて架空です。

月9:00／18:00パソコンの記録も同じ時間帯9:00／18:008時間0分0分

この設例の5日間の労働時間は合計42時間5分で、1日8時間を超えた時間外は合計2時間5分です。1日8時間以内の部分は合計40時間なので、この設例では週40時間を超える分は別に生じません。

金曜のように、退館が遅くても業務をしていなかったと確かめられれば確定時刻は変えません。木曜のように打刻後に業務をしていた日は、なぜ打刻後に働いたのかも確認します（ずれるときの節）。

打刻漏れを見つけたときの手順

打刻が無いことだけでは、働いていないとは決められません。他の記録と本人・上長の確認で時刻を確定し、修正記録を残します。次は社内手順の一例です。

  1. 気づいた日のうちに本人へ連絡し、始業・終業の時刻を申告してもらいます。
  2. 入退館の記録やパソコンの使用時間など、事業場にいた時間が分かる記録を集めます。
  3. 申告と記録の差を上長が確認し、確定した時刻を決めます。
  4. 修正前後の時刻・理由・照らした記録・確認者・確認日を修正記録に書きます。
  5. 確定した時刻で日ごとの労働時間を出し、月の集計に入れます。

同じ人の打刻漏れが続くときは、打刻機の置き場所や手順を見直します。本人の申告だけで時刻を決める日が増えると、客観的な記録を基礎にした確認ではなくなるためです。

打刻と実際の作業がずれるとき

打刻の前後でも、使用者の指揮命令下にあった時間は労働時間です。ガイドラインは、次の時間を労働時間として扱うよう挙げています。

  • 使用者の指示で、事業場内で行った業務に必要な準備（着用を義務付けた服装への着替えなど）や後始末（清掃など）の時間
  • 指示があればすぐ業務に就くことを求められ、労働から離れることが保障されていない待機の時間（手待時間）
  • 参加が業務上義務付けられた研修・教育訓練や、使用者の指示で業務に必要な学習をした時間

労働時間に当たるかは、就業規則などの定めではなく、指揮命令下にあったと評価できるかで客観的に決まり、個別具体的に判断されます。厚生労働省のリーフレットは、打刻前に着替え・清掃・朝礼を義務付けながら労働時間として扱わない例を、労働基準法違反として挙げています。

本人の申告で時刻を決めるときに確かめること

打刻を基礎に他の記録で確かめるのは原則の方法の中の確認で、記録そのものを本人の申告に頼る「自己申告制」とは別です。タイムカード等によらず自己申告制で行わざるを得ないときは、ガイドラインが定める措置が要ります。

  • 対象の労働者と、実際に労働時間を管理する者に、適正な申告・運用について十分に説明する
  • 入退場やパソコンの記録と申告に著しい乖離があれば、実態調査をして労働時間を補正する
  • 申告を超えて事業場にいた理由を報告させるなら、報告が適正か確かめる
  • 申告できる時間外の時間数に上限を設けるなど、適正な申告を妨げる措置をとらない

ガイドラインは、実際には36協定で延長できる時間を超えて働いているのに、記録上は守っているように見せることが慣習になっていないかの確認も求めています。木曜の設例のような「打刻後の業務」が続く職場では、この点も見直します。

1日ごとの切り捨ては違反になる

1日ごとに一定時間に満たない労働時間を一律に切り捨て、その分の賃金を払わないことは労働基準法違反です。厚生労働省のリーフレットは、1日の時間外の15分未満を勤怠システムで一律に切り捨てる例や、時間外の申請を30分単位でしか認めない例を挙げています。

上の設例で時間外を1日ごとに15分未満切り捨てると、水曜の10分が0分、木曜の40分が30分になり、週の時間外は1時間45分と20分少なくなります。

認められている端数処理は、1か月の時間外労働・休日労働・深夜業の各合計に1時間未満の端数がある場合に、30分未満を切り捨て、30分以上を1時間に切り上げる方法です。例えば1か月の時間外の合計が12時間35分なら13時間、12時間25分なら12時間です。1日の労働時間の端数を切り上げて払うことは問題ないとされています。

割増率や単価の端数は残業代の計算の記事で扱います。

給与集計へ渡す項目

確定した時刻から日ごとの労働時間と時間外を出し、月の合計を賃金台帳へ移します。ガイドラインは、労働基準法108条と施行規則54条により、賃金台帳に労働者ごとの労働日数・労働時間数・休日労働時間数・時間外労働時間数・深夜労働時間数といった事項を適正に記入するよう求めています。

集計を渡すときは、打刻記録と修正記録も同じ期間で揃えておくと、賃金台帳の時間数の根拠を後から追えます。賃金台帳のほかの記載事項は賃金台帳の記事、支給後に誤りが分かった場合の直し方は給与計算の間違いの訂正を確認してください。

まとめ

  • 打刻は労働時間を確かめる基礎の記録。打刻・確定時刻・修正記録を分けて残す。
  • 打刻漏れや打刻とのずれは、入退館・PCの記録と本人・上長の確認で時刻を確定する。
  • 1日ごとの一律の切り捨てはしない（1か月の合計の端数処理は別）。確定した時間を賃金台帳の時間数へ移す。
確定した時間外の時間から残業代を計算する

よくある質問

打刻漏れの日は欠勤扱いにしてよいですか？

打刻が無いことだけでは、働いていないとは決められません。入退館やパソコンの記録、本人の申告と上長の確認で始業・終業時刻を確かめ、確定した時刻と理由を修正記録に残します。

労働時間を1日15分単位で切り捨ててよいですか？

1日ごとに一定時間に満たない時間を一律に切り捨て、その分の賃金を払わないことは労働基準法違反です。認められているのは、1か月の時間外などの各合計の1時間未満の端数を、30分未満は切り捨て・30分以上は切り上げる処理です。

タイムカードを押す前の着替えは労働時間ですか？

ガイドラインは、着用を義務付けた服装への事業場内での着替えを、労働時間として扱う時間の例に挙げています。当たるかは指示や義務付けの有無と実態から個別に判断されるため、職場のルールと実際の運用を確かめます。

打刻した後に残って仕事をしていた日はどうしますか？

打刻の後でも、使用者の指示で業務をしていた時間は労働時間です。退館やパソコンの記録と照らして終業時刻を確定し、修正記録に理由を残します。打刻後の業務が続くなら、その原因も確かめます。
