無職でも確定申告は必要？退職後の還付・無収入の住民税申告

公開日: 2026年10月24日

文責: Masahiro Yasu（クリニック・EC事業の経営者／経理実務者）

退職した年に給与から税金が引かれ、年末調整を受けていなければ、確定申告で納め過ぎた税金が戻る場合があります。一方、課税対象の所得も納めた所得税もない年は、所得税の納付・還付の申告は必要ありません。

ただし、無収入でも住民税の申告が必要な場合があります。国民健康保険料の軽減判定や非課税証明書に関わるため、所得税とは分けて確認します。まずは次の早見表で、自分に近い状況を探してください。

無職の人の申告を状況別に確認

今働いているかどうかよりも、申告する年にどんな所得があったかが判断の出発点です。退職した年と、その後に給与収入がなかった年は、分けて整理してください。

状況所得税の確認次にすること
退職年に給与があり、年末調整を受けていない源泉徴収された税が年税額を超えていれば還付の対象給与の源泉徴収票を用意し、下の還付の節へ
課税対象の所得も、源泉徴収・予定納税もない所得税の納付・還付の申告は不要住民税の申告が必要か自治体に確認
収入は雇用保険の基本手当のみ基本手当は非課税給与や他の課税所得がなかったか確認し、住民税の扱いも調べる
給与のほかに副業・家賃などの所得がある無職でもその年の所得に応じて申告義務を確認確定申告が必要になる所得の線へ
退職金も受け取った給与とは別に退職所得の扱いを確認退職金の税金と確定申告へ

還付になるかと、申告義務があるかは別の確認です。年末調整が済んでいないという理由だけで、全員が納税のための確定申告をするわけではありません。給与以外の所得がある人は、その分も含めた判定を先に行います。

退職した年の還付を確認する

給与から引かれた税は、最終的な年税額と一致するとは限りません。国税庁の中途退職で年末調整を受けていないときの案内では、退職後に再就職せず、年末調整を受けないことで納め過ぎが生じる場合を説明しています。

確認するのは、給与の源泉徴収票の「源泉徴収税額」です。ここに税額が記載されていても、その全額が戻るとは限りません。所得や控除を申告書に入力して求めた年税額と比較します。

還付の仕組みを示す仮定の設例として、予定納税その他の精算はなく、源泉徴収税額を36,000円、申告で確定した年税額を24,000円とします。年税額は年収から計算した公表例ではありません。

仮定の設例の項目金額・計算
給与から源泉徴収済みの税額36,000円
申告で確定した年税額24,000円
納め過ぎの差額として還付される額36,000円 − 24,000円 ＝ 12,000円

社会保険料などの所得控除は、税額を計算する前の所得から差し引くものです。支払った保険料が、そのまま還付金になるわけではありません。源泉徴収も予定納税もしていない年には、所得税の還付はありません。

還付の申告はいつできるか

申告義務のない人の未申告分の還付申告は、対象年の翌年1月1日から5年間提出できます（期限内提出が要件の特例を除く）。

期限内提出が要件の特例を使うときは、還付申告でも法定申告期限までの提出が必要です。既に申告した年分を訂正する手続とは区別してください。根拠は国税庁「還付申告」です。申告義務がある人の提出・納付期限は確定申告の期限で確認できます。

退職時に年末調整を受けていることもある

まず会社に、年末調整の実施の有無を確認してください。中途退職でも、扶養控除等申告書を所定の時期までに提出し、所定の対象区分に該当すれば、年末調整の対象となる場合があります。

例えば、12月に支給されるべき給与を受け取った後に退職する場合などです。対象区分と条件の一覧は国税庁「年末調整の対象となる人」にあります。年末調整が済んでいる人でも、医療費控除などで還付を受けられる場合があるため、単に「調整済みだから申告できない」とは判断しません。

源泉徴収票と控除の資料を集める

最初に集めるのは、退職した年の給与の源泉徴収票です。退職金を受け取った人の「退職所得の源泉徴収票」とは、書類も入力する所得の種類も違います。

次は申告書の入力に備えて手元に集める資料の例です。提出時の添付・提示書類の完全な一覧ではありません。所得や控除、提出方法に応じた必要書類は国税庁の作成画面で確認してください。

手元に用意する資料確認する内容
給与所得の源泉徴収票支払金額・源泉徴収税額・社会保険料等の金額
本人が支払った国民年金・国民健康保険の資料控除証明書や納付額の通知、支払記録で対象年の実際の支払額を確認
利用する所得控除の資料生命保険料などの控除証明書、医療費の明細など該当分
退職金がある人の退職所得の源泉徴収票給与の票と分けて、退職所得の内容を確認

本人がその年中に実際に支払った本人負担の国民年金・国民健康保険の保険料は、本人の社会保険料控除の対象です。未払いの請求額や免除された額は含めず、家族が払った分を本人が重ねて控除しないようにします。

給与から引かれた保険料は、源泉徴収票に記載された分と別途自分で支払った分を分けて整理すると、重複入力を防げます。国民年金の証明書類や申告方法別の扱いは、国税庁「社会保険料控除」で確認してください。

退職所得の票の内容を確認したい場合は退職所得の源泉徴収票の見方・記載欄へ進んでください。給与の源泉徴収票を探す際に、この退職金用の票だけで足りると考えないことが大切です。

失業手当は給与と分ける

雇用保険の基本手当は非課税で、所得税の申告の課税所得には入れません。退職前の給与と基本手当の振込額を合計して、給与収入として入力しないでください。

根拠の雇用保険法の公課の禁止の規定は、失業等給付として支給を受けた金銭を標準として租税を課すことを禁じています。退職後に振り込まれたお金でも、給与や退職金なら別の扱いです。振込日だけで基本手当と同じ分類にはできません。

この説明は税金の課税所得の話です。健康保険の扶養に入るための収入判定は別に確認してください。

収入がない年は住民税の申告を確認

課税対象の所得がなく所得税の申告をしない人は、市区町村に住民税の申告が必要か確認してください。無収入であっても、国民健康保険料の算定や軽減判定、非課税証明書のために所得情報が必要になる場合があります。

横浜市の令和8年度・令和7年分の案内は、前年に収入がなかった人にも、非課税証明書の発行や保険料の減額判定などのために申告を求めています。市内の人に扶養されている人でも、証明書に収入がない旨を表示するためには申告が必要になる場合があります。

所得割の納税義務がない人の申告不要の範囲には、地方税法の住民税申告の規定に加え、条例による部分があります。全国一律に「無職なら不要」「家族の扶養なら不要」とはせず、住所地の自治体の案内を使います。

自治体へ確認するときは、「前年中は給与もほかの課税所得もなかった」「家族の扶養に入っているか」「国民健康保険に加入しているか」「非課税証明書が必要か」を伝えると、確認する項目を整理できます。自治体から収入申告の書類が届いている場合は、その案内も手元に置いてください。

住民税申告をしたことだけで、国民健康保険料の軽減や世帯全体の非課税が確定するわけではありません。申告した所得情報は、該当する制度の判定に使われます。

所得税を申告した場合の重複提出

横浜市の令和8年度・令和7年分の案内では、所得税の確定申告書を税務署へ提出した人は、改めて住民税の申告をする必要はないとしています。所得税を「申告しなくてよい」と判断しただけの場合とは区別してください。

退職後に届いた住民税の納付書をどう払うかは、申告の要否とは別の問題です。徴収方法や退職後の納付については退職後の住民税にまとめています。

申告書を作る順序

給与の源泉徴収票と控除の資料を集めたら、国税庁の作成画面で所得と税額を確認します。無職になったことだけを入力するのではなく、申告する年の所得を整理して進めます。

  1. 給与の源泉徴収票が複数あれば、申告する年の分をそろえる。退職金の票は別に分ける。
  2. 副業など給与以外の所得を確認する。雇用保険の基本手当は課税所得に入れない。
  3. 控除の資料を整理し、給与から引かれた分と本人が別途支払った分の保険料を区別する。
  4. 国税庁の申告書等作成コーナーの案内に沿って入力し、還付か納付かを確認して提出する。

国税庁中途退職者の手続案内から作成コーナーへ進めます。本人確認や提出方法までの全体の手順は初めての確定申告のやり方で確認してください。

所得税・還付金の目安を計算する

計算機は対応する年分と対象範囲を確認して使います。申告書の作成・提出は国税庁の案内に沿って行ってください。

よくある質問

無職なら確定申告をしなくてもよいですか？

今無職というだけでは判断できません。申告する年に給与やほかの所得があれば、申告義務を確認します。年末調整を受けておらず、源泉徴収された税が年税額を上回る人は、還付申告で納め過ぎを精算できる場合があります。

収入がなかった年でも申告が必要ですか？

課税対象の所得も源泉徴収・予定納税もない年は、所得税の納付・還付の申告は不要です。ただし、住民税の申告は国民健康保険料の判定や非課税証明書などのために必要になる場合があるので、住所地の自治体に確認してください。

失業手当は確定申告に入れますか？

雇用保険の基本手当は非課税なので、課税所得には入れません。同じ年に受け取った給与・退職金・副業の所得は別に確認します。

退職すれば、給与から引かれた税金は全部戻りますか？

全部戻るとは限りません。還付されるのは、源泉徴収税額などの既納付額が申告で求めた年税額を上回る場合の納め過ぎです。源泉徴収も予定納税もなければ、所得税の還付はありません。

退職金の源泉徴収票だけで給与の還付を申告できますか？

給与の確認には、給与所得の源泉徴収票を用意します。退職所得の源泉徴収票は退職金の資料なので、給与の票とは分けてください。退職所得がある人は、その内容も確認して申告します。

最後に確認すること

  • 給与の源泉徴収票を用意し、年末調整の実施の有無と税の納め過ぎを確認する。
  • 給与以外の所得も確認し、還付の話と申告義務の判定を分ける。
  • 課税対象の所得がない場合も、住民税の申告が必要か住所地の自治体へ確認する。

次に読む

親の扶養控除【令和8年分】年金収入の条件・老人扶養親族と年末調整親の扶養控除を年末調整で確認する参照表。年金収入と所得の違い、老人扶養親族・同居老親等の控除額、別居の仕送り、入院と老人ホーム、兄弟の重複申告を整理します。確定申告しないとどうなる？無申告加算税・延滞税と期限後の対処申告義務がある人の無申告加算税・延滞税と、還付申告だけの人の違い。自主申告の時点別の割合と対応手順。パート・アルバイトも年末調整は必要？対象と書類の確認表パート・アルバイトも条件を満たせば年末調整の対象です。扶養控除等申告書の提出先、年末まで働くか、掛け持ち・中途退職・転職の確認事項と必要書類を整理します。
