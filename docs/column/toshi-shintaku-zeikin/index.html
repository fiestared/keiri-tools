投資信託の税金：分配金と売却の手取りを検算

公開日: 2026年10月19日

文責: Masahiro Yasu（クリニック・EC事業の経営者／経理実務者）

国内公募株式投信は、個人の課税口座では売却益と普通分配金に税金がかかり、元本払戻金は非課税です。

ここでは国内の個人居住者が保有する国内公募株式投信を扱います。法人・NISA・私募投信・公社債投信・ETF・外国籍投信の計算は対象外です。

課税される額の早見表

国内公募株式投信を保有する個人の課税口座の区分です。売却には解約・償還を含め、源泉徴収や申告後の税額の違いは後の節で区別します。

受け取るお金と課税対象
受取の区分課税対象になる額照合するもの
売却・解約・償還受取価額から取得費と売却委託手数料等を引いた利益取引報告書の受取価額・取得費・費用
普通分配金分配金のうち、元本払戻金を除いた額分配金の通知の課税対象額
元本払戻金（特別分配金）非課税。受取額だけ個別元本が減る通知の元本払戻金と分配後の個別元本

個人の課税口座で受け取る国内公募株式投信の普通分配金は、再投資する場合も税引後の額が再投資に回ります。再投資コースの元本払戻金は非課税のため、その全額が再投資に回ります。

同じ分配金でも手取りが変わる

個別元本の違いを、架空の受取表で比べます。

令和8年分の国内公募株式投信の架空設例で、居住者である個人の課税口座・外国税額調整なしの現金分配を、国税15.315%・住民税5%で計算します。この設例に税額の端数はありません。

設例は分配時の国内徴収額です。外国税額の調整、申告による損益通算・税額控除などがある場合の最終年税額とは区別します。

個別元本と分配の内訳を計算する

個別元本は、購入時の基準価額を出発点に管理する本人ごとの元本です。購入時手数料とその消費税は含みません。同一ファンドを複数回買う場合は購入口数で加重平均しますが、複数支店での購入などでは把握方法が異なる場合があるため、販売会社の表示を確認します。

元本払戻金を受け取った後は、その額を引いた個別元本で次の分配を判定します。購入時の元本のまま固定する計算ではありません。

分配の内訳は、同じ口数当たりの金額で比較します。分配落ち後の基準価額が本人の個別元本以上なら、分配金の全額が普通分配金です。

分配落ち後の基準価額が本人の個別元本を下回るときは、個別元本から分配落ち後の基準価額を引いた額が元本払戻金です（分配額が上限）。普通分配金は、分配金から元本払戻金を引いた残額です。

個別元本と取得費は同じものではありません。換金の利益を計算する取得費には購入時手数料とその消費税も含めます。分配の区分は請求目論見書「課税上の取扱い」、譲渡益の算式は国税庁No.1463で確認できます。

元本払戻し後に売却したら

元本払戻しを受けた分は、後の換金で使う取得費にも反映します。ここでは購入時手数料のないBさんが、その後、追加購入も再投資もせずに保有分を換金する例を示します。

令和8年分の国内公募株式投信の架空設例で、居住者である個人の課税口座は源泉徴収口座とし、外国税額調整なし、国税15.315%・住民税5%で計算します。Bさんが払戻し後に全量換金し、手数料等なし、他取引・追加購入・再投資・損失との通算なしとします。この設例に税額の端数はありません。

取得費には払戻し後の額を使います。購入時の支払額をそのまま引くと、元本払戻金として既に受け取った分まで重ねて控除することになります。

売却価額は取引報告書の金額で確認します。信託財産留保額などが既に反映された換金価額から、同じ費用を再度引かないようにします。買取請求の受取額・費用は販売会社の表示で確認します。

表は源泉徴収時の手取りで、申告後の追加納付・還付は計算していません。

通知を照合する順序と申告の確認先

  1. 分配金の通知で、税引前分配金・普通分配金・元本払戻金・源泉税を分けます。
  2. 個別元本は分配前と分配後を区別し、表示がどの口数当たりかをそろえます。
  3. 換金時は、取引報告書の売却価額・取得費・費用・源泉税を確認します。

口座による納税手続や申告する範囲は、特定口座と確定申告にまとめています。普通分配金を申告する場合の総合課税・申告分離課税・申告不要の違いは、配当金の確定申告を参照してください。

よくある質問

元本払戻金は非課税なら利益ですか？

利益としての分配ではなく、元本の一部の払戻しです。国内公募株式投信では、元本払戻金を受け取るとその額だけ本人の個別元本が減ります。

分配金を再投資すると税金はかかりませんか？

個人の課税口座にある国内公募株式投信の普通分配金は、再投資でも課税され、税引後の額で再投資します。元本払戻金は非課税で、その全額が再投資されます。

同じ投信を持っている人と課税対象額が違うのはなぜですか？

本人の個別元本が違うと、分配金に含まれる普通分配金と元本払戻金の額が違うためです。国内公募株式投信では、分配落ち後の基準価額と本人の個別元本を同じ口数当たりで比べます。

売却代金の全額に税金がかかりますか？

個人の課税口座にある国内公募株式投信では、売却・解約・償還の受取価額から取得費と売却委託手数料等を差し引いた利益に課税されます。取得費には購入時手数料とその消費税を含め、元本払戻し後は払戻し分を反映します。
