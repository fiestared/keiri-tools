定額小為替の買い方・手数料・受取方法｜券種と期限切れの手続き

公開日: 2026年10月21日

文責: Masahiro Yasu（クリニック・EC事業の経営者／経理実務者）

定額小為替は、取扱いのあるゆうちょ銀行・郵便局の貯金窓口で購入する送金用の証書です。現行の定額小為替の購入料金は、額面に加えて証書1枚につき200円（税込）です。購入料金は送付先に渡る金額には含まれません。

証明書の郵送請求で指定されたときは、必要額・券種の指定・受取人欄の記入方法を請求先の案内で確認します。ここでは購入から受取までの持参物と、使わなかった場合・期限切れ・紛失時の手続きをまとめます。

券種と購入料金の早見表

定額小為替は、決まった額面の証書を必要な金額に合わせて購入します。額面は相手が受け取る金額であり、購入料金は別です。

以下は、2026年10月21日に確認した現行の定額小為替の金種です。ゆうちょ銀行の商品案内に掲載された額面を並べています。

定額小為替の金種
区分額面
金種50円、100円、150円
金種200円、250円、300円
金種350円、400円、450円
金種500円、750円、1,000円

額面が違っても、購入料金は証書の枚数で計算します。

普通為替は定額小為替とは別の商品です。請求先が定額小為替を指定している場合、商品名を省かず窓口に伝えます。受け付ける送金方法や券種を請求先が指定しているときは、その指定を先に確認します。

証明書代と購入費用を分ける設例

証明書を取る費用には、証明書そのものの交付手数料と、小為替を購入するための料金があります。小為替の購入料金を差し引いた額面を送ると、証明書の手数料が不足します。

架空の証明書代を450円とした定額小為替の購入設例です。この設例の定額小為替の購入料金は1枚200円（税込）として、額面合計に加算します。郵送料は含めず、送付先の券種指定がない場合の比較です。特定の自治体の証明書料金ではありません。

架空の証明書取得で定額小為替を購入する設例
用意する券種額面合計購入料金窓口で払う合計
450円券（1枚）450円200円650円
200円券＋250円券（2枚）450円400円850円

同じ額面合計でも、分けて購入すると証書の枚数分の料金がかかります。請求先が券種を指定している場合は、費用の比較より先にその指定を確認してください。

購入する窓口と手順

郵便ではなく貯金の取扱窓口を確認する

定額小為替の購入・受取は、取扱いのあるゆうちょ銀行・郵便局の貯金窓口へ申し出ます。

為替規定の取扱店の定めには、取り扱わない店舗があることも示されています。利用する店舗の案内で、貯金窓口の営業日・営業時間と取扱いを確認します。全国共通の閉店時刻としては扱いません。

窓口では額面と枚数を伝える

  1. 請求先の案内から、送る金額と券種の指定を確認します。
  2. 取扱店の貯金窓口で定額小為替振出請求書に必要事項を記入します。
  3. 額面分の現金と購入料金を用意して手続きをします。
  4. 定額小為替証書と為替金受領証書を受け取り、額面と枚数を確認します。

定額小為替の新規振出では、取扱金額が10万円を超える場合に本人確認書類が必要です。この金額以下でも正当権利者等の確認を求められる場合があるため、本人確認書類も用意すると手続きに対応できます。

定額小為替を同一金種で100枚以上購入する場合は、事前にゆうちょ銀行または郵便局へ申し出るよう、商品案内に記されています。本人確認書類の条件とは別の案内です。

持参物はゆうちょ銀行の手続き案内で確認できます。相続など通常と異なる手続きは、窓口に必要資料を確認してください。

受領証書は送付せずに保管する

為替金受領証書は差出人が保管します。為替規定では、各種の請求に必要になるため大切に保管するよう求めています。送付先へ渡す定額小為替証書と取り違えないようにします。

会社の支出管理では、送金に使う額面と購入料金、郵送料を区別して記録すると、請求先に送った金額を確認しやすくなります。帳簿の勘定科目や税区分の個別判断は、この記事の対象に含めません。

受取人欄の書き方・送る前の確認

通常の送金では受取人名を記入しますが、証明書の郵送請求には空欄を求める案内もあります。「どこへ送る場合も空欄」とは扱わず、請求先の記入指示を確認します。

定額小為替の受取人欄を記入する前の確認
使う場面確認する案内
通常の送金ゆうちょ銀行の商品案内は、受取人欄に受取人名を記入して送る手順
自治体への証明書の郵送請求請求先が示す受取人欄等の記入方法を確認

横浜市の本人名義の課税証明書の郵送請求では、「指定受取人」「おなまえ」の欄等は空欄とし、有効期限が残り1か月以上のものを送るよう協力を求めています。これは横浜市の当該請求の案内です。

横浜市の郵送請求の案内のように、記入方法や残存期間まで指定されることがあります。別の自治体にも同じ条件が当てはまるとは限りません。

申請書類・返信用封筒・切手など、小為替以外の同封物も請求先の案内で確認します。課税証明書の取り方を読む

受取人名を書き間違えた場合

受取人氏名の訂正は、差出人が証書を窓口へ提出し、為替金受領証書を提示して請求します。為替規定の記載事項の訂正が認める対象は、受取人の氏名です。

この訂正手続きを、額面金額を変更する手続きと混同しないようにしてください。記入指示と違う内容を書いた場合も、送る前に窓口と請求先に取扱いを確認します。

受け取るときの持参物・代理受取

定額小為替を受け取ったら、まず発行日と指定受取人を確認します。取扱店の貯金窓口で、証書の状態に応じた手続きを確認してください。

定額小為替の受取・払戻しの持参物
手続き用意するもの・確認先
受取人が受け取る「払渡し」定額小為替証書・印鑑・本人確認書類
有効期間内の証書を差出人が戻す「払戻し」定額小為替証書・印鑑・本人確認書類・為替金受領証書
代理人に払渡しを委任証書の委任欄に記入。手続き案内では別の委任状は不要
払渡し以外を代理人に委任手続きに必要なものに加えて、別途委任状が必要

手続き案内の持参物を示しています。有効期間内の定額小為替は、指定受取人が住所を記入し、記名押印または署名をして証書を提出します（為替規定）。

代理受取では、委任欄への記入と本人確認を別々に確認します。委任欄を埋めたことだけで確認資料が不要になるわけではありません。必要資料の細目は、窓口の案内を確認してください。

期限切れ・紛失・払戻しの手続き

定額小為替証書の有効期間は発行日から6か月です。期限が過ぎた証書は、再交付と契約解除後の返還を分けて手続きを確認します。

契約解除前の定額小為替の再交付は、証書1枚200円（税込）ですが、有効期間経過後、再交付請求のうえ即時払渡し・払戻しをする場合は無料です（商品説明書）。再交付の請求者は、銀行所定の請求書に必要事項を記入し、記名押印または署名をします。再交付では銀行が為替金の未払を確認します。

定額小為替の再交付手続き
状況請求する人と必要な証書
有効期間が経過した差出人または受取人が、元の証書を添えて再交付を請求
有効期間内の汚損・き損で記載事項が不明差出人または受取人が、元の証書を添えて再交付を請求
紛失（有効期間内は発行・交付なし）差出人が為替金受領証書を添えて再交付を請求

再発行された後は、元の定額小為替証書を払渡し・払戻しの請求に使うことはできません。紛失後に見つかった場合は、再交付の手続状況を窓口に伝えて確認します。

使わずに残ったときの払戻し

契約が解除されていない有効期間内の定額小為替を戻すときは、差出人が証書に住所を記入して記名押印または署名をし、証書を提出して為替金受領証書を提示します。

長く請求していない証書は差出人側の手続きも確認

定額小為替の発行日から5年間、払渡し・払戻し・再交付の請求がないと契約が解除され、以後は差出人が返還を請求する手続きになります。契約解除後の返還は、差出人が所定の書類に必要事項を記入して記名押印または署名をし、証書か為替金受領証書を添えて請求します。

契約解除後の返還請求と、通常の受取を同じ手続きと考えないようにします。古い証書の相談では、証書と受領証書の有無、差出人・受取人のどちらかを伝えると、必要な手続きを確認できます。

まとめ

  • 定額小為替は取扱店の貯金窓口で購入・受取。店舗の営業時間と取扱いを確認する。
  • 送る額面と購入料金を分ける。請求先の金額・券種・記入方法の指定を確認する。
  • 為替金受領証書は差出人が保管。期限切れ・紛失・払戻しは状況と請求人を分けて確認する。
書類を準備する日程を営業日カレンダーで確認する

窓口の営業日・営業時間や郵便の到着日は、利用する店舗・送付方法で別に確認してください。

よくある質問

定額小為替はどこで買えますか？

取扱いのあるゆうちょ銀行・郵便局の貯金窓口で購入します。店舗によって取り扱わない場合があるため、貯金窓口の営業日・営業時間と取扱いを確認してください。

購入料金も含めた額面を送りますか？

送付先が必要とする額面と、購入料金は分けます。購入料金は証書を発行するための料金で、相手が受け取る額面には加わりません。券種や必要額は送付先の案内で確認します。

受取人欄は空欄で送るのですか？

送付先の案内を確認します。ゆうちょ銀行の通常の送金案内は受取人名を記入する手順です。横浜市の本人名義の課税証明書の郵送請求では空欄を求めています。記入する前に請求先の案内を読んでください。

定額小為替をなくしたら、すぐに再交付されますか？

紛失した定額小為替は、有効期間内には発行・交付されません。差出人が為替金受領証書を用意し、再交付の請求方法と契約の状態を窓口で確認します。紛失した状況と発行日を窓口に伝えて確認してください。

期限が過ぎた定額小為替は捨ててよいですか？

処分する前に、証書を持って貯金窓口で再交付や払戻しの手続きを確認します。長く請求していない場合は契約解除後の扱いもあるため、差出人・受取人のどちらかと、受領証書の有無を伝えてください。
