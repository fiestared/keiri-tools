マル優・特別マル優｜非課税の利子・枠の数え方・税額差を検算

公開日: 2026年10月22日

文責: Masahiro Yasu（クリニック・EC事業の経営者／経理実務者）

マル優は、国内に住所のある障害者等が使える、預貯金などの利子の非課税制度です。マル優の枠は、店ごとに申告する最高限度額の合計で350万円までです。国債・地方債の利子には、マル優とは別枠の特別マル優があります。

使えるのは、身体障害者手帳の交付を受けている人、遺族基礎年金や寡婦年金を受ける妻、障害年金を受けている人など、法令の列挙に当たる国内に住所のある人です。マル優を使って最初に預ける日までに、金融機関を通じて申告書を出しておく必要があります。

本記事の基準日は2026年10月22日です。仕組みと設例の検算を示す一般的な解説で、預け先や商品を勧めるものではありません。

マル優と特別マル優の早見表

国内に住所のある障害者等が、マル優・特別マル優を使う場合の比較です。枠は、それぞれの申告書に書いた最高限度額の範囲で使います。

項目マル優特別マル優
正式な名前障害者等の少額預金の利子所得等の非課税障害者等の少額公債の利子の非課税
対象預貯金・合同運用信託・特定公募公社債等運用投資信託・一定の有価証券（一部を除く）国債・地方債（政令で定めるもの）

根拠所得税法10条・租税特別措置法3条の4租税特別措置法4条

どちらも、非課税には国内に住所のある障害者等による申告・申込が必要です。枠内に収まる必要があるのは、利子の計算期間全体です（途中で買った有価証券・公債は購入日から期末まで）。貸付信託・特定公募公社債等運用投資信託・有価証券・公債は、その計算期間を通じて振替口座簿等で管理されていることも条件です。預貯金・合同運用信託のうち所得税法9条で非課税のものや政令で除くものは対象外です。

マル優と特別マル優をそれぞれ350万円ずつ使えば、元本と額面で合計最大700万円分の利子が非課税の対象になります。

マル優の元本の上限は、所得税法10条7項1号では300万円と書かれ、租税特別措置法3条の4が平成6年1月1日以後の預入等について350万円に読み替えています。条文だけを読むと上限を少なく読み違えます。

使える人（障害者等）

マル優・特別マル優を使えるのは、国内に住所のある個人で、所得税法10条1項と同法施行令31条の2に列挙された「障害者等」です。主な例は次のとおりです。

  • 身体障害者手帳の交付を受けている人
  • 遺族基礎年金を受けることができる妻、寡婦年金を受けることができる妻
  • 障害基礎年金・障害厚生年金を受けている人
  • 遺族厚生年金を受けている妻
  • 児童扶養手当を受けている児童の母
  • 療育手帳・精神障害者保健福祉手帳の交付を受けている人

施行令31条の2は18号まであり、労災の障害の年金や特別障害者手当の受給者、労災の遺族の年金を受ける妻なども含みます。上の一覧は一部なので、手帳や年金証書の種類を列挙と照らして確かめます。

列挙に年齢による区分はなく、高齢であることだけではマル優を使えません。

枠は営業所等ごとの最高限度額の合計で数える

マル優の非課税貯蓄申告書には、その店で非課税にする元本の最高限度額を書きます。同じ金融機関のほかの店を含め、ほかの営業所等にも申告書を出していれば、その店の名前と最高限度額（変更していれば変更後の額）も書きます（所得税法10条3項3号・4号）。

マル優では、その店の最高限度額とほかの店の最高限度額の合計が350万円を超える申告書は出せず、金融機関も受理できません（所得税法10条7項1号を措置法3条の4で読み替え）。

例えばA銀行だけに最高限度額200万円の申告書を出している人が、B銀行で新たに申告するなら、B銀行に書ける最高限度額は合計の上限から引いて150万円までです。

マル優を利用中の預貯金は、利子の計算期間を通じて同じ店の元本合計が最高限度額を超えないことが必要です。合計するのは、申告書を出した店で申込書を出して預けたその預貯金と、同じ店で申込書を出した他の預貯金です。変更後の最高限度額は、変更申告書を出した日以後に適用します（所得税法10条1項1号）。

限度額を変えるときは、申告書を出した店を経由して非課税貯蓄限度額変更申告書を出します。そのときも確認書類の提示か署名用電子証明書等の送信による確認を受けます（所得税法10条4項・5項）。

通常の課税との差を設例で検算

設例：居住者が国内の銀行の預金で、利子2万円（仮定）を1回受け取る場合です。通常の課税は、基準日時点の所得税と復興特別所得税で計算します。本例の金額には端数が出ません。

利子2万円の設例：通常の課税とマル優の枠内
項目通常の課税マル優の枠内
利子20,000円20,000円
所得税（利子の15%）3,000円0円
復興特別所得税（所得税額の2.1%）63円0円
住民税の利子割（利子の5%）1,000円0円
差し引かれる合計4,063円0円
手取り15,937円20,000円

本設例の所得税と復興特別所得税の合計率は15.315%です（居住者が国内で受け取る通常課税の預貯金利子）。

マル優の枠内の利子には、所得税・復興特別所得税に加えて住民税の利子割もかかりません。地方税法23条1項14号イが、マル優の適用を受ける利子を利子割の対象から除いているためです。

税率で計算した差額は、利子の額によって変わります。

給与・年金など申告する所得の税額は所得税計算機へ

手続きの順番

  1. マル優を使って最初に預け入れる日までに、非課税貯蓄申告書を金融機関の営業所等を経由して住所地の所轄税務署長に出します。
  2. 申告書を出すときに、身体障害者手帳や年金証書、個人番号カード等の確認書類を提示します（署名用電子証明書等の送信でも可）。
  3. 原則として、預け入れるたびに非課税貯蓄申込書を、申告書を出した店に出します。

申告書が税務署長に提出された場合、金融機関で受理された日に提出があったものとみなされます（所得税法10条6項）。

特別マル優も、その適用を受けて最初に国債や地方債を購入する日までに、マル優と同じ方法で確認を受け、特別非課税貯蓄申告書を購入先の営業所等を経由して住所地の所轄税務署長に出します。原則として購入のたびに、申告書を出したときと同じ営業所等に特別非課税貯蓄申込書を出します。

銀行で取り扱っている商品でも、マル優が使えないものがあります。預ける前に、その商品で使えるかを金融機関で確かめます。

残高がなくなったときのみなし廃止

マル優の預貯金等をその店で持たなくなった日以後2年を経過する日の属する年の末日までに、同じ店でマル優の預貯金等の預け入れをしないと、翌年の元日に非課税貯蓄廃止申告書を出したものとみなされます（所得税法施行令45条4項、自分で廃止申告書を出した場合を除く）。

再び使うときは、金融機関で手続きを確かめます。

マル優は預貯金などの元本、特別マル優は国債・地方債の額面で、それぞれ別に枠があります。マル優の枠は店ごとの最高限度額の合計で数え、マル優を使って最初に預ける日までに申告書を出します。

よくある質問

高齢であることだけでマル優を使えますか？

使えません。対象は国内に住所のある個人で所得税法10条1項と同法施行令31条の2に列挙された障害者等に当たる人で、列挙に年齢による区分はありません。手帳の交付や年金の受給が列挙に当たるかで確かめます。

特別マル優の枠をマル優の預金に回せますか？

回せません。マル優は預貯金などの元本、特別マル優は国債・地方債の額面で、別々の申告書にそれぞれの最高限度額を書く別枠の制度です。

マル優の預金が最高限度額を超えそうなときは？

非課税になるのは、同じ店で申込書を出した預貯金の元本の合計が、利子の計算期間を通じて最高限度額（変更後の額は変更申告書を出した日以後に適用）を超えない場合です。預ける前に店の残高を確かめ、限度額を変えるなら非課税貯蓄限度額変更申告書を出し、確認書類の提示か署名用電子証明書等の送信による確認を受けます。
