為替差益の確定申告：円転・同通貨の預け替え・外貨の使用を検算

公開日: 2026年10月20日　更新日: 2026年10月20日

文責: Masahiro Yasu（クリニック・EC事業の経営者／経理実務者）

個人の非事業用外貨預金で実現した為替差益は、雑所得（その他）です（金融類似商品は下の例外）。円転・別通貨への交換のほか、貸付用建物の購入に使う場合にも差益を認識します。同一通貨の元本部分を引き続き預け替える取引では、その時点で差益を認識しません。

まず下の表で「何に使ったか」を確認し、次に所得の集計、申告要否へ進みます。この記事は居住者個人の外貨預金元本が対象です。法人・事業用の換算、FX、海外預金の利息、相続・贈与による外貨取得は扱いません。

円転・預け替え・使用を同じ元本で比較

為替差益を認識する時点と、確定申告が必要かどうかは別の判定です。外貨預金の元本の動きを分けてから、実現した差益を集計します。

居住者個人の非事業用外貨預金の設例：取得1回・元本全額1万ドル、取得時100円、円転・預替・貸付用建物への使用時110円（各1ドル）、利息・手数料・為替予約等なし、払出しと使用は同日とします。各行は独立した取引の比較です。

元本全額の動き差益の認識設例で確認すること
円に交換する円転時に認識110万円－100万円＝10万円の差益
同一通貨の元本部分を引き続き他行へ預け替える預け替え時には認識しない評価差額10万円をこの時点の所得にしない
貸付用建物の購入に充てる購入に充てた外貨の差益を購入時に認識購入時の円換算110万円－取得額100万円＝10万円
交換・使用をせず外貨預金を保有する未実現の含み益は認識しない評価差額10万円は、利益未確定のまま

円転差益の所得区分は国税庁の申告漏れ注意事項、同通貨での預け替えは外貨建預貯金の預入・払出の質疑、建物への使用は貸付用建物の購入に関する質疑で確認できます。

国税庁の預け替えの回答は、同一通貨で引き続き預け入れる元本部分を対象としています。銀行が変わるかどうかより、通貨と資金の使い道を確認します。途中で円や別通貨へ交換する取引を、同通貨の預け替えに含めないようにします。

米ドルからユーロへ替える場合

別通貨への交換でも差益は実現します。円に戻していないことだけでは申告対象から外せません。国税庁の別通貨交換の質疑は、取得したユーロの交換時の円換算額と、渡した米ドルの当初の円換算額との差額を所得として認識すると説明しています。

国税庁の建物購入例を検算

外貨を払い出した日と、建物の購入に使った日が違う場合は、購入時のレートで確認します。銀行明細の払出額だけから差益を計算しないための確認です。

以下は国税庁の貸付用建物の公表事例の検算です。利子を考慮しない例で、預金A・Bを合わせて払い出し、一部を建物購入に使用し、残りを引き続き保有します。

国税庁の建物購入例の計算式・結果
預金Aの取得記録10万ドル・1,000万円
預金Bの取得記録5万ドル・560万円
払出時と建物購入時の相場1ドル当たり、払出時115円・購入時120円
保有ドルの平均取得レート（1,000万円＋560万円）÷15万ドル＝104円
購入に充てた外貨の為替差益（120円－104円）×12万ドル＝192万円
差益の計算に入れないもの未使用の3万ドル、払出時の115円

この公表事例では、購入に充てた外貨の取得原価を平均レートで求めています。直近に取得した分だけを使った扱いにはしていません。また、購入した建物の取得価額は購入時の円換算額であり、外貨の差益の計算と区別されます。

同通貨の預け替えを間に挟んでいても、元本の当初の取得記録を残します。預け替え時の評価額を新しい取得額としてしまうと、その後の円転や購入に充てた外貨の差益を正しく確認できません。

給与所得者の申告不要制度と住民税

実現した外貨の差益を集計し、所得税の申告要否を確認します。実現した差益があっても、申告不要制度の対象となる場合があります。

次の表は給与収入が年2,000万円以下、給与は1か所・全額が源泉徴収の対象・年末調整済みで、同族会社役員等の別の申告事由がない給与所得者の説明です。給与所得・退職所得以外の所得は合計で判定し、源泉分離課税の所得等は判定の合計から外します。制度の対象でも、確定申告をする場合は少額の雑所得も含めます。

給与所得者の状況所得税の確認
給与・退職以外の所得合計が20万円以下所得税の申告不要制度の対象。非課税になる枠ではない
給与・退職以外の所得合計が20万円超申告が必要か確認。申告すると還付になる人は申告義務の対象から除かれるが、還付には申告が必要
医療費控除などで確定申告する申告不要制度の対象となる少額の雑所得も含める

国税庁「給与所得者で確定申告が必要な人」と、同ページの申告不要制度のQ&Aが根拠です。給与を複数の勤務先から受ける人、年金受給者、給与所得がない人は、この表で申告不要と判定しません。

住民税の申告は別に確認します。横浜市の案内では、その年の元日に市内住所がある給与所得者で、前年に給与以外の少額の雑所得等がある人は申告対象ですが、所得税の確定申告書を提出した人の別提出は不要です。住所地の案内は横浜市「市民税・県民税の申告について」などで確認します。

差益に同じ固定税率を掛けて申告額を決める記事ではありません。総合課税の雑所得は給与所得などと合計し、所得控除などを反映して税額を求めます。税額の計算に進む前に、ツールの対象年分と利用条件を確認します。

所得税の計算ツール：対象年分・利用条件を確認する

申告準備でそろえる記録

取引日・外貨額・円換算額をつなげて確認できる形にします。以下は申告準備のための整理例で、書類の法定添付義務を列挙したものではありません。

  • 取得の記録：円から外貨へ交換したときの明細、外貨額、円の支払額。
  • 預け替えの記録：送金元と送金先の通貨・元本額を追える明細。利息や手数料を元本と分ける。
  • 円転・交換・使用の記録：取引日、外貨額、円受取額、購入時の円換算額。建物購入の契約書や決済明細も対応させる。
  • 年間の集計：実現した差益・差損と、他の雑所得等の金額。給与の源泉徴収票と合わせて申告要否を確認する。

準備の際は、年末の残高と当初の取得明細を並べて整理すると、取引履歴の抜けを探しやすくなります。取引履歴が途中からしかない場合は、取得額を推測して計算を埋めず、元の明細を確認します。

入力先の全体像は確定申告書の書き方、一般的な所得区分は国税庁「雑所得」で確認できます。個別の取得原価や必要経費の判断は、取引資料をもとに税務署・税理士へ確認してください。

課税方法が違う取引・損失の扱い

「外貨預金」という名称だけで、すべての収益を同じ扱いにはしません。元本と利子をあらかじめ定めた利率で円や他の外貨に換算して支払う外貨建預貯金の契約の換算差益は、国税庁「金融類似商品と税金」で源泉分離課税の対象とされ、ここで説明した総合課税の申告には含めません。

国内外の預金利息、FX、株式売却の損益も、この元本差益の表に混ぜません。外貨建て株式自体の売却損益は米国株の税金と円換算、法人・事業の外貨建取引は外貨建取引の換算へ分けています。

総合課税の雑所得の計算で残った損失は、給与など他の所得と損益通算できません。国税庁「雑所得」の注意事項による扱いです。これは、雑所得内での差引きまで一切できないという意味ではありません。

確認する順番
  • 外貨の元本が、円転・別通貨交換・貸付用建物の購入のどれに動いたかを確認する。
  • 同一通貨の元本部分を引き続き預け替えた取引と、利益未確定の含み益を分ける。
  • 実現した差益を集計してから所得税の申告要否と住民税の申告を確認する。

よくある質問

同じ米ドルのまま別の銀行へ預け替えた場合は？

同一通貨の元本部分を引き続き預け替える国税庁の質疑のケースでは、預け替え時に為替差益を認識しません。利息や途中の別通貨への交換まで同じ扱いにするものではありません。

円に戻さず外貨で建物を買った場合は？

外貨預金を貸付用建物の購入に充てた国税庁の事例では、購入に充てた外貨の差益を購入時に認識します。建物購入時の円換算額と、その外貨の取得額との差を確認し、使わずに保有する外貨の含み益とは分けます。

給与所得者の申告不要制度は非課税枠ですか？

非課税枠ではありません。給与所得者の少額所得による申告不要制度の対象であっても、還付申告などで確定申告をする場合は、その制度の対象となる雑所得も含めて申告します。住民税の申告も別に確認します。
