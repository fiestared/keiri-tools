外貨建て保険とは：円払込・外貨保険金・為替費用と解約控除を基準日付きで確認

公開日: 2026年10月23日

文責: Masahiro Yasu（クリニック・EC事業の経営者／経理実務者）

外貨建て保険は、保険料や保険金などを外貨で定める保険です。円で受け取る金額は、外貨の受取額と換算レートで変わります。円の受取額が、払い込んだ円の保険料累計を下回ることもあります。

確認するのは、契約の通貨、保険の費用、円と外貨の交換費用です。以下では同じ商品の公式資料で費用の場所を確かめ、円払込・保険金受取・解約返戻金を分けて整理します。

円で払えても、契約の通貨は外貨

外貨建て保険には、終身保険や個人年金保険などがあります。円入金・円支払等の特約を付加すると円で授受できる商品がありますが、円と外貨の換算には会社所定の為替手数料がかかります。

外貨のまま保険料を払い込んだり保険金を受け取ったりする場合は、専用の外貨口座が必要になります。取扱いは商品・金融機関で確認します。

同じ商品資料で費用の引かれ方を確認

例にするのは、メットライフ生命「ドルスマート S」の公表資料です。商品間の順位や加入の適否を示すものではありません。

次の表は、ドルスマート Sの公式商品ページの費用の整理です。契約条件により金額が異なるため、実際の額は契約資料で確認します。

項目どこから引かれるか・確認するもの

ドルスマート Sの積立金は、表示された積立利率でそのまま運用されるものではありません。保険料からの費用控除もあるため、払込保険料全体の利回りと積立利率を同一視しません。

ドルスマート Sの2025年4月の商品資料では、年金支払特約・年金移行特約による年金受取は、毎年の受取時に年金額の1.00％が管理費用として差し引かれます（割合は将来変更）。

円払込と円受取は、換算の向きが逆

円から外貨を用意する際は加算側、外貨を円で受け取る際は減算側です。ニュースの為替相場をそのまま使う計算とは分けます。

以下は架空の個別換算です。ドルスマート Sの2025年4月公表の特約レートを仮定し、TTMを下表の値に固定します。保険料と保険金は別々の入力例で、同一契約の収支・将来額を示しません。税金・送金費用は含めず、計算上の端数はありません。

外貨額を固定した円換算の検算
独立した入力例円換算の式と結果
仮定するTTM150円
円入金特約で保険料200米ドルを用意200米ドル×150.50円＝30,100円の払込
円支払特約で保険金30,000米ドルを受取30,000米ドル×149.50円＝4,485,000円の受取

外貨額を固定すると、円で払うときは換算レートが高いほど必要な円が増え、円で受け取るときは換算レートが低いほど受取円額が減ります。円の払込累計と受取額の比較では、各払込時の円額を合計します。

為替手数料を含む特約レートで換算した額から、同じ為替手数料を再度引く計算にはしません。外貨での授受には、金融機関によって送金・引出し・口座振替等の手数料がかかる場合があります。

解約返戻金は、積立金や保険金と別に確認

解約時に受け取る外貨額は、死亡保険金額をそのまま円換算して求めるものではありません。解約希望日を指定し、保険会社に解約返戻金の外貨額と控除の内訳を確認します。

ドルスマート Sの解約・減額・払済終身保険への変更では、保険料払込期間と契約日から10年間のいずれか短い期間に、経過期間などに応じた解約控除があります。

ドルスマート Sの主契約で低解約返戻金特則を付加した場合、保険料払込期間中の解約返戻金は所定の割合で抑制され、その抑制後の額を円換算する際にも為替の影響を受けます。

  • ドルスマート Sの解約控除で用いる経過期間は払込年月数ですが、年払・半年払では払込年月数と経過年月数の短い方を用います。控除額は経過期間などの条件で異なります。
  • ドルスマート Sの低解約返戻金特則の対象には三大疾病・介護給付終身保険特約（米ドル建）も含まれます。特則による抑制と解約控除は別の項目として確認します。
  • ドルスマート Sでは、契約条件によっては外貨建払込保険料の累計が外貨建保険金額を上回る場合もあります。

商品ごとの計算方式や控除を、別の商品に当てはめないようにします。解約控除の期間が終わっても、為替変動によって円の受取額が払込円額の累計を下回る可能性は残ります。

確認する順序

契約の外貨額と費用を確認してから、円への換算を見ます。解約時は、その日の解約返戻金を保険会社に確認し、保険金額や積立金と混同しないようにします。

よくある質問

円で払えるなら、円建て保険と同じですか？

同じではありません。円入金等の特約で円払いができても、保険料・保険金等を外貨で定める契約では、円換算額は為替相場の影響を受けます。換算の際の会社所定の為替手数料も確認します。

外貨のまま受け取れば、手数料はかかりませんか？

外貨受取でも金融機関の手数料がかかる場合があります。送金・引出し等の費用を取扱金融機関で確認します。後日円に交換する場合には、その際の為替レートと両替費用も確認が必要です。

積立利率で、払った保険料全体が増えますか？

ドルスマート Sでは、そのようには計算しません。保険料や積立金から差し引かれる契約維持・保障等の費用があり、積立金も積立利率でそのまま運用されるものではないと公式資料に記載されています。

解約控除がなくなれば、円の元本は保証されますか？

円の元本が保証されるわけではありません。外貨建て保険は、為替変動によって円の受取額が各払込時の円換算額の累計を下回ることがあります。解約控除の有無と円換算の損益は分けて確認します。
