金の税金：売却益・50万円控除・所有期間を同じ条件で検算

公開日: 2026年10月18日

文責: Masahiro Yasu（クリニック・EC事業の経営者／経理実務者）

個人の現物金地金の売却益は、通常、給与などと合算する総合課税の譲渡所得です。売却代金をそのまま所得にせず、取得費と売却に直接かかった費用を引き、所有期間と同年のほかの譲渡益を確認します。

ここでは営利目的の継続売買を除き、購入資料がある現物金地金を扱います。金投資口座・金貯蓄口座、投資信託、相続・贈与で取得した金の計算は対象外です。

現物金と口座の利益を分ける

最初に確認するのは、売却したものが現物金地金なのか、金融商品の契約なのかです。名称に「金」が入っていても、同じ式は使えません。

個人の金取引と所得の区分
取引扱い
現物金地金の売却（営利目的の継続売買を除く）通常は譲渡所得・総合課税。本記事の計算対象
営利目的の継続的な金地金売買実態に応じて事業所得または雑所得
金投資口座・金貯蓄口座などの利益金融類似商品として源泉分離課税。現物金の式は使わない

金投資口座等の利益は源泉徴収で課税が終了し、ほかの所得と合算して確定申告はできず、扶養親族等の判定に使う所得からも除かれます。根拠は国税庁「金地金の譲渡による所得」です。

金の投資信託の仕組みは金ファンドの比較記事で扱います。また、資産を売った対価は、臨時の入金だからという理由で一時所得にはしません。

所有期間と控除の早見表

現物金地金の譲渡益は「売却代金−取得費−譲渡費用」で求めます。取得費には購入代金や購入手数料を含め、譲渡費用には売るために直接かかった費用を入れます。

令和8年分の個人の現物金地金について、総合課税の譲渡所得を整理した表です。営利継続売買・相続贈与・損失がある場合は対象外とし、特別控除は同年のほかの総合課税の譲渡益と共通で、短期から先に使います。

現物金地金：所有期間と総所得への算入
所有期間区分総所得へ加える額
所有期間が5年以内短期譲渡所得短期の譲渡益から配分された特別控除を引いた額
所有期間が5年超長期譲渡所得長期の譲渡益から配分された特別控除を引いた額の2分の1

令和8年分の総合課税の譲渡所得の特別控除は、同年の金以外を含む短期・長期の譲渡益合計に対し最高50万円です。利益合計を超えて控除はできず、短期・長期の両方があるときは短期から先に差し引きます。

金の売却ごと・買取先ごとに控除枠を取り直す計算ではありません。土地建物や通常の株式の売却は分離課税なので、この総合課税の集計に混ぜません。

同じ年の短期・長期を検算する

先に取引ごとの利益を出し、次に所有期間ごとに合計します。以下では、金以外の短期譲渡益も同じ年にある例を使います。

令和8年分の居住者個人の架空の設例です。営利継続売買・相続贈与・損失はなく、現物金地金と投資用美術品の総合課税の譲渡益だけを集計します。美術品は時の経過により減価しないものと仮定します。取得費・譲渡費用は確定済み、金額は万円単位で、計算に端数はありません。

設例：各取引の売却代金から譲渡益へ
売った資産・区分売却代金取得費譲渡費用譲渡益
現物金地金・短期180万円145万円5万円180−145−5＝30万円
現物金地金・長期260万円160万円10万円260−160−10＝90万円
投資用美術品・短期40万円18万円2万円40−18−2＝20万円

同じ令和8年分の設例では、同年の総合課税の譲渡益を短期・長期に集計し、特別控除を短期優先で配分して、長期の控除後を半額算入します。万円単位・端数なしで、所得控除前の総所得への算入額を示し、税額は示していません。

設例：共通の特別控除から総所得への算入まで
計算段階短期長期
同年の譲渡益を合計金30万円＋美術品20万円＝50万円金90万円
特別控除の配分50万円を控除残りの控除枠は0万円
特別控除後の譲渡所得50万円−50万円＝0万円90万円
総所得へ加える額0万円90万円÷2＝45万円

この設例で総所得へ加える額は、短期と長期を合わせて45万円です。美術品の利益を集計から落とすと控除の配分が変わるため、金の取引資料だけでは計算を終えられません。

購入・売却資料から集計する

購入時の計算書と売却時の明細を、売った現物に対応させます。購入手数料を取得費に含めた場合に、同じ手数料を譲渡費用へ重ねて入れないようにします。

資料確認する内容

売却明細・入金記録売却日、数量、売却代金、売却に直接かかった費用

売却手数料が入金前に引かれているときは、売却代金と手数料を明細で分けて確かめます。購入資料がない場合や、複数回購入した金の一部を売る場合は、取得費と所有期間をこの単純例だけで決めないでください。

所得から税額へ進むときの注意

総合課税の長期譲渡所得で半分にするのは、特別控除後に総所得へ加える額です。所得税額そのものを半分にする仕組みではありません。ほかの所得と合計した後の控除や累進税率によって、年間の税額は変わります。

所得の計算と確定申告の要否も分けて確認します。金の利益が特別控除で消えることだけで、給与やほかの所得を含めた申告が不要とは決まりません。申告の入口は確定申告はいくらから必要か、作成・提出の流れは確定申告のやり方を参照してください。

所得税計算機の対応範囲を確認する

当サイトの所得税計算機は、現物金地金など総合課税の譲渡所得に対応していません。本記事の設例の額を、一時所得や雑所得の欄へ置き換えて入力しないでください。

営利継続売買を除く個人の現物金地金の確認の順序：現物か金融商品かを分ける → 取引ごとの譲渡益を出す → 同年の総合課税の短期・長期に集計する → 特別控除を短期から配分する → 長期の控除後を半額にして合算する。

よくある質問

金を売った代金がそのまま所得になりますか？

なりません。個人の現物金地金が総合課税の譲渡所得になる場合、売却代金から取得費と売却に直接かかった費用を引いて譲渡益を求め、特別控除と所有期間による計算へ進みます。

金投資口座の利益にも現物金の式を使いますか？

使いません。金投資口座・金貯蓄口座等の利益は金融類似商品の源泉分離課税です。源泉徴収で課税が終了し、ほかの所得と合算して確定申告はできず、扶養親族等の判定に使う所得からも除かれます。

出典

  • 国税庁「金地金の譲渡による所得」：所得区分、所有期間、控除の共通枠と順序。
  • 国税庁「譲渡所得の計算のしかた（総合課税）」：取得費、譲渡費用、総所得への算入。
  • 国税庁「譲渡所得の対象となる資産と課税方法」：総合課税と分離課税、生活用動産との区別。

国税庁の令和8年4月1日現在法令等の解説を参照。設例は架空の取引です。
