年末調整 計算機（還付・不足額）

公開日: 2026年10月7日（更新日: 2026年10月9日）

1年分の給与の総額と天引きされた所得税、各種申告書の内容を入れると、国税庁「年末調整のしかた」の手順どおりに年調年税額を計算し、12月の年末調整で超過額と実際に戻る額／いくら追加で引かれるか（不足額）の目安を出します。令和8年分の改正（基礎控除104万円・給与所得控除の最低74万円・扶養親族の所得要件62万円・23歳未満の扶養親族がいる場合の生命保険料控除）と特定親族特別控除に対応しています。

1. 給与と天引きされた税額（1〜12月の合計） 入力例：1年分の給与が500万円なら 5000000源泉徴収簿の「計⑦」欄。通勤手当など非課税のものは含めません。年の中途で就職した人は、前の勤務先に扶養控除等（異動）申告書を出して受けていた給与（前職の源泉徴収票で確認）も含めます。前職で乙欄だった給与は含めず、下の「他の勤務先の給与」に入れます。本年中に支給日が来て支払が確定した給与は、未払でも含めます（前年分の未払給与を本年に支払ったものは含めません） 入力例：1年分で12万円なら 120000（天引きが無かったなら 0）給与明細の「所得税」欄の1年分の合計（源泉徴収簿の⑧）。本年分の未払給与の未徴収の税額も含め、前年分の未払給与を本年に支払ったときの税額は含めません。前年の年末調整の不足額を本年に徴収した額や、過納額を本年に充当・還付した額は関係させず、本年の給与から徴収すべきであった税額で集計します。12月の給与の税額計算を省略する会社では、12月分を含めません 入力例：1年分で75万円なら 750000健康保険・介護保険・厚生年金・雇用保険の1年分の合計（賞与分も含む）。給与から天引きされている小規模企業共済等掛金（iDeCoなど）もここに含めます
自分で払った社会保険料・iDeCoなど（ある人だけ） 未設定 国民年金保険料・国民健康保険料など、給与から引かれていないもの iDeCo（個人型確定拠出年金）・小規模企業共済の掛金で、給与から引かれていないもの
最後の給与（賞与）・未払給与の税額をまだ天引きしていない場合 未設定 12月の給与の税額も計算してから年末調整する会社で、その税額を上の合計に含めた場合に入れます。超過額はまずこの税額に充当され、残りが還付されます（年末調整のしかた40頁） 本年中に支給日が来たのにまだ支払っていない給与があり、その税額を上の合計に含めた場合に入れます。超過額から控除した部分は、その未払給与を支払うときに徴収すべき税額に充当されます
他の勤務先の給与・特定支出控除・給与以外の所得（ある人だけ） 未設定

次の3つは、年末調整の税額の計算には足しませんが、基礎控除・配偶者控除・寡婦控除・ひとり親控除などの判定に使うあなたの合計所得金額に入ります（基礎控除申告書の「本年中の合計所得金額の見積額」）

2か所以上から給与を受けている人は、合計所得金額は給与の全部を基に計算します 年末調整の税額には反映しませんが、合計所得金額の見積額は特定支出控除の控除後の金額で計算します（基礎控除申告書の注） 年金の収入から公的年金等控除額を引いた額。給与と両方ある人は、合計所得金額の計算で最大10万円の所得金額調整控除（措置法41条の3の11第2項）が引かれます 合計所得金額に入る額で入れます（年末調整のしかた9頁）: 事業・不動産・総合課税の利子・配当・短期譲渡所得とその他の雑所得（損益通算後）＋総合課税の長期譲渡所得と一時所得の合計額の2分の1＋退職所得・山林所得＋申告分離課税の所得（譲渡所得は特別控除前）。純損失などの繰越控除は適用前の額です。源泉分離課税の利子、確定申告しないことを選んだ配当や源泉徴収選択口座の株式の譲渡などは含めません。損益通算できる赤字があるときは通算後の額（マイナスも入力できます）

2〜6は、当てはまる人だけ開いて入力します。開かずに計算すると、その控除は無いものとして計算します。

2. 保険料控除申告書（年間の支払保険料） 未設定

控除証明書の金額を入れます。控除額はこの計算機が条文どおりに計算します。該当しない欄は空欄で構いません。一つの契約が地震保険料と旧長期損害保険料の両方に当たる場合は、どちらか一方の金額だけを入れます（両方は控除できません。どちらが得かは地震保険料控除シミュレーターで比べられます）

3. 配偶者 未設定

内縁関係の人は配偶者に含まれません。他の所得者の扶養親族とされる人・青色事業専従者等も対象外です。夫婦の双方がお互いに配偶者特別控除を受けることはできません（どちらか一方だけ）。配偶者が他の所得者の特定親族にも当たる場合は、どちらか1人の控除の対象になります

収入ではなく所得。給与だけなら給与収入136万円以下で62万円以下（令和8年分） 同居特別障害者は、特別障害者のうち、あなた・あなたの配偶者・あなたと生計を一にするその他の親族のいずれかとの同居を常況としている人です（あなたと別居でも、生計を一にする他の親族と同居していれば当たります）
4. 扶養親族（合計所得金額62万円以下の親族）の人数 未設定

扶養親族は、あなたと生計を一にする親族（配偶者、青色事業専従者として給与を受ける人、白色事業専従者を除く）で、合計所得金額が62万円以下（給与だけなら給与収入136万円以下）の人です。配偶者など他の人が扶養控除を受ける人は、ここには入れず、下の「他の人が扶養控除を受けている扶養親族」に入れます。年齢は令和8年12月31日の現況で数えます（その親族が年の中途で死亡した場合はその死亡の時、あなた自身が年の中途で死亡したり出国して非居住者になったりする場合はその時の現況）。親族は6親等内の血族と3親等内の姻族で、いわゆる里子や、市町村長から養護を委託された老人で一定の要件を満たす人も扶養親族に含まれます。国外に住む親族（非居住者）を扶養控除の対象にできるのは、16歳以上30歳未満・70歳以上の人と、30歳以上70歳未満で留学により国内に住所・居所を有しなくなった人・障害者・本年に生活費や教育費として38万円以上の支払を受けている人だけです（この年齢の制限は扶養控除の対象の範囲で、16歳未満の国外居住親族が障害者なら障害者控除の対象になります）。国外居住親族（配偶者・特定親族を含む）について控除を受けるには、親族関係書類（留学による場合は留学ビザ等書類も）と送金関係書類（38万円以上の支払による場合は38万円送金書類）の提出または提示が必要です

扶養控除はありませんが、所得金額調整控除・生命保険料控除の特例・障害者控除の判定に使います

上の扶養親族（16歳未満を含む）のうち、障害者に当てはまる人の人数

あなた・配偶者・生計を一にするその他の親族のいずれかとの同居を常況としている特別障害者

他の人（配偶者など）が扶養控除を受けている扶養親族の人数。あなたの扶養控除にはなりませんが、所得金額調整控除と生命保険料控除の特例は、誰が扶養控除を受けているかに関係なく判定します（夫婦の両方が所得金額調整控除を受けられます）

5. 特定親族（19歳以上23歳未満で、合計所得金額62万円超123万円以下の親族） 未設定

あなたと生計を一にする親族（配偶者・青色事業専従者等を除く）で、アルバイト収入が多く扶養親族に入らない大学生の子など。給与だけなら給与収入136万円超197万円以下です。扶養親族の人数には入れません。2人以上の所得者の特定親族に当たる人は、そのうち1人だけが控除を受けられます。他の所得者の配偶者特別控除の対象となる配偶者にも当たる人は、どちらか1人の控除の対象になります。その親族自身が特定親族特別控除を受けている場合は、その親族について控除を受けられません（親族の双方がお互いに受けることもできません）

入力例：2人なら 900000, 1100000
6. あなた自身・住宅ローン控除 未設定
ひとり親: 現に婚姻をしていない人（または配偶者の生死が明らかでない人）で、①生計を一にする子（他の人の同一生計配偶者・扶養親族とされている子を除き、総所得金額等が62万円以下の子）がいる、②合計所得金額500万円以下、③事実上婚姻関係と同様の事情にある人がいない、のすべてに当たる人。
寡婦: ひとり親に当たらない人で、(1) 夫と離婚した後婚姻をしていない人で、扶養親族がいる・合計所得金額500万円以下・事実婚の相手がいない、のすべてに当たる人、または (2) 夫と死別した後婚姻をしていない人か夫の生死が明らかでない人で、合計所得金額500万円以下・事実婚の相手がいない人。
判定はひとり親控除・寡婦控除シミュレーターでもできます

年末調整は、毎月の給与から概算で天引きしてきた所得税を、1年分の給与が確定した12月に正しい年税額で計算し直して精算する手続きです。天引きの合計が年税額より多ければ超過額が出て、まだ天引きしていない税額に充当した残りが戻り、少なければ12月の給与から追加で引かれます（不足額）。令和8年分は、基礎控除の引上げなどの改正が令和8年12月1日に施行され、11月までの天引きは改正前の税額表のままなので、改正の効果がまとめて12月の年末調整に出ます。上の計算機は、国税庁「令和8年分 年末調整のしかた」の手順と表で計算します（一般的な計算方法の説明であり、個別の税務相談ではありません）。

年調年税額の計算の手順

年末調整の年税額（年調年税額）は、次の順で計算します（年末調整のしかた37〜39頁）。

課税給与所得金額算出所得税額
1,950,000円以下×5%
1,950,000円超 3,300,000円以下×10%−97,500円
3,300,000円超 6,950,000円以下×20%−427,500円
6,950,000円超 9,000,000円以下×23%−636,000円
9,000,000円超 18,000,000円以下×33%−1,536,000円
18,000,000円超 18,050,000円以下×40%−2,796,000円

令和8年分の年末調整のための算出所得税額の速算表（年末調整のしかた55頁）。課税給与所得金額が18,050,000円を超える場合は年末調整の対象になりません。

課税されるのは給与だけです。年末調整で精算するのは給与にかかる所得税だけなので、課税給与所得金額は「給与所得控除後の給与等の金額（調整控除後）−所得控除の合計額」で求め、給与以外の所得は足しません。ただし、基礎控除・配偶者控除・寡婦控除・ひとり親控除・勤労学生控除が受けられるか、いくらかは給与以外の所得も足した合計所得金額で決まります。給与所得・退職所得以外の所得が20万円を超える人は、確定申告を要しない場合（所得税法121条1項1号）に当たらないため、確定申告が必要になることがあります。

年末調整の対象にならない人

次のいずれかに当てはまる人は、勤務先で年末調整をしません（年末調整のしかた5頁）。
  1. 本年中の主たる給与の収入金額が2,000万円を超える人
  2. 災害により被害を受けて、災害減免法の規定により本年分の給与に対する源泉所得税及び復興特別所得税の徴収猶予又は還付を受けた人
  3. 2か所以上から給与の支払を受けている人で、他の給与の支払者に扶養控除等（異動）申告書を提出している人や、扶養控除等（異動）申告書を提出していない人（乙欄の人）
  4. 年の中途で退職した人で、①死亡により退職した人、②著しい心身の障害のため退職した人で本年中に再就職ができないと見込まれる人、③12月中に支給期の到来する給与の支払を受けた後に退職した人、④パートタイマーなどが退職した場合で本年中に支払を受ける給与の総額が136万円以下の人（退職後本年中に他の勤務先等から給与の支払を受けると見込まれる人を除く）のいずれにも当たらない人
  5. 非居住者（ただし、年の中途で海外の支店へ転勤したことなどにより非居住者となった人は、非居住者となった時に年末調整をします）
  6. 継続して同一の雇用主に雇用されない日雇労働者など（丙欄の人）

対象にならない人は、原則として自分で確定申告をして精算します（確定申告を要しない場合（所得税法121条）に当たる人もいます）。

還付・不足額の精算

徴収税額の合計が年調年税額より多いと超過額が出ます。最後の給与の税額や未払給与の税額をまだ天引きしていないときは、超過額をまずその税額に充当し、残りを本人に還付します。勤務先は、年末調整をした月分（通常は12月分）として納める源泉所得税から差し引いて還付し、引ききれないときはその後に納める源泉所得税から順次還付します。少ないと不足額が出て、年末調整をする月の給与から徴収されます。不足額を引くと12月の手取りが1〜11月の平均の70%未満になる人は、勤務先が税務署の承認を受けて、翌年1月と2月に分けて徴収できます（その月の給与の通常の税額は繰り延べられないので、繰延べを受ける人は最後の給与の税額計算を省略せずに年末調整をします）（年末調整のしかた39〜41頁）。

国税庁の設例（年末調整のしかた57〜59頁）を、この計算機に入れると1円まで一致します。 給与8,970,000円・徴収税額156,670円・社会保険料等1,386,102円・配偶者控除・扶養3人・特定親族1人・住宅借入金等特別控除76,500円の人は、年調年税額41,400円で、115,270円が還付されます。給与4,390,000円・徴収税額51,845円の設例（12月の税額計算を省略しない場合）は、年調年税額26,100円・超過額25,745円です。

よくある質問

令和8年の年末調整は何が変わりましたか？

合計所得金額489万円以下の人の基礎控除が104万円になり、給与所得控除の最低額が74万円になりました。扶養親族と同一生計配偶者の所得要件は合計所得金額62万円以下、勤労学生は89万円以下に上がり、23歳未満の扶養親族がいる人は一般の生命保険料控除（新契約・新旧併用）の上限が6万円になりました。改正は令和8年12月1日施行で令和8年分から適用されますが、11月までの天引きは改正前の税額表のままなので、改正による減税分は12月の年末調整でまとめて精算されます。

年末調整で医療費控除やふるさと納税の控除は受けられますか？

受けられません。年末調整で差し引くのは所得税法190条2号が定める社会保険料控除・生命保険料控除・扶養控除などの13の所得控除と、所得金額調整控除・住宅借入金等特別控除だけで、医療費控除・寄附金控除（ふるさと納税）・雑損控除は確定申告で受けます。住宅借入金等特別控除も1年目は確定申告が必要で、2年目以降は年末調整で受けられます。

年末調整の還付金はいつ戻りますか？

勤務先が、年末調整をした月分（通常は12月分）として納める源泉所得税から差し引いて本人に還付します。勤務先が納める源泉所得税だけでは還付しきれないときは、その後に納める源泉所得税から順次還付し、還付することとなった日の翌月から2か月を経過しても還付しきれない見込みのときなどは、勤務先が税務署に還付請求書を出し、税務署から還付されます。

不足額が出たら、どうなりますか？

年末調整をする月の給与（賞与を含む）から徴収されます。引ききれないときは、その後の給与から順次徴収されます。不足額を引くと、その月の税引き後の手取りが1月から前月までの手取りの平均の70%未満になる人は、勤務先が「年末調整による不足額徴収繰延承認申請書」を税務署に出して承認を受ければ、翌年1月と2月に分けて徴収できます。

この計算機の結果と会社の源泉徴収票が違うのはなぜですか？

入力した徴収税額・社会保険料・保険料の金額が、会社の集計（源泉徴収簿）と違うことが原因として考えられます。12月の給与の税額計算を省略する会社では、12月分の税額を徴収税額に含めずに精算します。また、前の勤務先の給与や現物給与の課税分の有無、扶養親族の年齢区分（令和8年12月31日の現況）でも結果が変わります。正式な金額は勤務先の年末調整の結果（源泉徴収票）で確認してください。
